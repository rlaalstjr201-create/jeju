# Light Spec: 홈 개편 A′ + 비 소식

근거: ADR-0075, ADR-0076. 목업 `apps/web/design/proto-d/a2.html`(동작 참고용. 문구·크기는 이 문서와 SPEC §14가 이긴다).

## 화면 (390px 기준)

### 홈 (위 → 아래)

1. **머리줄**: 그대로다(`#basis` 「여기 근처 ⌄」, ♥ N).
2. **앱 이름 줄**: 「여행계획짜기 귀찮아:제주」, 15px, 회색.
3. **오늘 판** (`--fill` 바탕, `--r-ctl`):
   - 첫 줄: 「10월 3일 토요일」(굵게) + 회색 ` · `로 이은 접힌 정보.
   - 접힌 정보: 해 지는 시각 「해 지는 시각 18:16」, 그리고 둘째 줄에 오르지 못한 것.
   - 둘째 줄: 누를 수 있는 줄 하나. 없으면 둘째 줄도 없다.
     - 비: 「비 소식 · 실내만 볼까요?」 → 실내만을 켠다(이미 켜져 있으면 「비 소식이 있어 실내만 보고 있어요」 + 「모두 보기」). 옆에 「날씨: 기상청」.
     - 장날: 「오늘 {장 이름} 장날 · 차로 약 N분」(기준이 없으면 「· {지역}」) → 아래 장날 묶음으로 스크롤.
     - 오른쪽 끝에 SVG 화살표. 글자 `›`는 금지(슬롭 #2).
4. **질문**: H1 「지금 뭐 하고 싶어요?」, 그 아래 회색 「하나 고르면 근처 3곳을 골라 드려요」.
5. **기분 4줄**: 줄 높이 84 이상.
   - 왼쪽: 이름(20px) + 회색 「예: A, B」(한 줄, 넘치면 말줄임).
   - 오른쪽: 52px 사진 2장(`--r-thumb`), `alt=""`.
   - 버튼 하나가 줄 전체다. 기존 `button.mood[data-mood]`를 그대로 쓴다.
6. **아무거나 골라줘**: 그대로다.
7. **「오늘 장 서는 곳」** (`#market`): 64px 사진 + 이름 + 「오늘 장 서는 날 · 차로 약 N분」. 누르면 그 장소의 길찾기(`goLink`). 0곳이면 묶음째 숨긴다.
8. **「다른 동네 둘러보기」**: 3열 정사각 타일. 사진 + 지역 이름 + 대표 지명. 링크는 `/jeju/<slug>/`이고, 지금 동네는 뺀다.
9. **출처 줄**: 「정보·사진: 비짓제주(제주관광공사)」.

### 결과

- `#basis`: 실내만이면 「구제주 근처 · 실내만」.
- 제목 아래 한 줄(회색): 「{차로 30분|걸어서 15분|차로 1시간} 안에서, 소개글로 볼 때 가 볼 만한 곳부터 골랐어요」. 실내만이면 「실내 중에서, 」를 덧붙인다.
- 큰 카드 `a.go`: 높이 48, 너비 100%, `--main-tint` 바탕, `--main` 글자, `--r-ctl`. 작은 카드 `a.go`는 지금 그대로다.
- 큰 카드와 「아니면」 사이 여백은 40px.

## 데이터 규칙

- **예시·사진**: `pool(spots, origin, mood, tab, reach, indoor, day)`의 앞 2개.
  - origin은 기준(지역·숙소 중심 → 이번 세션 마지막 결과의 origin → 없음) 순으로 정한다.
  - origin이 없으면 섬 전체에서 점수 → id 순.
  - 먹기는 식사 탭 기준이다. 실내·날짜 모드를 따른다.
- **해 지는 시각**: 기기에서 NOAA 식으로 계산하고, 좌표는 기준 지역(없으면 제주시청)을 쓴다. 맞는지는 Open-Meteo 값(제주시)으로 확인한다: 2026-10-03 18:16, 2026-06-21 19:46, 2026-03-20 18:45, 2026-09-01 18:59. 허용 오차는 ±2분.
  - 날짜 모드(다른 날을 보고 있을 때)는 그날 기준으로 계산하고, 「이날」 문구를 쓴다(market.ts와 같은 규칙).
- **오늘 장**: `marketDay(rule, day) === 'open'`. 기준이 있으면 차로 30분 안에서 가까운 순이다.
- **비 소식**:
  - 기준 동네가 있을 때만 `/api/rain?area=<slug>`를 부른다. GPS면 마지막 origin에서 가장 가까운 동네로 바꾼다.
  - 3초 타임아웃. 204·오류·타임아웃이면 숨긴다.
  - `sessionStorage['jeju.rain']`에 `{v:1, area, at, rain}`를 30분 저장하고, 읽을 때 검증한다.

## 함수 `/api/rain`

- 입력 `area`는 15 slug 중 하나여야 한다. 아니면 400.
- 발표 시각: KST 기준 02·05·08·11·14·17·20·23시 + 10분 뒤부터 쓴다. 그 전이면 직전 발표분.
- 응답 200 `{area, pop, rain, base, from:"기상청"}`, `Cache-Control: public, max-age=1800`. 키 없음·실패면 204 + `no-store`.
- 격자: 기상청 LCC 변환. 15곳 표를 단위 테스트로 고정한다(제주시청 근처 = (53,38), 서귀포 시내 = (52,33)).

## 바꾸지 않는 것 (회귀 기준)

- **뒤로 가기**: 홈이 첫 기록이고, 결과에서 뒤로 2번이면 앱 밖으로 나간다(e2e S17~S20).
- **카드 마크업 계약**: `.card[data-id]`, `a.card-link`, `a.go`가 카드마다 1개, `button.heart`, `.meta .market`, `.card .indoor`.
- **추적 이벤트 계약**: tap·shown·save·map·book.
- **홈 계약**: `button.mood[data-mood]` 5개, `#home`, `#date`, `#ask`, 이른 탭 스크립트.
- **예산·규칙**: JS+CSS gzip 50KB 이하. 슬롭 0건. 대비 테스트 통과. 모든 저장소 키는 parse 검증을 거친다.
