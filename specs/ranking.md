# Light Spec: 만족도 점수와 범위

근거: ADR-0060.

## 점수 기준 (1~5, 정수)

근거는 그 장소의 원본(`review/input`: summary, comment, intro, tags, awards, category)과 이미 출하된 이유 문장뿐이다. 모르면 3.

| 점수 | 뜻 | 신호 예 |
|---|---|---|
| 5 | 여행 중 일부러 가도 아깝지 않은 곳 | 공식 수상·선정(awards), 원문이 대표 명소·경관·전문점을 구체적으로 설명, 제주다움이 뚜렷함 |
| 4 | 근처라면 들를 만한 좋은 곳 | 구체적 강점(대표 메뉴, 경관, 체험)이 원문에 분명함 |
| 3 | 무난함 / 정보 부족 | 원문이 짧거나 일반적 |
| 2 | 여행자 만족이 낮을 가능성 | 일상 편의 시설 성격, 원문에 강점이 거의 없음, 계절·조건 의존이 큼 |
| 1 | 추천하기 어려움 | 운영 불확실 표시, 여행과 무관한 성격 |

- 수상 규칙(교차 감사 후 통일): `blue_ribbon`·`blue_ribbon_star` → 5, `blue_ribbon_listed` → 최소 4. 휴관 등으로 1점인 곳은 예외.
- 기분별로 따로 본다: 쉬기·걷기·새로운 것·먹기(식사/카페). 같은 기준을 그 기분의 기대에 맞춰 적용.
- 유명세 자체가 아니라 "여행자가 갔을 때 만족할 근거"를 본다. 원문에 없는 사실로 가산하지 않는다.
- 분포 목표(강제 아님): 5점 ≤ 15%, 3점이 가장 많게.
- 기록: `review/score/score-NN.json` = `{ id, score, basis }[]`, basis는 원문 인용 한 줄.
- 감사: 무작위 5%를 다른 opus가 재채점, ±1 이내 일치율 ≥ 85%.

## 정렬

- 후보 = 범위 안(이동 시간 ≤ 범위). 3곳 미만이면 가까운 3곳까지 넓힘.
- 정렬 키: 점수 내림차순 → 이동 시간 오름차순 → id.
- 순환(안 본 곳 먼저, 직전 3장 맨 뒤)은 정렬 결과 위에 그대로.
- `아무거나`: 쉬기·걷기·새로운 것 풀에서 각 1장, 각 풀은 위 정렬.

## 범위

- 기준 시트 `어디` 아래 `얼마나` 묶음: `걸어서`(걷기 15분 이내) · `차로 30분` · `차로 1시간`. 기본 `차로 30분`. 선택은 저장.
- 기준 라벨은 그대로(범위는 라벨에 넣지 않는다). 지역 기준일 때도 같은 규칙.

## 성공 기준

- R1: 2,959곳 모두 점수·근거 기록, 감사 일치율 ≥ 85%.
- R2: 15지역 × 6버튼 × 3범위에서 카드 3장(빈손 0), 범위 안이면 범위 초과 카드 없음.
- R3: 같은 범위 안에서 첫 장 점수 ≥ 뒤 장 점수.
- R4: 기존 vitest·e2e·check:slop 통과, 점수는 화면·DOM 텍스트에 나오지 않음.
