# Light Spec: 새로운 거 — 섞어서·구경·체험

근거: ADR-0064. 부품은 SPEC 3판 먹기 탭(§6.4)을 그대로 쓴다.

## 동작

- "새로운 거" 결과 머리 아래 탭 `섞어서 · 구경 · 체험`, 기본 `섞어서`.
- 섞어서 = sub 무관 후보 전체, ADR-0060 정렬(점수 → 이동 시간 → id).
- 구경 = `sub: sight`만, 체험 = `sub: do`만. 같은 정렬·범위·순환·넓히기 규칙.
- 탭 바꾸기 = 먹기 탭과 같은 요청 id·history·두 번 탭 규칙. 순환 기록은 탭별로 따로(`new:mix`, `new:sight`, `new:do`).
- 선택 탭 기억, 세션 복원 시 같은 탭.
- 아무거나는 지금처럼 새로운 거 풀(섞어서)에서 1장.

## 데이터

- 카테고리 → sub: experience → `do`, sightseeing·cultural_space → `sight`.
- cafe·restaurant 46곳: 원문(summary·tags)에 체험 활동(만들기, 클래스, 체험, 승마 등)이 중심이면 `do`, 아니면 `sight`. 판정과 근거는 `review/copy/new-sub.json`.
- 빌드 스크립트가 같은 규칙을 적용하고, 출하본에도 적용.

## 성공 기준

- N1: 새로운 거 508곳(현재 출하분) 모두 sub가 sight/do.
- N2: 15지역 × 3범위 × 3탭에서 3장(빈손 0).
- N3: 기본 탭 섞어서, 첫 화면·첫 탭 흐름 불변.
- N4: 탭 전환 history·두 번 탭·순환·복원 테스트 통과, 320/390 넘침 0, 탭 대상 ≥ 48px 누름 영역.
- N5: 기존 vitest·e2e·check:slop 통과.
