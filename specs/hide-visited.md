# Light Spec: 가 본 곳 빼기

근거: ADR-0087(Proposed). 부품은 하트(SPEC 6.5)·저장한 곳 화면(6.12)·순환(`pick.ts` `seen`/`last`)·기기 저장소(`store.ts`)를 그대로 쓴다.

## 사용자에게 보이는 것

### 카드의 「가 봤어요」

- 결과 카드 3장 모두에 `.tbtn` `가 봤어요`(`button.visited`)를 둔다.
  - 첫 장: 「길찾기」 면 버튼 아래에 줄을 하나 둔다(`div.ctl`, 위 4, 왼쪽 -8). 예약 링크가 있으면 그 줄의 앞에 예약 링크, 뒤에 「가 봤어요」(사이 8).
  - 줄 카드: 카드 폭 전체의 「길찾기」 줄 안에서 「길찾기」 뒤에 둔다(사이 8).
- 크기와 모양은 다른 `.tbtn`과 같다. 15/600 `--text`, 밑줄 1px `--muted`, 그린 높이 44, 누름 영역 48×48. 링크 위에 둔다(`z-index: 1`). 아이콘·면·색 없음. 새 글자 크기·색 없음.
- `aria-pressed`로 상태를 나타낸다. `aria-label`은 `{이름}, 가 봤어요`로 고정한다(하트와 같은 방식).
- 누르면:
  - 그 버튼만 `aria-pressed="true"`가 되고 글자 앞에 체크(하트처럼 그 노드만 바꾼다. 카드는 그대로 두고 다시 그리지 않는다).
  - 상태 줄(`#status`, `role="status"`)에 `{이름}은 다음부터 빼고 골라요` 한 줄.
  - 다시 누르면 되돌린다. 상태 줄은 `{이름}을 다시 넣었어요`.
- 「다른 3곳 보기」와 기분을 다시 누를 때부터 뺀 곳은 나오지 않는다. 지금 화면의 카드는 그대로 둔다.
- 저장한 곳 줄과 랜딩·장소 페이지에는 없다.

### 저장한 곳 화면의 「뺀 곳」

- 뺀 곳이 1곳 이상일 때만, 저장한 곳 화면 아래 「지도 앱」 줄 위에 `.tbtn` `뺀 곳 N곳`(`aria-expanded`)을 둔다.
- 저장이 0개라 ♥ N 버튼이 없어도 이 화면으로 올 수 있어야 한다. 그래서 설정 쪽에도 같은 입구를 둔다. 정확한 자리는 Plan에서 지금 설정 화면(H5~H8 개편)을 보고 정한다.
- 펼치면 이름 줄 목록(가까운 순, 사진 없음, 15/400)과 줄마다 `.tbtn` `다시 넣기`, 맨 아래 `.tbtn` `모두 다시 넣기`.
- 「모두 다시 넣기」는 확인 창(`confirm`) 없이 바로 하고, 상태 줄에 `뺀 곳 N곳을 모두 다시 넣었어요`.
- 목록이 비면 그 묶음은 사라진다.

## 고르는 규칙

- 뺀 곳(`visited` 집합)은 다음 계산에 들어가기 전에 후보에서 거른다.
  - `pool`, `islandTop`: 결과 카드와 홈 「예:」.
  - `sunsetSpots`: 노을 볼 곳 묶음과 줄의 수, 3곳 기준.
  - 오늘 장 서는 곳.
  - 거르는 자리는 이 넷이 함께 받는 장소 배열 한 곳이다(Plan).
- 저장한 곳 목록, 랜딩·장소 페이지, 사용 기록 집계에는 적용하지 않는다.
- 거른 뒤 모자라면 지금의 넓히기(범위·60분 가드)를 그대로 따른다. 새 규칙은 없다.
- 순환 기록(`seen`/`last`)은 그대로 둔다. 다시 넣은 곳은 순환 규칙대로 다시 나온다.
- 하트로 저장한 곳을 빼도 저장은 그대로다.

## 저장

- 키 `jeju.visited`: 장소 id 문자열 배열, 넣은 순서, 중복 없음, 최대 500(넘으면 가장 오래된 것부터 버림). 읽을 때 문자열이 아닌 값은 버린다. 출하 데이터에 없는 id는 지우지 않고 그냥 무시한다(데이터가 다시 생길 수 있다).
- **저장소가 없거나 오류(시크릿 모드, 용량, 차단)일 때**:
  - 앱은 지금처럼 메모리로 이어 간다(`store.ts` 원칙, S27~S29). 「가 봤어요」와 되돌리기는 이번 방문 동안 동작한다.
  - 다시 열면 사라지는 것은 하트와 같다. 따로 경고 문구는 없다.
  - 저장에 실패해도 예외가 화면이나 콘솔 오류로 새지 않는다.
- 데이터의 `hide`(폐업 숨김)와는 별개다. 이름과 키를 섞지 않는다.
- 링크로 백업(ADR-0063)에는 담지 않는다(1단계 범위 밖).

## 사용 기록

- 이벤트 `visited`(누름), `unvisited`(되돌림)를 넣는다. 필드는 `id`와 `d`만이고 `mood`·`range`·`basis`는 기존 규칙대로다. `/api/events`의 값 검사 목록에 더한다. D1 카운터 키는 (날, id, 이벤트) 그대로다.
- GA4·네이버에는 보내지 않는다.
- 기록 끄기가 켜져 있으면 보내지 않는다(지금 규칙).

## 성공 기준

- **S1(고르기)**:
  - 뺀 곳은 결과 카드·「예:」·노을 묶음·장날 줄에 나오지 않는다.
  - 다시 넣으면 다음 뽑기부터 나온다.
  - 15지역 × 3범위 × 기분에서 한 기분의 가까운 후보를 모두 빼도 빈손 조건은 지금과 같다(넓히기 규칙 그대로).
  - 뺀 곳이 없으면 카드·순서·홈 DOM이 지금과 바이트 단위로 같다.
- **S2(저장)**:
  - 누름·되돌림이 `jeju.visited`에 반영된다. 다시 열어도 유지된다.
  - 잘못된 값·비문자·중복을 읽으면 고쳐 읽는다. 500 상한을 지킨다.
  - `localStorage`가 없거나 `setItem`이 던져도 앱이 동작하고, 이번 방문 동안 빼기·되돌리기가 된다.
- **S3(화면)**:
  - 320·390, 밝게·어둡게에서 가로 넘침 0.
  - 「가 봤어요」 누름 영역 ≥ 48, 카드 링크를 누르지 않는다.
  - 누름 뒤 카드 노드는 그대로이고 사진이 깜빡이지 않는다.
  - 상태 줄 문구가 나온다. check:slop 0건.
- **S4(해제 경로)**:
  - 「뺀 곳 N곳」은 1곳 이상일 때만 보인다.
  - 「다시 넣기」·「모두 다시 넣기」 뒤 목록·수가 맞다. 비면 묶음이 사라진다.
  - 저장이 0개여도 설정 쪽 입구로 닿을 수 있다.
- **S5(기록)**:
  - `visited`·`unvisited`가 장소 id만 담는다. 기록 끄기면 0건이다.
  - `/api/events`가 새 이름을 받고 모르는 이름은 여전히 거른다.
- **S6(불변)**:
  - tsc, vitest(기존 테스트 그대로 통과), check:slop, build(JS+CSS gzip ≤ 50KB), e2e 모두 통과한다.
  - 새 e2e 한 항목: 빼기 → 다른 3곳에서 안 나옴 → 저장한 곳에서 다시 넣기 → 다시 나옴. 저장소가 던지는 상태도 포함한다.
