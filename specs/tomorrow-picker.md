## 화면

**한 화면**이 전부다.

1. **첫 상태**: 기분 버튼 ~~4개~~ 5개(ADR-0028) + 상단에 작은 위치 표시(~~"내 위치 기준 ⇄"~~ 기준 라벨 `여기 근처` / `숙소 근처` / `{지역} 근처`, `⇄` 없음 — D1, ADR-0058)
   - 푹 쉬고 싶어 / 좀 걷고 싶어 / 새로운 거 해보고 싶어 / 맛있는 거 먹고 싶어(ADR-0028) / 아무거나 골라줘
   - 맛있는 거 먹고 싶어는 식사(기본) | 카페·디저트 토글로 나눈다(ADR-0028).
2. **버튼 탭 후**: 같은 화면 아래에 카드 3장. 다른 버튼을 누르면 카드가 바뀐다.
3. **카드 탭**: 외부로 넘어간다(아래 "링크").
4. **위치 전환(~~⇄~~ 기준 라벨, D1·ADR-0058)**: 내 위치 ↔ 숙소(+ 지역 15곳, ADR-0029). 숙소가 없으면 이때 처음 ~~숙소 검색 시트를~~ 숙소 시트("지금 위치를 숙소로" 또는 지역 선택 — 검색 없음, ADR-0058)를 띄우고, 고른 값을 기기에 저장한다.

로그인, 온보딩, 설정 화면 없음.

## 규칙

- **후보**: 기분에 맞는 스팟 중 기준 위치에서 가까운 순.
- **빈손 없음**: 반경 안에 3개 미만이면 반경을 넓혀 3개를 채운다. 그래도 없으면 제주 전체에서 가까운 순.
- **아무거나 골라줘**: ~~나머지 세 기분에서~~ 쉬기·걷기·새로운 것에서 하나씩(먹기는 섞지 않음, ADR-0028), 가까운 것 위주로 3장.
- **같은 걸 반복하지 않기**: ~~같은 버튼을 다시 누르면 방금 본 카드는 뒤로 미룬다.~~ 기분 재탭은 마지막으로 본 3장 복원, 다음 3장은 `다른 3곳 보기`(후보 ≥ 6이면 직전 3장과 겹치지 않음) (D2, ADR-0058).
- **위치**: 기본은 내 위치(GPS). 권한 거절 시 지역 ~~4개(제주시/서귀포/동쪽/서쪽)~~ 15곳(ADR-0029) 중 선택.

## 링크

- **길찾기**: 카카오맵 장소 페이지 (`kakao_place_id` 사용). ID가 없으면 카카오맵 이름 검색 링크(이름에 `제주`·`서귀포`가 없으면 `제주 ` 접두) (ADR-0028, D4·ADR-0058).
- **~~유료 체험·입장권~~ `bookable` 카드**(ADR-0058): 카드 아래 "예약 찾아보기" → ~~클룩 또는~~ 마이리얼트립 검색 결과를 스팟 이름으로 연다(마이리얼트립만, ADR-0058). 개별 상품 링크는 저장하지 않는다(수집 금지).

## Open Questions

1. **카테고리 → 기분 매핑**: 기존 `category` 값을 세 기분(쉬기/걷기/새로운 것)에 어떻게 나눌지. ~~어느 기분에도 안 맞는 카테고리(음식점 등)는 제외.~~ → 결정: 맛집 포함, 기분은 전 항목 검수로 정함(ADR-0028).
2. **"차로 약 N분" 계산**: 서버가 없으므로 길찾기 API 대신 직선거리로 추정할지(예: 직선거리 × 1.3 ÷ 시속 40km). 정확도보다 감을 주는 용도.
3. **숙소 ~~검색~~ 등록**: 카카오 로컬 검색(브라우저용 키)을 쓸지, 지도에서 핀을 찍게 할지, 지역 ~~4개~~ 중 고르게 할지. → 결정: 검색 없이 "지금 위치를 숙소로" 또는 지역 15곳 중 선택(ADR-0029, ADR-0058).
4. **카드 수**: 3장 고정인지, "다른 거 보기"로 더 보여줄지. → 결정: 3장 고정 + `다른 3곳 보기`(D2, ADR-0058).
5. **"예약 찾아보기" 대상**: 클룩과 마이리얼트립 중 하나로 할지, 둘 다 보여줄지. → 결정: 마이리얼트립만, `bookable` 카드에만(ADR-0058).
