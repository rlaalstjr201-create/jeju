# Light Spec — 내일 뭐하지

**Feature:** 기분 버튼 한 번 → 근처 할 거리 카드 → 외부 링크로 넘기기
**Persona:** 계획을 자세히 세우지 않는 자유여행자 (렌터카로 제주를 다니는 중)
**Status:** Draft (2026-09-30)
**근거:** ADR-0025, ADR-0026, ADR-0027

---

## 사용자 시나리오

> 지은(31)은 제주 이틀째 밤, 서귀포 숙소에 누워 있다. 내일 계획은 없다.
> 친구가 보내준 링크를 연다. 버튼 네 개만 보인다.
> "좀 걷고 싶어"를 누른다. 카드 세 장이 뜬다 — 사진, 이름, 왜 좋은지 한 줄, 차로 몇 분.
> 두 번째 카드를 누르니 카카오맵이 열린다. 내일은 거기로 간다.
> 끝.

---

## 화면

**한 화면**이 전부다.

1. **첫 상태**: 기분 버튼 4개 + 상단에 작은 위치 표시("내 위치 기준 ⇄")
   - 푹 쉬고 싶어 / 좀 걷고 싶어 / 새로운 거 해보고 싶어 / 아무거나 골라줘
2. **버튼 탭 후**: 같은 화면 아래에 카드 3장. 다른 버튼을 누르면 카드가 바뀐다.
3. **카드 탭**: 외부로 넘어간다(아래 "링크").
4. **위치 전환(⇄)**: 내 위치 ↔ 숙소. 숙소가 없으면 이때 처음 숙소 검색 시트를 띄우고, 고른 값을 기기에 저장한다.

로그인, 온보딩, 설정 화면 없음.

## 카드

| 항목 | 내용 |
|---|---|
| 사진 | 스팟 이미지. 없으면 카드를 후보에서 제외 |
| 이름 | 스팟 이름 |
| 이유 한 줄 | 추천 이유 한 문장 |
| 거리 | "차로 약 N분" |

가격·운영시간·평점·태그는 보여주지 않는다.

## 규칙

- **후보**: 기분에 맞는 스팟 중 기준 위치에서 가까운 순.
- **빈손 없음**: 반경 안에 3개 미만이면 반경을 넓혀 3개를 채운다. 그래도 없으면 제주 전체에서 가까운 순.
- **아무거나 골라줘**: 나머지 세 기분에서 하나씩, 가까운 것 위주로 3장.
- **같은 걸 반복하지 않기**: 같은 버튼을 다시 누르면 방금 본 카드는 뒤로 미룬다.
- **위치**: 기본은 내 위치(GPS). 권한 거절 시 지역 4개(제주시/서귀포/동쪽/서쪽) 중 선택.

## 링크

- **길찾기**: 카카오맵 장소 페이지 (`kakao_place_id` 사용).
- **유료 체험·입장권**: 카드 아래 "예약 찾아보기" → 클룩 또는 마이리얼트립 검색 결과를 스팟 이름으로 연다. 개별 상품 링크는 저장하지 않는다(수집 금지).

## 데이터

기존 DB `spots`에서 **한 번만** JSON으로 뽑아 고정한다(ADR-0027). 필드:

| 필드 | 출처 |
|---|---|
| `id`, `name` | `spots.id`, `spots.name` |
| `lat`, `lng` | `spots.lat`, `spots.lng` |
| `mood` | `spots.category` → 기분 매핑 (Open Question 1) |
| `reason` | `spots.curation_comment` |
| `image` | `spots.image_url` (없으면 `thumbnail_url`) |
| `kakaoPlaceId` | `spots.kakao_place_id` |
| `paid` | `spots.price_range != 'free'` |

`is_active = false`, 사진 없음, 이유 없음인 스팟은 뽑을 때 제외한다.

## 범위 밖

앱 내 예약·결제 / 일정 짜기 / 맛집 / 로그인 / 데이터 추가 수집·갱신 / 스토어 앱

## 완료 기준

1. 배포된 URL을 폰에서 열면 3초 안에 기분 버튼 4개가 보인다. — 2026-10-14
2. 제주 지역 4개 대표 좌표에서 4버튼 모두 카드가 3장 이상 나온다(자동 테스트로 확인: 4지역 × 4버튼 = 16조합). — 2026-10-14
3. 제주 가는 지인 1명 이상이 여행 중 실제로 써 본다. — 2026-10-30

## Open Questions

1. **카테고리 → 기분 매핑**: 기존 `category` 값을 세 기분(쉬기/걷기/새로운 것)에 어떻게 나눌지. 어느 기분에도 안 맞는 카테고리(음식점 등)는 제외.
2. **"차로 약 N분" 계산**: 서버가 없으므로 길찾기 API 대신 직선거리로 추정할지(예: 직선거리 × 1.3 ÷ 시속 40km). 정확도보다 감을 주는 용도.
3. **숙소 검색**: 카카오 로컬 검색(브라우저용 키)을 쓸지, 지도에서 핀을 찍게 할지, 지역 4개 중 고르게 할지.
4. **카드 수**: 3장 고정인지, "다른 거 보기"로 더 보여줄지.
5. **"예약 찾아보기" 대상**: 클룩과 마이리얼트립 중 하나로 할지, 둘 다 보여줄지.
