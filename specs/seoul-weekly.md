## 후보 추출

1. **거르기(스크립트, `scripts/seoul-weekly/collect.mjs`)**: 글 날짜가 수집일 21일 전부터 수집일까지인 글만 남긴다(블로그 `postdate`, 뉴스 `pubDate`). 같은 링크·같은 제목(공백·기호 뺀 것)은 하나로 합친다. 제목·요약은 태그와 HTML 엔티티를 벗긴 글자만 둔다. 결과 `raw-01.json`.
2. **옮겨 적기(하위 에이전트, 한 번)**: `raw-01.json`의 제목·요약에서 행사·가게 하나하나를 후보로 옮긴다. 글에 있는 말만 쓴다(모르는 칸은 비움, 바깥 검색 금지). 같은 것은 하나로 합치고 그 글 번호를 모두 단다. 결과 `candidates-01.json`.
3. **근거 붙이기(스크립트, `scripts/seoul-weekly/enrich.mjs`)**: 후보마다 네이버 블로그를 이름으로 한 번(최신순 10건, 제목·요약·날짜) 묻고, 카카오 로컬로 장소를 한 번(필요하면 이름으로 한 번 더) 묻는다. 주소가 「서울」로 시작하는 첫 결과만 받는다. 결과 `judge-input-01.json`.

## 필드 (`data/seoul/weekly-seoul.json`의 `items[]`)

| 칸 | 뜻 |
|---|---|
| `id` | `wk-` + 카카오 장소 id + 시작일(같은 곳의 다른 회차를 가른다) |
| `name` | 이름(글에 적힌 대로) |
| `kind` | `팝업` · `새로 연 곳` · `전시` · `마켓` · `축제` |
| `start`·`end` | `YYYY-MM-DD`. 새로 연 곳은 `start` = 문 연 날, `end` = 문 연 날 + 27일(4주 동안만 「새로」) |
| `time` | 여는 시간(글에 있으면 `11:00~20:00` 꼴, 요일 묶음 허용 — `culture.ts parseCultureTime`이 읽는 꼴), 없으면 `''` |
| `place`·`lat`·`lng`·`kakao` | 카카오 장소 이름·좌표(소수 다섯째 자리)·카카오맵 링크 |
| `src` | 출처 글 링크(판정이 고른 대표 글 하나, https) |
| `reserve` | `none`(예약 없이) · `onsite`(현장 대기·현장 접수) |

## 앱

- `src/weekly.ts`(문화 청크): 자료를 그날 목록의 항목(`CultureItem` + `week` 칸)으로 바꾼다. `end`가 오늘보다 앞이면 넣지 않는다. 그날 서울시·KOPIS 목록에 같은 이름(공백 뺀 것)이 있으면 넣지 않는다.
- `browse.ts`: 선반 키 `week`. 채우는 순서(`SHELVES`)는 무대·오늘만·전시보다 앞이라 이번 주 항목은 이 선반만 가진다. 지금 열림은 `openNow`(기간·시간, 시간 없으면 시간대 규칙). 「동네」 시트에는 넣지 않는다(출처가 섞이지 않게).
- **시간대 순서표 안 자리**:

| 시간대 | 순서 |
|---|---|
| morning | g2, g1, **week**, hood, g5, g4, today, g7, stage, g6, exhibit |
| day | **week**, hood, g4, g5, g7, g1, today, stage, g2, g6, exhibit |
| dusk | g1, hood, **week**, stage, g7, g2, g4, g5, g6, today, exhibit |
| night | stage, g7, g2, **week**, g1, g5, hood, g4, g6, today, exhibit |
| late | g5, g2, g1, g7, hood, stage, **week**, g4, g6, today, exhibit |

- **카드**: 그날 목록 카드와 같다(그림이 없으면 종류 글자 카드). 줄은 `whyNow`(「일요일까지 · 지금 열림 · 20:00까지」). 노선색은 오늘 행사(보라)와 같다.
- **카드 시트**: 이름·장소, 왜 지금, 기간(「11.1~11.16」), 오늘 시간(읽히면), 현장 대기면 「현장 대기가 있을 수 있어요」, 거리, 길찾기, 「출처 글 보기」(src). 출처 줄 「정보: 네이버 블로그·뉴스 · 장소: 카카오맵」.
- **끝난 것**: `end` < 오늘이면 항목이 생기지 않는다. 시작 전이면 `openNow`가 닫힘으로 본다.

## 갱신

- 이번(첫 회): 2026-11-05 손으로 한 번. collect → 옮겨 적기 → enrich → 판정 → 감사 → `ship.mjs`. 폴더 `apps/web/review/seoul-weekly/`의 파일 이름 끝 번호(`-01`)가 회차다.
- 다음부터(주인 몫): 매주 한 번(목요일 아침 권장) 같은 순서를 새 회차 번호로 돌린다. 클라우드 주기 실행으로 옮기려면 그 환경에 NAVER_CLIENT_ID·NAVER_CLIENT_SECRET·KAKAO_REST_API_KEY를 두고, 판정·감사를 맡을 Claude Code 실행 경로를 정해야 한다. 새 회차마다 기준(`criteria-NN.md`)과 검색어 표를 먼저 커밋하고, 감사 게이트를 통과해야 배포한다.
