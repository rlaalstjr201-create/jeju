# Light Spec: 비 오는 날 → 실내만

근거: ADR-0065. 부품은 기준 시트 `얼마나`(ADR-0060)를 그대로 쓴다.

## 동작

- 기준 시트 `얼마나` 무리 아래 무리 제목 `날씨`, 가는선 줄 하나 `비 와요(실내만)`(`button.opt`, `data-indoor`, `aria-pressed`). 켜면 이름 600 + 체크. 기본 꺼짐.
- 누르면 켜고/끄고 세션에 저장, 시트 닫힘(history 균형), 결과 화면이면 새 요청 id로 같은 기분을 새로 뽑는다. 저장한 곳은 요청 없음. 400ms 재탭 무시.
- 켜져 있으면 모든 기분·탭(식사·카페·디저트·섞어서·구경·체험·아무거나)의 후보 = 그 목록의 `indoor: true`. 정렬(점수 → 이동 시간 → id), 범위, 넓히기, 로테이션은 같다.
- 넓히기: 범위 안 실내가 3곳 미만이면 섬 전체 실내 중 가까운 3곳. 섬 전체 실내가 3곳 미만인 목록(걷기)은 구경 실내를 함께 후보로 삼는다. 아무거나는 같은 곳이 두 번 나오지 않는다.
- 토글을 바꾸면 로테이션 기록은 처음부터(범위를 바꿀 때와 같음).
- 켜져 있을 때만 결과 카드 메타 줄 앞에 `실내`. 묶인 줄 카드(메타 없음)는 메타 줄에 `실내`만.
- 세션 저장 `jeju.indoor`(true일 때만, 끄면 지움). 결과 세션 기록에 `indoor`(로테이션이 속한 값). 백업 링크는 켜져 있으면 `#s=…&r=1`, 열면 그 세션은 켜짐.
- 사용 기록 `indoor: true`(꺼져 있으면 필드 없음, `specs/usage-events.md`).

## 데이터

- `indoor`: 카페·식당 → true, 단 `review/copy/indoor.json`에 판정이 있으면 그 값. 관광지·체험·문화공간은 `indoor.json`의 판정(근거 포함)이 있어야 한다.
- 애매하면 false(실외 중심 + 일부 실내, 동굴, 잠수함, 하우스 농장, 노천·정원·농장 중심 카페).
- `scripts/indoor.mjs`: 출하본에 직접 적용(`bookable` 바로 뒤에 `indoor`만 더함), 다시 돌려도 같음. `build-spots.mjs`도 같은 함수를 쓴다.

## 성공 기준

- I1: 2,955곳 모두 `indoor` boolean, 관광지·체험·문화공간 판정에 근거 문장, 실내 2,080 / 실외 875.
- I2: 토글을 켠 채 15지역 × 3범위 × 8목록(쉬기·걷기·섞어서·구경·체험·식사·카페·아무거나)에서 서로 다른 3장, 모두 실내(빈손 0). 범위 안 실내 후보가 3곳 이상이면 범위 밖 카드 0.
- I3: 기본 꺼짐, 꺼져 있으면 카드가 토글 전과 같다. 첫 화면 버튼 수·첫 탭 흐름 불변.
- I4: 토글 history 균형·두 번 탭·새 요청·세션 기억·새로고침 복원·백업 링크 테스트 통과. 320/390 기준 시트·결과 가로 넘침 0, 토글 누름 영역 ≥ 48, `실내` 라벨은 켜졌을 때만.
- I5: 기존 tsc·vitest·build·check:slop·e2e 통과.
