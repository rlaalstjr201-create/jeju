# Light Spec: 날짜 모드 (약식 플래너)

근거: ADR-0059. 권위: 이 문서 + `apps/web/design/SPEC.md`. 충돌 시 이 문서가 날짜 모드에 한해 우선하고, SPEC에 반영한다.

## 목표

첫 화면은 늘 "지금 여기". 필요할 때만 날짜를 골라 그날 갈 곳을 모아 두고, 저장 목록에서 날짜별로 순서를 정한다. 계획 세우기를 강요하지 않는다.

## 흐름

1. **기준 시트**(상단 기준 라벨 탭)에 `언제` 묶음을 위에 더한다: `지금`(기본) / `내일` / `날짜 고르기`(네이티브 `<input type="date">`, 오늘 이후만). 아래 기존 `어디` 묶음(지금 있는 곳 / 숙소 / 지역 15곳)은 그대로.
2. **기준 라벨**: 지금이면 기존과 같다(`여기 근처`). 날짜를 고르면 앞에 날짜를 붙인다: `내일 · 애월 근처`, `10월 3일 · 숙소 근처`.
3. **카드**: 추천 로직은 날짜와 무관(운영시간·날씨 데이터 없음, ADR-0027). 출발지만 고른 위치.
4. **하트**: 현재 기준 날짜에 보관한다. 지금 모드는 오늘. 같은 곳을 다른 날에 또 담을 수 있다. 하트 채움은 "현재 날짜에 담겼는가" 기준.
5. **저장 목록**(♥N): 담긴 것이 있는 날짜만 구역으로 묶는다. 순서: 오늘 → 이후 날짜 오름차순 → 맨 아래 `지난 날`(접힘, 펼치기 가능).
   - 구역 머리: `오늘`, `내일`, `10월 3일 금요일`.
   - 줄마다: 이름·이동 문구(출발지는 그날 기준이 아니라 현재 기준), `위로`/`아래로`(첫·끝 줄은 숨김), `다른 날로`(시트: 담긴 날짜들 + 날짜 고르기), 하트(빼기).
   - 날짜 안 순서는 사용자가 정한 순서. 기존 "가까운 순" 정렬 라벨은 없앤다.
   - ♥N은 오늘 이후(지난 날 제외) 전체 수.
6. **날짜 유지**: 고른 날짜는 기억한다. 날이 바뀌어 고른 날짜가 오늘이 되면 `지금`으로, 지나면 `지금`으로 되돌린다.

## 데이터

- 새 저장 키 `jeju.saved.v2`: `{ id, date: 'YYYY-MM-DD', order }[]`. 로컬 날짜(Asia/Seoul) 기준.
- 이전 키 `jeju.saved`(id 배열)는 첫 로드 때 오늘 날짜로 옮기고 순서 유지. 옛 키는 지우지 않는다(되돌리기 대비).
- 기준 날짜는 기존 기준 저장과 같은 곳에 `when: 'now' | 'YYYY-MM-DD'`.
- 저장소 실패 시 메모리로 동작하는 기존 규칙 유지.

## 범위 밖

여행 기간 입력, 일차 탭, 시간대, 동선·지도 경로, 끌어서 옮기기, 날짜별 추천 차이, 공유·내보내기.

## 성공 기준

- D1: 첫 화면·첫 탭 흐름은 날짜 모드 추가 전과 같다(첫 화면 인터랙티브 요소 수 불변).
- D2: 기준 시트에서 내일/날짜를 고르면 라벨에 날짜가 붙고, 하트가 그 날짜에 담긴다.
- D3: 저장 목록이 날짜 구역으로 나뉘고, 위로/아래로·다른 날로·빼기가 새로고침 후에도 유지된다.
- D4: 옛 `jeju.saved` 데이터가 손실 없이 오늘 구역으로 옮겨진다.
- D5: 자정이 지나면 지난 날짜 기준은 `지금`으로 돌아가고, 지난 담기는 `지난 날`에 모인다.
- D6: history 균형·두 번 탭·오프라인 등 기존 QA 속성과 e2e·vitest·check:slop 전부 통과, 320/390/430 × 라이트·다크 넘침 0, 탭 대상 ≥44px, 대비 AA.
