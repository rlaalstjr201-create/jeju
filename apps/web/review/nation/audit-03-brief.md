# 자동 지역 표본 판정 안내 (audit-03, 판정자용)

여행 앱 「여차나」는 여행자에게 「지금 주변에서 놀러 갈 만한 곳」을 보여 준다. 길찾기만 붙은 카드라서, 예약 없이 가면 할 수 없는 곳이 나오면 여행자가 헛걸음을 한다. 아래 장소마다 **예약 없이 가서 할 수 있는 곳인지** 정해 주세요. 장소 이름·주소·종류·분류 이름과 당신의 일반 지식으로만 판단하고, 웹 검색은 하지 마세요.

## walkin

- `true` 예약 없이 가는 곳: 현장에서 표를 사거나 그냥 들어가서 할 수 있다. 입장하는 목장·농장·동물농장, 레일바이크, 케이블카, 루지·카트·코스터, 테마파크·워터파크·동물원, 스키장·썰매장·빙상장, 유람선, 낚시터·방파제·갯바위, 계곡, 자전거길·대여소, 현장 입장 체험관.
- `false` 예약해야만 할 수 있는 곳: 운영자가 정한 시간의 수업·강습·프로그램·출항으로만 할 수 있다. 공방·만들기·요리 클래스, 다이빙·서핑·요트·패러글라이딩 강습이나 투어, 배낚시·선상낚시, 템플스테이·사찰 체험, 체험마을·어촌·농촌 체험 프로그램, 골프장.
- 둘 다 말할 수 있으면(현장 매표가 있고 일부 프로그램만 예약) 그곳에 간 사람이 예약 없이 할 수 있는 일이 있는지로 본다. 있으면 `true`.
- 확신이 없으면 `unsure: true`를 붙이세요. 그래도 가장 그럴듯한 답은 적어 주세요.

## 출력

입력과 같은 순서의 JSON 배열 하나:

```json
[{ "id": "nt-…", "walkin": true, "unsure": false },
 { "id": "nt-…", "walkin": false, "unsure": true }]
```
