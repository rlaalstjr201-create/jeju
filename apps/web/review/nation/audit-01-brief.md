# 자동 지역 표본 판정 안내 (audit-01, 판정자용)

여행 앱 「여차나」는 여행자에게 「지금 주변에서 할 만한 곳」을 기분별로 보여 준다. 아래 장소마다 세 가지를 정해 주세요. 장소 이름·주소·종류와 당신의 일반 지식으로만 판단하고, 웹 검색은 하지 마세요. 확신이 없으면 `unsure: true`를 붙이세요(그래도 가장 그럴듯한 답은 적어 주세요).

## 1. keep: 여행자가 일부러 찾아갈 만한 곳인가

뺄 곳(`keep: false`): 숙박·야영장, 주점, 주민 편의시설(도서관·문화원·체육시설·학교), 교통시설, 전국 체인 지점, 작은 사당·비석처럼 여행자가 일부러 찾지 않는 곳, 낚시터·저수지.

## 2. mood: 그곳에서 주로 무엇을 하나 (keep일 때)

| 값 | 뜻 |
|---|---|
| `food` | 먹고 마시는 곳(식당·카페·빵집) |
| `walk` | 걷거나 자연을 보는 것이 주인 곳: 산·숲·계곡·폭포·해변·섬·호수·공원·수목원·둘레길·전망대·성곽길·골목길·등대·포구 |
| `new` | 보고 배우거나 해 보는 곳: 박물관·미술관·전시관·공연장·유적·고궁·사찰·테마파크·동물원·시장(구경), 체험·레포츠·온천·찜질방(해 보기) |

둘 이상에 걸치면 그곳에서 가장 오래 하는 활동 하나를 고른다.

## 3. indoor: 비 오는 날 가도 거의 젖지 않는가 (keep일 때)

- `true`: 거의 모든 시간을 건물 안에서 보낸다(식당·카페·박물관·전시관·공연장·실내 체험·찜질방).
- `false`: 밖에서 보내는 시간이 크다(자연·공원·유적지·사찰·시장 골목·야외 레포츠·테마파크).

## 출력

입력과 같은 순서의 JSON 배열 하나:

```json
[{ "id": "nt-…", "keep": true, "mood": "walk", "indoor": false, "unsure": false },
 { "id": "nt-…", "keep": false, "unsure": false }]
```
