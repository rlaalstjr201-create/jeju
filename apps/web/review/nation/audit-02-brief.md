# 자동 지역 표본 판정 안내 (audit-02, 판정자용)

여행 앱 「여차나」는 여행자에게 「지금 주변에서 할 만한 곳」을 기분별로 보여 준다. 아래 장소마다 정해 주세요. 장소 이름·주소·종류와 당신의 일반 지식으로만 판단하고, 웹 검색은 하지 마세요. 확신이 없으면 `unsure: true`를 붙이세요(그래도 가장 그럴듯한 답은 적어 주세요).

## 1. keep: 여행자가 일부러 찾아갈 만한 곳인가

뺄 곳(`keep: false`): 숙박·야영장, 주점, 주민 편의시설(도서관·문화원·체육시설·학교), 교통시설, 전국 체인 지점, 작은 사당·비석처럼 여행자가 일부러 찾지 않는 곳, 민물 낚시터·저수지, 그리고 **예약해야만 할 수 있는 체험**(4절의 `walkin: false`에 드는 곳).

## 2. mood: 그곳에 가서 주로 무엇을 하나 (keep일 때)

그곳이 어떤 장소인가(장소 종류)로 고른다.

| 값 | 장소 종류 |
|---|---|
| `food` | 먹고 마시는 곳(식당·카페·빵집) |
| `rest` | 머물러 보는 바다·물가·전망 지점: 해변·해수욕장·항구·포구·등대·섬·호수·연못·강·폭포·기암괴석·해안 절경·전망대·타워, 공원(시민공원·근린공원·주제공원), 온천·스파·찜질방 |
| `walk` | 걷는 길과 안으로 들어가 걷는 산·숲: 산·숲·자연휴양림·수목원·국립공원·생태 습지·둘레길·골목길·성곽길·다리 |
| `new` | 놀러 가는 곳. 보고 배우는 곳(`sub: sight`): 박물관·미술관·전시관·공연장·유적·고궁·사찰·테마파크·동물원·시장. 해 보는 곳(`sub: do`): 체험·레포츠·체험목장·체험농장·유람선·스키장·썰매장, 계곡(물놀이) |

## 3. indoor: 비 오는 날 가도 거의 젖지 않는가 (keep일 때)

- `true`: 거의 모든 시간을 건물 안에서 보낸다(식당·카페·박물관·전시관·공연장·실내 체험·찜질방·온천).
- `false`: 밖에서 보내는 시간이 크다(자연·공원·유적지·사찰·시장 골목·야외 레포츠·테마파크).

## 4. walkin: 예약 없이 가는가 (`new`·`do`일 때만)

- `true`: 현장에서 표를 사거나 그냥 들어가서 할 수 있다(입장하는 목장·농장, 레일바이크, 케이블카, 루지·카트, 테마파크, 스키장·썰매장·빙상장, 유람선, 계곡, 자전거길, 현장 입장 체험관).
- `false`: 운영자가 정한 시간의 수업·강습·프로그램·출항으로만 할 수 있다(공방·만들기 클래스, 다이빙·서핑·패러글라이딩 강습, 배낚시, 템플스테이, 체험마을 프로그램, 골프장). 이런 곳은 `keep: false`로 하고 `walkin: false`도 적는다.

## 출력

입력과 같은 순서의 JSON 배열 하나:

```json
[{ "id": "nt-…", "keep": true, "mood": "rest", "indoor": false, "unsure": false },
 { "id": "nt-…", "keep": true, "mood": "new", "sub": "do", "walkin": true, "indoor": false, "unsure": false },
 { "id": "nt-…", "keep": false, "walkin": false, "unsure": false }]
```
