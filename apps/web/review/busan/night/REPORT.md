## 회차 01 (2026-10-20) — 통과 못 함

결론: 사전등록 기준(`criteria.md`, 2de06fe)을 넘지 못했다. 일치율은 기준을 넘었지만, 「첫 판정 true → 다시 판정 false」의 허용 수가 0인데 1곳이 나왔다. 그래서 `trail`은 붙이지 않았다.

| 단계 | 파일 | 수치 |
|---|---|---|
| 후보 | `candidates.json` | 204곳(걷기 87) |
| 1차 판정(판정자 둘이 반씩) | `trail-01.json` | true 17 |
| 블라인드 표본 | `audit-01-sample.json` | 한쪽 k=17, 34곳, 씨앗 20261020 |
| 다시 판정 | `audit-01.json` | 33/34 = 97.1%(기준 ≥ 95%) |
| true→false | `audit-01.json` | 1곳(허용 ⌊3k/60⌋=0) → 통과 못 함 |

- 어긋난 곳: `bs-3027098` 금정산성 동문. 1차는 true(「주능선 고개에 위치」), 다시 판정은 false(「산성 문루 하나」)였다.
- 가설(확인하지 않음):
  - 정의의 「산성 길」이 성곽을 따라 걷는 길과 성문 하나를 가르지 못했다.
  - 한쪽이 17곳이라, 제주 비율(60곳 중 3)을 소수점 아래 버림하면 허용이 0이 됐다.
- 이 회차는 기준을 고쳐서 통과시키지 않는다. 다시 판정하려면 주인 승인을 받은 뒤 새 회차로만 한다.
