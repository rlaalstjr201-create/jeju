# 밤 산길 부산 회차 02 — 사전등록 (2026-10-20, 판정 전)

근거: ADR-0091, `criteria.md`(회차 01). 회차 01은 일치율 33/34(97.1%)였으나 true→false 1 > 허용 0으로 통과하지 못했다(`audit-01.json`, 어긋난 곳은 산성 문 하나). 주인이 2026-10-20 채팅에서 선택지 (가) 「정의를 다듬어 새 사전등록 회차」를 승인했다(「가로 진행해」). 결과 생성 실행이라 **한 번만** 돈다. 못 넘으면 붙이지 않고 수치와 가설을 적고 멈춘다(회차 03은 주인 승인 뒤에만). 판정을 본 뒤 이 파일을 고치지 않는다.

**회차 01과 다른 것은 2절 정의의 한 줄과 3절 씨앗뿐이다.** 후보·방법·통과 기준은 `criteria.md` 그대로.

## 1. 후보 (회차 01과 같음)

- `review/busan/night/candidates.json`(회차 01 커밋 067bc2f 그대로, 204곳, 걷기 87). `public/spots-busan.json`은 그 뒤 장날 필드 등으로 해시가 바뀌었지만, `node scripts/busan/night.mjs --candidates`를 다시 돌려도 같은 파일이 나온다(2026-10-20 확인, git diff 없음).

## 2. 판정 (`trail-02.json`)

후보 **전부**(회차 01 true만이 아니라 204곳 모두)를 새 판정자가 다시 판정한다. 꼴·근거 규칙·입력은 `criteria.md` 2절 그대로: `{ id, trail, basis }`, `basis`는 원문 그대로 40자 이내, 애매하면 `애매: `. 판정자 둘이 `candidates.json` 순서로 앞 102곳·뒤 102곳을 나눠 맡는다. 판정자는 아래 정의와 지어낸 예시만 받고, 회차 01의 판정·표본·결과·어긋난 곳을 보지 않는다.

**야외 산길**(`trail: true`): 걷는 것이 주인 곳 중, 밤에 어둡고 사람 손이 덜 닿은 자연 산길 — 산·봉우리 오르기, 숲길·숲 탐방로·자연휴양림, 계곡 탐방로, 산 위 성곽을 따라 걷는 산성 길, 산자락을 도는 둘레길.

**아님**(`false`): 해변·해안 산책로·바닷가 절벽 길·포구, 시내 공원·광장·마을 골목길, 차로 바로 닿는 전망대·타워, 정원·수목원 같은 운영 시설·테마파크, 절·사찰 경내 구경이 주인 곳, 시장·거리, 실내, 먹는 곳, **성문·문루 하나만 있는 곳(성곽을 따라 걷는 길이 아닌 곳)**. ← 회차 02에서 더한 유일한 줄(주인 승인).

지어낸 예시: `criteria.md` 2절의 9개 그대로(더하거나 빼지 않음).

## 3. 다시 판정 (블라인드, `audit-02.json`)

- 회차 01·02 첫 판정을 모두 모르는 새 판정자 하나가 표본을 판정한다. 같은 정의·예시만, 곳마다 이름과 원문만. `[{ id, trail, reason }]` → `audit-02-judgments.json`.
- 표본: 한쪽 **k = min(60, true 수, false 수)**, true에서 k + false에서 k, **씨앗 `2026102002`**(mulberry32, `drawSample` 그대로; `scripts/busan/night.mjs` `SAMPLE_SEEDS['02']`). `node scripts/busan/night.mjs --sample`.
- **통과 기준(회차 01과 같음)**: 2k곳 일치율 ≥ 95%, 그리고 첫 판정 true k곳 중 다시 판정 false ≤ ⌊3k/60⌋(k < 20이면 0). `node scripts/busan/night.mjs --score`.
