# 서울 즐길 거리 기준 08 (감사 07 미달 뒤, 2026-11-05 주인 「2번으로 … 그걸로 가자」) — 실행 전 고정

criteria-07.md 1~3·5·7절은 그대로. 판정에 근거를 더하고 다시 판정한다.

## 1. 근거 모으기 (`evidence.mjs`, 네이버 검색 API 블로그, 한 번)
- 판정 입력 1,033곳마다 한 번: 검색어 「<이름> <구 이름에서 '구'를 뗀 것>」(예: 「콜트레인 마포」), 최신순 5개.
- 남기는 것: 전체 글 수(total), 최신 글 5개의 날짜(postdate)와 제목(태그 뺌). 본문 요약·글쓴이·주소는 남기지 않는다. 판정용 내부 자료이고 앱에 싣지 않는다.
- 실패하면 두 번까지 다시, 그래도 실패면 근거 없음으로 둔다.

## 2. 판정 08 (새 Opus, 한 번, 07 판정을 보지 않음)
- criteria-07.md 4절 질문에 근거를 더해 묻는다. 더하는 규칙:
  - 최신 글이 2025-11-05보다 앞이거나 글이 없으면 keep: false(문을 닫았거나 아무도 가지 않는 곳으로 본다).
  - 제목들이 다른 곳·다른 뜻(같은 이름의 다른 가게, 노래 제목 등)만 가리키면 이 곳의 근거로 쓰지 않는다.
  - 이름에 날짜가 붙은 한때 행사·이미 끝난 팝업은 keep: false.
- 판정 08이 07을 대신한다(07은 기록으로만 남김).

## 3. 감사 08 (또 다른 새 Opus, 한 번)
- 씨앗 20261106으로 keep 100곳, drop 50곳을 뽑아, 같은 근거를 주고 판정 칸 없이 다시 묻는다.
- keep 일치 90% 이상이면 출하. 갈래별로 keep 표본이 10곳 이상이고 일치 80% 미만인 갈래는 싣지 않는다.
- 못 미치면 출하하지 않고 주인에게 보고한다.
