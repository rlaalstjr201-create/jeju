# S9-3 충실성 감사 (faithfulness audit)

기준: plans/tomorrow-picker.md S9-3, design/SPEC.md §10. 원문에 없는 내용 비율 ≤ 2%.
상세 결과: `s9-3-faithfulness.json`

## 방법

- 모집단: `public/spots.json` 2,959곳의 `reason`.
- 층화: mood/sub 5층. 각 층 5% 올림(ceil). spots를 id로 정렬한 뒤 층마다 `random.Random(93).sample`, **seed = 93**.

| 층 | 모집단 | 표본 |
|---|---|---|
| food/cafe | 397 | 20 |
| food/meal | 1,281 | 65 |
| new | 509 | 26 |
| rest | 317 | 16 |
| walk | 455 | 23 |
| 합계 | 2,959 | 150 (5.07%) |

- 추가: `review/copy/fix-02.json` 21건 전부. spots.json의 reason과 21건 모두 일치함을 확인. 표본과 1건(농업회사법인 한울제주)이 겹쳐 **고유 n = 170**.
- 대조 원문: `review/input/batch-*.json`의 summary, comment, intro, tags, area, 좌표.
- 판정: faithful는 모든 주장에 원문 근거가 있는 경우. unfaithful는 원문에 없는 사실, 틀린 음식·특징, 과장이 하나라도 있는 경우. borderline는 근거는 있지만 연결 방식이나 수식어가 원문보다 조금 더 나간 경우.

## 결과

| 구분 | n | faithful | borderline | unfaithful | unfaithful 비율 |
|---|---|---|---|---|---|
| 층화 표본 | 150 | 145 | 5 | 0 | 0.0% |
| fix-02 | 21 | 21 | 0 | 0 | 0.0% |
| 전체(고유) | 170 | 165 | 5 | 0 | **0.0%** (한도 ≤ 2%) |

**통과.** unfaithful가 0건이라 전 항목 검사나 되돌리기는 필요 없다. 보수적으로 borderline 5건을 모두 unfaithful로 쳐도 표본 비율은 5/150 = 3.3%로, 그 경우에만 한도를 넘는다.

## 참고 (faithful로 판정했지만 기록할 점)

- 아리: 이유 문장의 '서흘동'은 태그 표기를 따른 것이다. summary에는 '서흥동'으로 되어 있어 원문 자체의 표기가 서로 다르다.
- 바람카페 '최고령 곰솔나무', 성이시돌목장 '국내 최대 규모', 오레브 '제주 유일 보양온천', 청수곶자왈 '가장 많이': 모두 원문에 있는 최상급 사실을 옮긴 것이라 과장으로 보지 않았다.
