## 왜 이렇게 했나

감사에서 AI가 만든 느낌을 준 원인은 세 가지였다. 베이지에 청록을 얹은 색, 기분 버튼과 장소 카드가 같은 테두리·그림자·라운드를 입은 것, 같은 틀로 찍힌 카드 세 장. 이 시안은 셋을 모두 뺀다.

1. **역할마다 재질 하나.** 누르는 것은 회색 면(`--fill`)이나 구분선만 쓴다. 읽는 것(장소)은 사진과 글자뿐이고 상자가 없다. 떠 있는 것은 시트 하나이고 이것만 `--surface`와 둥근 윗모서리를 쓴다. 그림자는 어디에도 없다.
2. **색은 두 역할뿐.** 먹색(`--sel-bg`)은 '지금 선택된 것', 동백 빨강(`--accent`)은 '내가 남긴 것'. 거리·링크·메타·아이콘은 무채색이다.
3. **첫 장은 크게, 나머지는 `아니면`.** 가까운 첫 곳은 3:2 사진으로 화면의 색을 맡고, 둘째·셋째는 작은 사진을 둔 줄로 훑는다. 똑같은 카드 격자가 아니라 "여기 가 봐, 아니면…"으로 읽힌다.
4. **질문은 접는다.** 기분을 고르면 질문과 목록이 한 줄 제목(`새로운 거 해보고 싶어 · 바꾸기`)이 되고 카드가 바로 온다. 320×568에서도 첫 장 이름이 y=324다(감사 당시 y=590).
5. **어디서부터 몇 분인지 적는다.** `애월에서 차로 약 5분`. 세 장이 같으면 한 번만(`셋 다 애월에서 차로 약 5분`). 섬이면 분 대신 `우도라서 배를 타야 해요`.
6. **밤이 기본.** 다크는 순검정이 아닌 #151718, 사진 밝기 0.9, 선택색은 밝은 막대가 아닌 중간 회색.

## 간격

단계: 2 · 4 · 8 · 12 · 16 · 20 · 24 · 28. 묶음 안은 2~12, 묶음 사이는 20~28. 테두리와 그림자 대신 간격이 묶음을 만든다.

- 앱 최대 폭 480, 좌우 여백 16(safe-area 반영), 아래 28.
- 첫 화면: 위 빈칸 : 아래 빈칸 = 5 : 2. 질문과 기분 목록이 엄지 쪽에 앉는다. 첫 기분 줄 윗변 390×844 y=415, 320×568 y=218, 430×932 y=478.
- 결과: 상단 줄 → 제목 4, 제목 → 탭 4, 상태 줄 위 12, 첫 카드 위 20, 사진 → 이름 12, 이름 → 이유 2, 이유 → 메타 4, 첫 장 → `아니면` 28, `아니면` → 줄 카드 12, 줄 카드 사이 20, 마지막 카드 → 버튼 28.
- 줄 카드: 사진과 글 사이 12. 하트는 이름 첫 줄에 맞춰 `margin: -10px -10px -10px 0`.
- 시트: 안쪽 24/16, 제목 → 칸 16, 무리 제목 위 24 아래 8, 칸 사이 8.

실측(프로토타입, 크롬): 첫 장 이름 윗변 390 y=371, 320 y=324(메타 아랫변 425), 식사 탭이 있으면 +49. `다른 3곳 보기`는 모든 폭에서 첫 화면 안(390 y=780~832, 320 y=504~556).

## 부품

**상단 줄.** sticky, 높이 52, 바탕 `--bg`, 선 없음. 왼쪽 기준 버튼(`애월 근처` + 아래 꺾쇠, 15/600, 높이 44, 왼쪽 -8로 글자를 여백 선에 맞춤). 오른쪽 ♥ N(저장 1개 이상일 때만, 채운 하트 16 + 숫자, 저장한 곳 화면에서 `aria-pressed="true"` + `--fill` 면). `flex-wrap`이라 글자가 커지면 줄이 바뀌고 버튼 자체는 부풀지 않는다.

기준 라벨: `내 주변` / `숙소 근처` / `{지역} 근처` / 권한 거절을 안 뒤에는 `지역 고르기`. 카드 메타의 출발지는 `여기서` / `숙소에서` / `{지역}에서`.

**첫 화면.** 날짜(`10월 1일 목요일`, 04시 전이면 오늘) → 질문 → 기분 줄 4개(높이 60, 17/600, 오른쪽 꺾쇠, 줄 사이 16px 들여 쓴 1px 선, 누르면 `--fill` 면, 틀 없음) → 떨어진 밑줄 글자 버튼 `아무거나 골라줘`(높이 48). 지난번 고른 기분은 꺾쇠 대신 체크와 `aria-current`.

**결과 머리.** 제목(고른 기분 문구) + 오른쪽 `바꾸기`(15/600 `--text`). 먹기일 때 아래에 글자 탭 `식사 | 카페·디저트`: 선택 탭은 `--text` + 글자 폭 2px 밑줄, 다른 탭은 `--muted`, 탭 줄 아래 1px 선. 알약·면 없음.

**첫 장.** 사진 3:2(radius 12) → 이름 20/700 + 하트 → 이유 15 → 메타 15 muted `{출발지 붙은 이동 문구} · 카카오맵` → (예약 가능한 곳만) `마이리얼트립에서 예약 찾아보기` 15/600 높이 44.
**아니면.** 15 muted 한 낱말.
**줄 카드.** 정사각 사진(`--thumb`, radius 8) 옆에 이름 17/600 + 하트, 이유, 메타(`차로 약 10분`, 출발지 없이). 세 장이 같은 이동 문구면 줄 카드에는 메타 줄이 없다. 좁은 폭(컨테이너 20em 미만, 글자 200% 포함)에서는 사진이 위로 가고 2:1.
**카드 전체가 지도 링크.** 이름의 `<a>`를 `::after { inset: 0 }`로 카드 전체에 편다. 하트와 예약 링크만 그 위(`z-index: 1`). 키보드 포커스 링은 카드 전체에 2px, offset 4. 누르는 동안 사진·이름 투명도 .72.
**하트.** 44×44, SVG 22, 빈 상태 `--muted` 선 1.8, 저장 `--accent` 채움. `aria-label="{이름} 저장"` 고정, 상태는 `aria-pressed`로만. 누르면 그 하트와 ♥ N만 바뀐다(카드를 다시 그리지 않아 사진이 깜빡이지 않는다). 토스트·폭죽 없음.
**사진 실패.** 사진 칸을 통째로 빼고 글 카드로. 회색 빈 상자를 남기지 않는다(`#noimg`).

**다른 3곳 보기.** 폭 100%, 높이 52, radius 10, `--fill`, 17/600 `--text`. 띠(`--bg`, 위아래 12)에 담겨 `sticky; bottom: 0`. IntersectionObserver로 띠 아래 1px 표지가 화면 밖일 때만 띠 위에 `--line`. 누르면 같은 기분의 다음 3장, 등장 애니메이션 없음, 제목이 화면 위로 나갔으면 즉시 제목으로 스크롤, 포커스는 제목. 400ms 안의 두 번째 탭은 무시. 한 바퀴 돌면 상태 줄에 안내.

**상태 줄.** `role="status"`, 15 muted, 비면 숨김. `위치 확인 중…` 옆에 밑줄 글자 버튼 `지역으로 고르기`(높이 44).
**회색 틀.** 첫 장(3:2 면 + 막대 3) + 줄 2개. 움직임 없음, `aria-hidden`. 300ms 넘을 때만.
**결과 자리 안내.** 시트를 저절로 띄우지 않고 카드 자리에 그린다. 제목 17/600 + 설명 15 muted + 지역 무리(권한 거절·위치 실패·제주 밖) 또는 `다시 불러오기`(목록 실패) + 권한 켜는 방법 한 줄.
**지역 칸.** 기본 4열(`repeat(auto-fill, minmax(max(4em, (100% - 24px)/4), 1fr))`, 제주시 8 = 4+4, 서귀포 7 = 4+3), 글자가 커지면 2열·1열. 높이 48, `--fill`, 15/600, 왼쪽 정렬. 선택 칸만 `--sel-bg`. 서→동 순서, 첫 무리 제목 줄 끝에 `서쪽부터`.

**기준 시트.** 딤 + 아래 붙은 시트(최대 88dvh, 안에서만 스크롤, 손잡이 막대 없음). 제목 `어디 근처로 볼까요?` → `내 위치` | `숙소(동네 이름)` 두 칸(높이 60) → `숙소 다시 정하기` → 지역 무리 둘 → 아래 붙는 `닫기`(높이 56, 위 1px 선). 열린 동안 `#app`에 `inert`, 문서 스크롤 잠금, 포커스는 선택된 칸. `닫기`·딤·Esc로 닫고 포커스는 연 버튼으로. 등장 240ms `cubic-bezier(.2,.8,.2,1)`, 퇴장 190ms.
**숙소 시트.** 제목 `숙소가 어디예요?` + `한 번 정하면 이 기기에 기억해 둘게요.` → `지금 위치를 숙소로`(`--fill`, 높이 48; 누르면 `위치 확인 중…` + disabled; 실패 사유는 버튼 아래 별도 줄) → 지역 무리. 확인 중에 시트가 닫히면 결과를 버린다(기준이 몰래 바뀌지 않는다).

**저장한 곳.** 상단 줄은 그대로(♥ N 눌림). 제목 `저장한 곳 2` + `돌아가기` → 정렬 문장(`애월에서 가까운 순이에요.`) → 줄 카드만, 모든 줄에 출발지 붙은 메타 → `이 브라우저에만 저장돼요.` 열 때의 목록을 스냅숏으로 써서 하트를 풀어도 줄이 남는다(되돌리기).

**아이콘.** 인라인 SVG만: 아래 꺾쇠 16, 오른쪽 꺾쇠 18, 체크 18, 하트 16/22. 유니코드 기호(⇄ ↗ ♥)와 이모지 없음.

**움직임.** 시트와 딤만 움직인다. 면 버튼 누름 `scale(.98)` 120ms, 하트 아이콘 `scale(.88)`. 카드 등장·전환 애니메이션 없음. 전부 `prefers-reduced-motion: no-preference` 안에만 있다.

## 실제 앱으로 옮길 때

- `다른 3곳 보기` 띠: `.more-bar { position: sticky; bottom: 0; background: var(--bg) }` + 띠 바로 뒤 1px 표지를 IntersectionObserver로 보고 `.stuck`을 토글(스크롤 핸들러 없음). 띠 z-index 2는 카드 하트(1)보다 위, 시트(10)보다 아래.
- 요소 id가 상태 해시와 같으면 브라우저가 그 요소로 스크롤한다(프로토타입에서 `#sheet`로 겪음). 앱에서 해시를 쓰게 되면 id와 겹치지 않게 한다.
- 첫 화면 질문과 기분 목록은 `index.html`에 정적으로 둔다(JS 전에 보이게). 프로토타입은 편의상 JS로 그린다.
- 프로토타입은 이미지를 모두 즉시 받는다. 앱은 줄 카드에 `loading="lazy"`.
- 프로토타입 데이터는 애월 근처뿐이라 다른 지역을 고르면 같은 곳이 먼 이동 시간과 함께 나온다(이동 문구 계산을 보여 주는 용도).

## 사용자 확인이 필요한 것

1. **떠 있는 `다른 3곳 보기`.** SPEC.md는 마지막 카드 아래 고정 자리였다. 이 시안은 목록이 길 때 엄지 자리에 띄운다. 스크롤하는 동안 줄 카드 아래 76px를 가린다.
2. **첫 장만 크게.** 가까운 순이라 사실과 맞지만 '정답 하나'처럼 읽힐 수 있다. 세 장 같은 무게가 ADR-0025의 뜻이면 전부 줄 카드로 바꿀 수 있다.
3. **지도 폴백.** 카카오 ID 없는 곳은 지금 앱처럼 `제주 {이름}` 이름 검색으로 열었다. 좌표 핀(`map.kakao.com/link/map/{이름},{위도},{경도}`)으로 바꾸려면 ADR-0028 수정이 필요하다.
4. **어제 고른 지역.** `애월 근처`가 다음 날에도 남는다. 상단 왼쪽 라벨로 드러내는 데서 멈췄다. 하루 지나면 `내 주변`으로 되돌릴지는 ADR-0029 해석 문제다.
5. **데이터 문장.** `겉바속촉 돈까스와 생선카츠예요.`처럼 줄임말과 비표준 표기(돈까스)가 실제 데이터에 남아 있다. 시안은 데이터를 고치지 않았다.
