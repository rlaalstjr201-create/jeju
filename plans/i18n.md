# Plan — 영어·중국어(简体)·일본어 (ADR-0093, specs/i18n.md)

## 구조

| 자리 | 파일 | 하는 일 |
|---|---|---|
| 언어 고르기 | `apps/web/index.html` `<head>` 첫 인라인 스크립트 | `?lang=` → `localStorage.lang` → 브라우저 언어. 한국어가 아니면 `<html lang>`과 `.l10n`(가림 최대 3초) |
| 불러오기 | `src/main.ts` `WORDS`·`words()` | 한국어가 아니면 그 언어 청크를 동적 import, 장소 글 `i18n/places.<lang>.json?v=__PLACES_V__`를 같이 받는다. 둘 다 앱 마운트·목록 사용 전에 끝난다. 실패하면 한국어 |
| 바꿔 끼우기 | `src/i18n/apply.ts` | 한국어 표의 내용을 그 언어 표로 바꾸고 index.html 고정 문구(`page` 표: `selector` / `selector@attr`)를 쓴다. `PLACE.name`·`PLACE.reason`을 장소 글로 감싼다 |
| 언어 표 | `src/i18n/{en,zh-Hans,ja}.ts` | `Lang` 타입이 한국어 표의 키를 모두 요구한다(빠지면 tsc 실패) |
| 한국어 표 | `render.ts` `COPY`·`MOOD_LABEL`·`PLACE`, `pick.ts` `TRAVEL_TEXT`, `dates.ts` `DAY_TEXT`, `market.ts` `MARKET_TEXT`, `season.ts` `SEASON_TEXT`, `state.ts` `FROM_TEXT`, `links.ts` `GO_TEXT`·`BOOK_TEXT`·`MAP_APP_NAME`, `areas.ts` `AREAS`·`AREA_GROUPS` | 원래 함수 안에 박혀 있던 낱말을 표로 꺼냈다. 한국어 출력은 그대로 |
| 장소 글 | `scripts/i18n-places.mjs`, `review/i18n/` | `--export`로 원문 묶음, 번역 묶음 → `public/i18n/places.<lang>.json` |
| 캐시 | `vite.config.ts` | `src/i18n/` 청크는 precache에서 뺀다. `_headers`: `/i18n/*` immutable(늘 `?v=`), `/privacy-*` no-cache |
| 스위치 | `render.ts` 홈 꼬리 `.lang-line`, `index.html` 설정 `.langs` | `/?lang=xx` 링크 |
| 글꼴·줄바꿈 | `style.css` 끝 | ja·zh-Hans: `word-break: normal; line-break: strict`, 그 언어 글꼴 |
| 개인정보 | `public/privacy-{en,zh-Hans,ja}.html` | 번역본(noindex), 한국어판이 기준. 한국어판에 「고른 언어」(기기 저장) 한 줄 |

## 검증

- `tests/i18n.test.ts`: 인라인 스크립트의 언어 고르기 표(가상 window), 세 언어 표가 한국어 표 키를 다 채우고 한글이 없음, `page` 키가 index.html에 다 맞음, 언어마다 첫 화면·카드 3장·기준 시트·저장한 곳에 한국어 UI 낱말 없음(jsdom).
- e2e `I18N-en`·`I18N-zh-Hans`·`I18N-ja`·`I18N-ko`(SPEC 15.1 39).
- 장소 글: 사전 등록 표본 검수(specs/i18n.md 6절), 결과 `review/i18n/qa/`.

- 원어민 검수(「판단」·「확인 실패」 표시 줄).
