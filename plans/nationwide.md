# Plan: 전국 확장 + 주요 도시 큐레이팅 (ADR-0101 2단계 앞당김)

주인 지시(2026-10-30 밤): 「전국 단위로 확장하고, 서울·강원 주요 관광도시는 큐레이팅까지. 자는 동안 끝까지. 권한 다 준다.」 「메인 오케스트레이터는 Opus 5.5, 역할마다 모델을 지정해 나눠서.」
근거: ADR-0101(두 층), ADR-0095(파일 파이프라인), ADR-0100(예산 60,000 B). 주인이 없는 동안 고른 기본안은 **[기본안]**으로 표시하고 아침에 주인이 뒤집을 수 있다.

## 성공 기준 (끝낼 조건)

1. **전국 자동 지역이 운영에 있다**: 제주·부산 밖 아무 좌표(전국 17개 시도)에서 위치를 켜면 그 주변 자동 지역 카드(먹기·걷기·새로운 것·아무거나)가 나온다. 위치가 없을 때는 시작 화면에서 시도 → 시군구로 고를 수 있다. 이름 줄은 시군구 이름.
2. **비 소식이 좌표로 동작**: 자동 지역에서 「비 와요 → 실내만」이 나온다(`/api/rain`이 좌표를 받음, 제주 15 slug 응답은 그대로).
3. **규칙 정확도를 사전 기준으로 쟀다**: 분류 → 기분·실내 규칙을 먼저 커밋하고, 블라인드 표본(시도 고르게 200곳)을 규칙을 모르는 판정자가 매긴 뒤 비교. 기준: 기분 일치 ≥ 85%, 실내 ≥ 90%. 못 넘으면 그 규칙은 배포하지 않고 수치·가설을 보고(재측정은 주인 승인).
4. **서울·강원 주요 도시가 검수한 곳으로 들어간다**: [기본안] 서울(25개 구 전체)과 강원 강릉·속초·양양·춘천·평창. 부산과 같은 길(수집 → 사전 기준 → AI 판정 → 표본 감사 → 카카오 대조 → 검색수 → 출하 파일). 감사 기준은 부산과 같다(keep·기분 ≥ 90%, 실내 ≥ 95%, 사실 오류 ≤ 3/120).
5. **제주·부산 그대로**: `check:jeju`가 허용 목록 밖 차이 0. 제주·부산 데이터 파일 해시 그대로.
6. **품질 문**: `tsc`, `vitest`, `check:slop` 0, e2e 전부, 한국어 진입 JS+CSS gzip ≤ 60,000 B, 375×812·320 폭 가로 넘침 0, 독립 리뷰(ADR-0058, 별도 Opus 에이전트) MAJOR 0 뒤 배포, 배포 뒤 smoke 통과.
7. 각 단계는 따로 커밋·따로 배포·따로 되돌린다.

## 현실 제약 (숨기지 않음)

- TourAPI 개발 키는 하루 1,000회(우리 상한 900). 전국 **목록**은 약 75회면 끝난다(2026-10-30 측정: 목록 기준 44,760곳. 서울 7,455·경기 9,041·강원 4,092·전남광주 3,304 등, 원자료 `review/nation/counts-2026-10-30.json`). 큐레이팅은 장소마다 **상세** 호출이 필요해 서울·강원 5개 도시는 며칠에 걸친다. 그래서 4번은 하루 할당량만큼 이어 받는 일정으로 진행하고, 수집이 끝난 도시부터 판정·출하한다.
- 표본 「사람 검수」는 주인 몫이다. 밤사이에는 판정과 다른 모델의 독립 감사로 대신하고 그 사실을 REPORT에 적는다. 주인이 아침에 표본을 볼 수 있게 `REPORT.md`를 남긴다.

|---|---|---|---|
| N1 | 전국 목록 수집 | `scripts/nation/collect.mjs`, `review/nation/raw/`(gitignore, 해시만 기록), `review/nation/scope-<시도>.json`(줄인 레코드, 커밋) | 구현: Sonnet 5.5 |
| N2 | 분류 → 기분·실내 규칙 + 측정 | `review/nation/rules-criteria.md`(먼저 커밋) → `scripts/nation/rules.mjs` → 블라인드 표본 판정 → `review/nation/rules-REPORT.md` | 규칙: Opus 5.5(총괄), 블라인드 판정: Sonnet 5.5(규칙을 모르는 별도 에이전트) |
| N3 | 출하 조각 | `public/nation/<시도>.json`(시도 단위, 쓸 때 받음, SW 미리 받기 제외) | 구현: Sonnet 5.5 |
| N4 | 앱: 자동 지역 | 위치 → 자동 지역, 시작 화면 「다른 곳」, 이름 줄 시군구, 기분 제한, 오늘 판 부분, `/api/rain` 좌표, i18n, e2e | 설계: Opus 5.5(Plan), 구현: Opus 5.5 |
| N5 | 독립 리뷰 + 배포 | `docs/reviews/nationwide-review.md`, 운영 배포, smoke | 리뷰: Opus 5.5(새 에이전트, 결론 안 줌) |
| C1 | 큐레이팅 수집(서울·강원 5도시) | `review/<dest>/raw/`, 일일 이어받기 | 구현: Sonnet 5.5 |
| C2 | 판정·감사·대조·측정 | 부산과 같은 파일들 | 판정: Sonnet 5.5, 감사: Opus 5.5 |
| C3 | 출하 + 앱에 검수한 곳으로 올림 + 리뷰 + 배포 | `public/spots-<dest>.json` | 구현: Opus 5.5, 리뷰: Opus 5.5 |

## [기본안] 목록 (주인이 뒤집을 수 있음)

- 강원 큐레이팅 도시: 강릉·속초·양양·춘천·평창(관광 수요가 큰 순).
- 공유 묶음(1b)은 전국 확장 뒤로 미룬다(주인: 「전국 확장이 먼저」).
- 자동 지역 장소 범위: 부산과 같은 범위(관광지·문화시설·레포츠·음식점 + 전통시장). 사진 없는 곳은 「지금 여기서」 후보에서 뺀다(home-v2 Q-C).
- 랜딩(`/jeju/**`·`/busan/**`)은 넓히지 않는다(ADR-0101 기본).
