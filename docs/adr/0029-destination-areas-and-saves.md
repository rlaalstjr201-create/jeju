# ADR-0029: 세부 지역(목적지) 기준 + 하트 저장

Status: Accepted (2026-09-30) — ADR-0025의 "지역 4개" 폴백을 확장

## Context

"내일 뭐하지"는 내일 갈 동네가 대충 정해진 경우가 많다(내일은 애월 쪽, 성산 쪽). 제주시/서귀포/동쪽/서쪽 4개로는 너무 넓다. 또 즉흥적으로 고르다가 "이건 나중에" 싶은 곳을 남겨 둘 방법이 없다 — 일정 짜기가 아니라 가볍게 세이브하는 정도가 필요하다.

## Decision

- **기준 위치 3가지**: 내 위치(GPS, 기본) / 숙소 / **지역(목적지)**. 위치 전환 버튼을 누르면 시트에서 고른다. 라벨 예: "애월 기준 ⇄".
- **지역 15곳** (중심 좌표는 보유 스팟 분포 기준, `plans/tomorrow-picker.md`):
  - 제주시 쪽: 구제주, 신제주, 애월, 한림, 한경, 조천, 구좌, 우도
  - 서귀포 쪽: 서귀포시내, 중문, 안덕, 대정, 남원, 표선, 성산
  - GPS를 쓸 수 없을 때도 같은 목록에서 고른다(기존 4개 대체).
- **하트 저장**: 카드 사진 오른쪽 위 하트로 저장/해제. 기기에만 저장(`localStorage`, 로그인 없음 — ADR-0026).
- **저장 목록**: 저장한 곳이 1개 이상일 때만 상단에 "♥ N" 버튼이 보이고, 누르면 저장한 카드 목록(현재 기준 위치에서 가까운 순). 0개면 버튼 없음 — 첫 화면은 그대로 조용하게.
- 일정·순서·날짜 배정은 하지 않는다(ADR-0025 범위 밖 유지).

## Consequences

- 첫 화면 요소: 기분 버튼 5개 + 위치 전환 (+ 저장이 있을 때만 ♥ N).
- 데이터가 바뀌어 저장한 id가 사라지면 목록에서 조용히 뺀다.

Updated by ADR-0058 (2026-09-30): 라벨은 "애월 기준 ⇄"가 아니라 `{지역} 근처`(GPS `여기 근처`, 숙소 `숙소 근처`), `⇄` 없음(SPEC D1). 하트는 사진 오른쪽 위가 아니라 이름 오른쪽(D3). 동네 칸에 대표 지명 15개를 보인다(D7). 어제 고른 지역 기준은 GPS로 되돌리지 않는다(D5).
