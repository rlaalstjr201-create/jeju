# ADR-0070: 색 체계 「바다·귤」: 흰 바탕과 3색, 주 버튼은 메인 색 채움

Status: Accepted (2026-10-01)

## Context

지금 색(녹회색 바탕 `#f6f6f3`, 회색 면 버튼, 빨간 하트)이 "기본값 같다"는 피드백이 있었다. `apps/web/design/palette.md`(2026-10-01)는 참고 사이트(오늘제주·마이리얼트립 등)의 실제 색을 뽑아 원칙을 세우고 후보 3개(A 바다·귤, B 유채·동백, C 오름·노을)를 비교했다. 문서의 추천은 B였지만 **사용자는 A를 골랐다.**

조건(palette.md): 흰 바탕 + 최대 3색(메인, 포인트, 글자). 회색은 새 색을 만들지 않고 글자색을 바탕에 섞어 만든다. 그라디언트·베이지·테라코타 금지.

## Decision

1. **3색과 바탕**(palette.md 3절 A 그대로).

   | 역할 | 토큰 | 라이트 | 다크 |
   |---|---|---|---|
   | 바탕 | `--bg` | `#ffffff` | `#0f1319` |
   | 메인 (바다) | `--main` | `#0a6fd6` | `#5aa9ff` |
   | 포인트 (귤) | `--accent` | `#f06400` | `#ff8a3d` |
   | 글자 (현무암) | `--text` | `#14181f` | `#eef1f5` |

   파생(글자색을 바탕에 섞음, palette.md 비교 화면 값): `--surface` `#ffffff` / `#1a1e24`, `--fill` `#f3f3f4` / `#23272d`, `--fill-press` `#e8e8e9` / `#30343a`, `--line` `#e3e3e4` / `#33373c`, `--field-line` `#8a8c8f` / `#7e8287`, `--muted` `#5f6267` / `#b0b3b7`. 메인 파생: `--on-main` `#ffffff` / `#0f1319`(다크는 밝은 바다 위라 어두운 글자), `--main-press` `#0c62bb` / `#4d8ed6`, `--main-tint`(메인 10%) `#e6f1fb` / `#1b2b3e`.

2. **역할 지도**(palette.md 4절 A).

   | 역할 | 클래스 | 색 |
   |---|---|---|
   | 바탕·상단 줄·아래 띠 | `body`, `.top`, `.more-bar` | `--bg` 흰색 |
   | 주 버튼 채움 + 글자 | `.more`, `.retry`, `.primary` | `--main` + `--on-main`, 누름 `--main-press` |
   | 선택 체크(기분·동네 색인·시트 옵션·`아무거나`) | `[aria-current/pressed="true"] > .i-check` | `--main` |
   | 기분 누르는 중 | `.mood:active` | `--main-tint` |
   | 선택 탭 밑줄 | `.tab[aria-pressed="true"]::after` | `--main` 3px(2px에서) |
   | 예약 링크 밑줄 | `.book` | `--main`(다른 `.tbtn`은 `--muted` 그대로) |
   | 저장 하트, ♥ N 하트 | `.heart[aria-pressed="true"]`, `.saved-btn svg` | `--accent` |
   | `아무거나 골라줘` 밑줄 | `.any` | `--accent` 2px(1px `--muted`에서) |

   글자·포커스 링·빈 하트 선·`.tbtn` 밑줄은 그대로 `--text`·`--muted`다.

3. **바뀌는 규칙은 하나: 주 버튼이 회색 채움(`--fill`)에서 메인 색 채움(`--main`)으로 바뀐다.** SPEC 1절 원칙 3·4와 2.1절, 6.6·6.11, 13절, design.md를 이에 맞춘다.
4. **선택은 여전히 색만으로 보이지 않는다**(SPEC 1절 4, design.md C6, WCAG 1.4.1). 선택은 체크·굵기·밑줄과 `aria-pressed`/`aria-current`로 표시하고, 색은 그 표시를 칠할 뿐이다. 채운 면으로 선택을 표시하지 않는다(`check:slop` 18번 그대로).
5. **포인트(귤)는 아이콘과 밑줄에만** 쓴다. 흰 바탕 위 3.22라 글자 색으로는 쓰지 않는다(4.5 미달). `check:slop` 10번 허용 목록에 `.any`를 더한다.
6. **바깥 색도 같은 토큰**: `index.html` 첫 칠 바탕·`theme-color`(라이트 `#ffffff`, 다크 `#0f1319`), 매니페스트 `theme_color`·`background_color` `#0f1319`(ADR-0058 D6의 "밤 기준"은 그대로, 값만 바뀜), `public/404.html`·`public/privacy.html` 인라인 토큰.
7. **아이콘·OG 이미지**: `scripts/make-icons.ts`가 그리는 "바다 위 해" 그림을 녹청 `#2f6f68`·크림색에서 바다 `#0a6fd6` 바탕·귤 `#f06400` 해·흰 물결로 바꾸고 다시 만든다(`npm run make:icons`: `icons/icon-{180,192,512}.png`, `icon-maskable-512.png`, `favicon.ico`, `og.png`). 글자는 없다.
8. **넣지 않는 것**: palette.md의 제안 두 가지(질문의 「지금」 메인 색 강조, 첫 저장 「저장」 배지)는 이번에 넣지 않는다. 넣을지는 따로 정한다.

## Consequences

- 대비(WCAG 2, 토큰 계산, 라이트 / 다크): 본문 17.79 / 16.44, 보조 글자 6.12 / 8.85(최저 `--fill-press` 위 5.00 / 5.95), 주 버튼 글자 4.93 / 7.59(누름 6.03 / 5.46), 체크·탭 밑줄 4.93 / 7.59, 저장 하트 3.22 / 7.94, 날짜 칸 테두리 3.37 / 4.33. 모두 기준(글자 4.5, 본문 7, UI 3)을 넘는다. 빠듯한 곳은 라이트 주 버튼 글자(4.93)와 라이트 하트(3.22).
- **남은 빠듯한 곳 하나(결정 대기)**: 저장한 곳 화면에서 ♥ N이 눌림(`--fill` 면)일 때 라이트 귤 하트가 면 위 2.90으로 UI 3:1에 조금 못 미친다(다크 6.40). 숫자와 `aria-label`이 같은 정보를 주고 하트는 채움 모양으로도 보이지만, 규칙대로 맞추려면 ♥ N 눌림 표시를 면 대신 밑줄로 바꾸거나 라이트 귤을 어둡게 해야 한다. 어느 쪽도 이 ADR 범위 밖이라 사용자 결정으로 남긴다.
- 다크 `--muted`가 `#a3a8a5` → `#b0b3b7`(바탕 위 8.85)로 밝아져 design.md C4(다크 보조 글자 APCA)가 조금 나아진다. APCA 값은 다시 재지 않았다.
- 다크 바탕은 녹회색에서 남색 기운의 현무암으로 바뀐다(SPEC 원칙 11 "순검정 아님"은 그대로).
- 테스트: `tests/contrast.test.ts`에 메인·포인트 대비 하한, `scenarios`·`data`·`deploy` 테스트의 바탕 hex 기대값 갱신.
