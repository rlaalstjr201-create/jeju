# ADR-0078: 분석은 셋(GA4 · 네이버 애널리틱스 · 자체 익명 기록), 꺼진 채로는 배포하지 않는다

Status: Accepted (2026-10-03). ADR-0061의 「수집 주소가 없으면 보내지 않는다」를 운영 빌드에서는 금지로 바꾸고, ADR-0058·ADR-0063 「외부 요청 최소·쿠키 없음」에 분석 두 곳을 더한다. measurement.md의 「GA4 도입 여부부터 결정」을 이 결정으로 닫는다.

## Context

사용자 요구(2026-10-03): GA4와 자체 분석 프로그램이 늘 연동되어 분석돼야 한다. 네이버에 비슷한 것이 있으면 그것도 붙인다.

이 요구에는 사고 이력이 있다. seoulist에서는 GA4가 꺼진 채로 운영돼 정보가 모이지 않았다. 지금 이 앱도 같은 상태다. ADR-0061의 수집기 코드(`apps/web/events/`)는 있지만 배포되지 않았고, `VITE_EVENTS_URL`이 비어 있어 **아무것도 모으지 않고 있다**(docs/deploy.md 「넣지 않는다」).

네이버 애널리틱스(analytics.naver.com)는 운영 중이다. 2026-10-03 확인: 사이트 200, `wcs.naver.net/wcslog.js` 200. 2022년에 끝난 것은 스마트스토어 연동뿐이다.

## Decision

1. **세 가지를 같이 쓴다.**
   - **GA4**: 속성 「여행귀:제주」, 측정 ID `G-P8DN26LKBC`, 대한민국 시간·원화(2026-10-03 생성).
   - **네이버 애널리틱스**: `wcs_add.wa` = `1caa51952fb5230`(사이트 「여행귀:제주」, 2026-10-03 등록). 스크립트는 공식 주소 `wcs.pstatic.net/wcslog.js`.
   - **자체 익명 기록**: ADR-0061 형식 그대로. Pages Function `POST /api/events`가 받아 Cloudflare D1(`yeogwi-events`)에 날짜 × 장소 × 이벤트 카운터로 쌓는다. IP·UA·쿠키는 읽지도 저장하지도 않는다(`events/handler.ts` 그대로).
2. **꺼진 채 배포 금지**(seoulist 재발 방지):
   - **빌드**: `SITE_URL`이 있는 운영 빌드에서 `VITE_GA4_ID`·`VITE_NAVER_WA`·`VITE_EVENTS_URL` 중 하나라도 없으면 빌드가 실패한다.
   - **배포 직후**(`smoke.sh` + e2e 한 항목): 실제 브라우저로 홈을 열고 GA4 수집 요청(`/g/collect`), 네이버 `wcs` 요청, `/api/events` 204를 각각 확인한다. 하나라도 없으면 실패다.
   - **매일**: 자체 기록이 지난 24시간 0건이면 알린다(로컬 예약 작업). 주간 점검에서 GA4·네이버 대시보드의 지난 7일 사용자 수를 기록한다.
3. **사용자 끄기**: 기존 「기록 끄기」가 세 가지를 모두 끈다. GA4는 `ga-disable-<ID>`, 네이버는 스크립트를 넣지 않는 방식이다. 끈 사람에게는 아무것도 로드하지 않는다.
4. **개인정보 안내 고침**:
   - GA4와 네이버 애널리틱스가 쿠키와 접속 정보(IP 등)를 각 회사 서버에서 처리한다는 사실을 쓴다.
   - 좌표는 어느 쪽으로도 보내지 않는다. 기존 문장 「좌표를 기기 밖으로 보내지 않아요」는 그대로 참이다.
   - 끄는 방법을 쓴다.
   - 한국에서는 분석 쿠키에 사전 동의 배너가 의무가 아니다. 그래서 배너는 두지 않고 고지와 끄기로 한다.
5. **번들 예산**:
   - GA4 `gtag.js`와 네이버 `wcslog.js`는 외부에서 `async`로 불러온다. 우리 JS+CSS 50KB 예산에는 들어가지 않는다.
   - 첫 화면을 막지 않도록 `load` 뒤에 붙인다.
6. **분석 프로그램**: `npm run analytics:report`.
   - D1에서 지난 7·28일 기분 탭 수, 카드 노출 → 지도 열기 비율, 저장 상위 장소, 날짜 모드 비율을 뽑아 `docs/analytics/YYYY-MM-DD.md`로 쓴다.
   - 주간 점검이 이것을 같이 돌린다.

## Consequences

- 서버 쪽 구성: Functions 2개(`/api/rain`, `/api/events`)와 D1 1개. `wrangler.toml`에 D1 바인딩을 둔다.
- ADR-0061 4의 고지 문구와 privacy.html을 함께 고친다. deploy.md의 「`VITE_EVENTS_URL` 넣지 않는다」를 뒤집는다.
- 공개 ID 둘은 `scripts/analytics-env.ts` `SITE_IDS`에 고정한다(셸 변수로 두면 빠뜨린다 — seoulist). 빈 값으로 덮으면 빌드가 실패한다.
