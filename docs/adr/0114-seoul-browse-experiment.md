# ADR-0114: 오늘 서울 둘러보기 — 구경하는 화면 실험

Status: Accepted (2026-11-04, 주인 「1번으로 해봐」 — 고르는 도구는 두고 서울에 둘러보기를 시험으로 붙여 잰다).

## Context

- 주인 관찰(2026-11-04): 카드를 10번쯤 넘기면 같은 것이 다시 나오고 박물관 위주라 지루하다. 넷플릭스는 「뭐 볼까」 하며 목록을 보는 것만으로 시간이 간다.
- 여차나는 고르는 도구다(기분 하나 → 근처 3곳 → 길찾기). 둘러보는 재미는 목표가 아니었다. 장소 카드는 날마다 같다.
- ADR-0112·0113으로 서울에는 날마다 바뀌는 자료가 생겼다(서울 문화행사 약 120건 + KOPIS 공연 약 200건, 공연은 포스터 있음). 홈에는 그중 2개만 보인다.
- P 여행자도 미리 훑어보고 염두에 둔다. 경계할 것은 일정으로 묶는 것이다(메모: P traveler understanding). 구경은 이와 부딪치지 않는다.

## Decision

1. **자리**: 서울 홈 「오늘 근처에서 하는 것」 블록에 「오늘 서울 둘러보기」 입구 하나. 누르면 전체 화면 보기(뒤로 가기로 닫힘). 고르는 도구(기분·아무거나·카드)는 그대로.
2. **꼴**: 주제별 가로 줄(넷플릭스식). 줄마다 포스터·사진 카드를 가로로 넘긴다. 줄은 많아야 7개, 줄마다 많아야 12장. 빈 줄은 숨긴다.
   - 지금 근처(가까운 순, 기준이 있을 때), 오늘만·오늘까지, 이번 주에 끝나요, 무대(연극·뮤지컬), 라이브·인디(콘서트·소규모 공연장), 전시, 무료.
   - 한 항목은 한 줄에만(앞 줄 우선) — 같은 것이 줄마다 반복되면 지루함이 그대로 남는다.
3. **오늘만**: 그날 목록(`/api/culture?city=seoul`)만 쓴다. 이미 시작한 공연·지금 닫혀 다시 열리지 않는 곳은 뺀다(`openNow`가 shut). 「19:30 시작」「지금 열림 · 18:00까지」 같은 이유 줄을 카드에 단다. 거리는 기준이 있을 때만.
4. **카드를 누르면**: 아래 시트에 포스터, 제목, 장소, 오늘 시간, 출연, 거리, 「길찾기」와 「자세히(예매·안내)」 링크. 링크는 http(s)만.
5. **그림**: KOPIS 포스터·서울 행사 그림은 그쪽 주소에서 바로 받는다(lazy, https). 그림 요청은 그 사이트로 간다 — 개인정보 안내(네 언어)에 적는다. 그림이 깨지면 글자 카드로.
6. **청크**: 따로 받는 청크(ADR-0100 진입 예산 60,000B 안, 지금 59,396B).
7. **재는 것**(ADR-0061 익명 사용 기록에 이벤트 더함, 위치·항목 이름 없이): 둘러보기 열기, 머문 시간(10초 단위로 묶음), 가로로 넘긴 줄 수, 카드 누름, 길찾기·자세히 누름.
   - **2주 뒤 판정(2026-11-18)**: 열기 30회 이상일 때 머문 시간 중앙값 45초 이상 **그리고** 열기의 30% 이상이 카드를 누름 → 넓히기(제주 재료 찾기·홈 자리 키우기). 못 미치면 원인을 적고 접거나 고친다. 30회 미만이면 판정 보류.

## Consequences

- 고르는 도구의 「적게」(ADR-0112 2)와 다른 층이다. 둘러보기 안에서만 많이 보인다.
- 제주·부산·다른 곳에는 이 입구가 없다(매일 바뀌는 재료가 없음).
