# ADR-0108: 언제나 지금 내 위치에서 가까운 곳부터 (ADR-0060 2 대체)

Status: Accepted (2026-11-03, 주인 결정 「언제나 지금 내위치 기준을 먼저로 해야돼」 → 「A로 가야지」(정렬)).

## Context

- 맞대결 01(`docs/research/vs-llm-01/04-result.md`)에서 여차나는 1위를 하나도 못 했다(0/10).
- ADR-0060 2에 따라 카드는 범위(기본 차로 30분) 안에서 점수 높은 순이었다. 그래서 먼 곳이 가까운 곳보다 먼저 나왔다.
  - 수원 행궁동(자동 지역): 「가까운 순」이라고 적었지만 걸어서 5분인 화성행궁이 걸어서 15분인 두 곳 뒤에 나왔다.
  - 해운대: 해운대에 서 있는데 첫 카드가 「달맞이 고개」 대구탕이었다.
- 주인 원칙: 「지금 여기」가 먼저다. 카드에 보이는 이동 시간이 위에서 아래로 늘어나야 한다.

## Decision

1. **정렬 첫 키는 거리 칸**이다. 칸은 카드가 보여 주는 이동 시간과 같은 단위로 나눈다.
   - 1km 안은 걸어서 5·10·15분 칸이다.
   - 그 밖은 차로 5분 단위 칸이다.
   - 걸어서 칸은 언제나 차로 칸보다 앞이다.
2. **같은 칸 안에서만** 지금까지의 순서를 따른다: 유명한 데의 인기·가까움 합(ADR-0092) → 점수(ADR-0060 1) → 그날 장(ADR-0066) → 그날 철(ADR-0080) → 실제 거리 → id. 점수는 「같은 거리라면 어느 곳」을 정할 때만 쓴다.
3. **밤의 산길·배로 가는 섬(ADR-0091)은 거리보다 앞선 키로 그대로 둔다**(지금 가기 어려운 곳은 뒤로).
4. 이 순서는 두 군데에 같이 쓴다.
   - 순환(안 본 곳 먼저)이 고르는 후보 풀의 순서.
   - 고른 3장을 보여 주는 순서. 「아무거나」의 기분별 3장도 여기에 들어간다.
5. **고르는 방식 줄**: 「{범위} 안에서, 가까운 곳부터 골랐어요.」. 실내는 「{범위} 안의 실내 중에서, 가까운 곳부터 골랐어요.」다. 외국어판도 같은 뜻으로 바꾼다.
6. 위치가 아직 없을 때(`islandTop`, ADR-0075 3)는 거리가 없으므로 지금과 같다.

## Consequences

- ADR-0092 Amendment 2(유명한 데 = 인기 반·가까움 반)는 같은 거리 칸 안에서만 쓴다. 미리 등록한 점검 C1(「훨씬 더 많이 찾는 곳이 15분이면 5분 거리의 덜 알려진 곳보다 앞」)은 이 결정으로 폐기한다.
- `specs/ranking.md`의 정렬 키와 R3를 고친다. R3는 이제 「같은 범위 안에서 첫 장의 거리 칸 ≤ 뒤 장의 거리 칸」이다.
- 점수가 낮아도 가까운 곳이 먼저 나온다. 점수 1~2점(운영 불확실 등)은 이미 심사에서 걸러졌다는 것이 전제다.
- 「지금 불가능한 곳은 추천하지 않는다」(영업시간·정기 휴무)는 이 ADR의 범위가 아니다. 따로 연다.
