# ADR-0063: 배포 준비 — Cloudflare Pages, 로그인 없는 저장 유지, 출처 표시

Status: Accepted (2026-10-01) — ADR-0026(로그인 없음)을 확장

Amended by ADR-0097 (2026-10-19): 저장 키에 `jeju.dest`와 부산 기준·동네·숙소 키(꼬리 `.busan`)를 더했다. 머리말 `jeju.`은 그대로.
Amended by ADR-0076·ADR-0078 (2026-10-03): 「서버 없음」에 첫 서버 코드(비 소식 Pages Function, ADR-0076)를, 「쿠키 없음」에 D1 사용 기록·분석 쿠키(ADR-0078)를 더했다.

## Context

배포 전 검수(`docs/reviews/predeploy-review.md`)에서 막힘 4건이 나왔다: 사실 확인 수정 미반영, spots.json 재생성 불가, 데이터·사진 출처 표시 없음, 호스트 설정. 저장한 곳·날짜별 플랜은 `localStorage`에만 있어 Safari 7일 삭제, 카카오톡 등 인앱 브라우저 저장소 분리, 기기 변경에 약하다.

## Decision

1. **호스팅**: Cloudflare Pages. `_headers`로 해시 자산 1년 immutable, `index.html`·`sw.js`·manifest no-cache. 모르는 경로는 `404.html`(SPA 폴백 없음). HTTPS. 익명 기록 수집기는 나중에 같은 주소의 Functions로.
2. **로그인 없이 저장 유지(배포 전)**:
   - 첫 저장 때 `navigator.storage.persist()` 요청.
   - 인앱 브라우저(카카오톡·인스타그램·네이버 등)면 "브라우저로 열기" 안내(카카오톡은 외부 브라우저 열기 링크).
   - 플랜 백업·복원 링크: 저장 내용을 URL `#` 뒤에 담아 복사. 서버로 가지 않는다. 열면 합칠지 물어본다.
   - 홈 화면 추가 안내: 첫 저장 뒤 한 번.
   - 로그인·서버 동기화는 사용자가 요구할 때 검토.
3. **출처 표시**: 화면에 `정보·사진: 비짓제주(제주관광공사)`. 사진 직접 표시 허락은 제주관광공사에 문의한다(사용자).
4. **개인정보 안내 페이지**: 저장은 기기에만, 위치는 기기 밖으로 안 나감, 익명 기록(켜졌을 때) 내용·끄는 법.
5. **데이터 수정 기록**: 사실 확인 결과는 `review/copy/` 수정 파일로 남기고 빌드 스크립트가 적용한다.

## Consequences

- 링크 미리보기(OG), maskable 아이콘, favicon, robots.txt를 함께 넣는다.
- 오류 집계와 실기기 점검(아이폰 Safari, 카카오톡 인앱, 삼성 인터넷)은 배포 직전 체크리스트에 남긴다.
