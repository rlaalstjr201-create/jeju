# ADR-0060: 만족도 점수 우선 정렬과 범위 선택

Status: Accepted (2026-09-30)

## Context

지금 카드는 차로 1시간 안에서 가까운 순이다. 남은 2,959곳은 심사를 통과했을 뿐 서로 우열이 없다. 여행 중 추천이라면 만족도가 높은 곳이 먼저 나와야 한다. 평점·리뷰 수 같은 인기 지표는 데이터에 없다.

## Decision

1. **만족도 점수(A안)**: 기존 원본(비짓제주 요약·코멘트·태그·수상 이력)만 근거로 곳마다 1~5점을 매기고 근거를 기록한다. 새 출처 수집 없음(ADR-0058 유지). 기준은 `specs/ranking.md`.
2. **정렬**: 범위 안에서 점수 높은 순, 같은 점수대는 가까운 순. "다른 3곳 보기" 순환 규칙은 유지.
3. **범위 선택**: 기준 시트에 `걸어서 · 차로 30분 · 차로 1시간`. 기본은 차로 30분. 3곳이 안 되면 지금처럼 넓힌다(빈손 없음).
4. **표시하지 않음**: 점수·별점은 화면에 보여 주지 않는다(가격·평점 없음 원칙 유지).
5. **나중**: 배포 후 모은 사용 기록 인기도(ADR-0061)를 점수에 섞는다. 섞는 비율은 데이터가 쌓인 뒤 정한다.

## Consequences

- spots.json에 `score` 필드가 생긴다. 점수 기록은 `review/score/`.
- 가까운 곳보다 먼 좋은 곳이 먼저 나올 수 있다. 카드의 이동 문구가 거리를 알려 준다.
