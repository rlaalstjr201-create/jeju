# ADR-0058: 리빌딩 이전 제약 재판정 (apps/web "내일 뭐하지")

Status: Accepted (2026-09-30) — ADR-0025·0027·0028·0029와 `plans/tomorrow-picker.md` 일부를 갱신. "예약은 마이리얼트립만(`bookable`)"은 ADR-0073이 멈추고 ADR-0074(체험마다 확인된 경로 하나)가 대체했다(2026-10-01)

Amended by ADR-0076·ADR-0078 (2026-10-03): 「외부 요청 제한」에 비 소식 Pages Function(ADR-0076)과 분석 두 곳 GA4·네이버 애널리틱스(ADR-0078)를 예외로 더했다.

## Context

`plans/tomorrow-picker.md`, `specs/tomorrow-picker.md`, ADR-0025~0029는 리빌딩(ADR-0028·0029, SPEC 3판) 전에 쓰였다. 출하 코드·데이터와 문서가 여러 곳에서 어긋난다(기분 4 vs 5, 지역 4 vs 15, `paid` vs `bookable`, 라벨 `기준` vs `근처` 등). ADR-0057에서 gzip 120KB를 폐기하며 "리빌딩 이전 제약은 재판정 대상"이라 했고, 이 ADR이 그 재판정 결과다.

측정(2026-09-30, apps/web): spots.json 2,959곳, 카카오 ID 없음 748곳, 기분별 최소 rest 317, 이유 문장 15~47자, 90조합 × 3페이지 최악 이동 15분, 한 화면 세 장 끝맺음이 모두 같은 화면 21.9%(59/270).

## Decision

### SPEC §16 D1~D7 — 기본값대로 확정

| # | 확정 |
|---|---|
| D1 | 기준 라벨 `{지역} 근처` / `여기 근처` / `숙소 근처`. `⇄` 없음 |
| D2 | 기분 재탭 = 마지막으로 본 3장 복원. 다음 3장은 `다른 3곳 보기`(후보 ≥ 6이면 직전 3장과 겹치지 않음) |
| D3 | 하트는 이름 오른쪽(44×44) |
| D4 | 카카오 ID 없는 748곳은 이름 검색 링크, 이름에 `제주`·`서귀포`가 없으면 `제주 ` 접두(S56) |
| D5 | 어제 고른 지역 기준을 GPS로 되돌리지 않는다 |
| D6 | 매니페스트 `theme_color`·`background_color` `#161817` |
| D7 | 동네 칸에 대표 지명 15개를 보인다(화면 문구만) |

### 제약별 판정

| 제약 (출처) | 판정 | 이유 |
|---|---|---|
| 한 종결 어미 ≤ 25% (S9-3, SPEC §10) | DROP | 이에요·예요를 따로 세서만 통과하는 지표. 의도는 금지어·길이·마침표 규칙이 지킨다 |
| 세 장 끝맺음이 같은 화면 ≤ 5% (SPEC §10) | DROP | 현 분포에서 우연만으로 약 22%. 도달 불가, 테스트 없음 |
| 금지어 0, 길이 15~70자, 끝 마침표 없음, `~수 있어요` ≤ 20% | KEEP | 싸고 의미 있는 가드 |
| S9-3 opus 충실성 감사(표본 ≥ 5%, 원문 밖 ≤ 2%) | KEEP | 실행 결과는 `apps/web/review/audit/` |
| S6 Codex 교차 리뷰 (CLAUDE.md 7단계) | 면제 | 계정에서 실행 불가. opus 적대적 코드 감사 3라운드 + 시각 QA로 대체, MAJOR 전부 수정 |
| ADR-0027 "한 번 뽑고 재실행 안 함" | MODIFY | 새 소스 없음, 정기 갱신 없음. 기존 레코드의 일회성 수정(중복 제거·재지오코딩·문구 수정)은 `review/` 또는 git 기록이 있으면 허용 |
| S1 restaurant 0건 | DROP | ADR-0028이 맛집 포함으로 대체 |
| S1 총 ≥ 400건 | DROP | S1'로 대체(현재 2,959) |
| S1 이유 18~120자 | DROP | S1'·S9-3의 15~70자로 대체 |
| S1 기분별 ≥ 80건 | DROP | 실제 보장은 S8-1(15지역 × 6 = 90조합) |
| S1 gzip ≤ 120KB | DROP | ADR-0057 |
| S1 필드 `…,paid` | MODIFY | `id,name,lat,lng,mood,reason,image,kakaoPlaceId,bookable`(+먹기는 `sub`) |
| S2 대표 좌표 4 × 버튼 4 | MODIFY | S8-1로 흡수. 4좌표는 추가 고정값으로만 |
| 기분 4개, 지역 4개, 카드 3~4장, 숙소 검색 등록, 클룩·마이리얼트립 | MODIFY | 기분 5, 지역 15, 카드 3장, 숙소는 GPS 또는 지역 선택, 예약은 마이리얼트립만(`bookable`) |
| S9-5 자체 호스팅 웹폰트 ≤ 150KB 허용 | MODIFY | SPEC §3.1이 이긴다: 웹폰트 0 |
| 좌표·https 사진·카카오 ID 중복 0, 60분 가드, `any`에 먹기 없음, 반경 확대, JS+CSS gzip ≤ 50KB, 가격·운영시간·평점 없음, 로그인·일정·결제 없음, PWA(S5), 외부 요청 제한, 접근성(S9-4·S9-6), 슬롭 체크리스트, 시나리오 표(S9-2) | KEEP | 지금도 의미 있고 통과 중 |

## Consequences

- 문서 동기화: `plans/tomorrow-picker.md`(대체 표시, 이력은 지우지 않음), `apps/web/design/SPEC.md` §10·§16, ADR-0025·0028·0029에 갱신 줄.
- `tests/data.test.ts` S60에서 25% 단언을 뺀다. 5% 화면 지표는 원래 테스트가 없었다.
- ADR 번호 0025~0029가 큐레이션 시절 파일과 겹친다. 이 문서의 ADR-0025~0029는 웹 쪽(`0025-pivot-to-tomorrow-picker` … `0029-destination-areas-and-saves`)을 뜻한다. 번호는 바꾸지 않는다.
