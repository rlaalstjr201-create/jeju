# ADR-0062: 지역 확장 여지 (TourAPI), 제주 배포 우선

Status: Accepted (2026-10-01) — ADR-0058의 "새 출처 금지"를 이 범위만큼 대체

## Context

제주 데이터는 비짓제주 원본에서 왔다. 서울·부산 등으로 넓히려면 한국관광공사 TourAPI(국문 관광정보 서비스, 전국 약 26만 건, 좌표·개요·사진, 공공누리 1·3유형)가 같은 구조의 출처다. 지금 앱은 지역 15곳, 제주 범위 판정, 카카오 검색 접두어 `제주`, 섬 기준 이동 시간 등이 제주에 묶여 있다.

## Decision

1. **배포 먼저**: 제주로 배포하고 첫 실사용자 반응을 본다. 확장은 그 뒤.
2. **확장 허용**: 다음 지역 데이터는 TourAPI를 출처로 쓸 수 있다(ADR-0058의 새 출처 금지를 이 출처에 한해 해제). 같은 파이프라인(심사 → 이유 문장 → 만족도 점수 → 사실 확인)을 거친다.
3. **여지 남기기**: 새 코드는 제주 고유 값(경계, 세부 지역, 검색 접두어, 이동 속도)을 상수 한곳에 모으는 방향으로 쓴다. 본격 분리(지역 설정 파일, 지역별 데이터 파일)는 확장 착수 때 한다.
4. **두 번째 지역 후보**: 이동이 제주와 비슷한 부산·강릉·경주. 서울은 이동 방식(대중교통·도보)이 달라 뒤로.
5. **사진**: TourAPI 사진은 출처 표시, 3유형은 변경 금지를 지킨다.

## Consequences

- 확장 착수 시 Light Spec(`specs/region-expansion.md`)과 TourAPI 키 신청이 필요하다.
