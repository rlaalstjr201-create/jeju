# ADR-0026: 로그인 없음 (ADR-0011 대체)

Status: Accepted (2026-09-30) — Supersedes ADR-0011

## Context

ADR-0011은 Shortlist·Trip의 영구 소유를 위해 카카오 로그인을 필수로 했다. ADR-0025로 대상 순간이 "내일 뭐하지?"로 바뀌면서 Shortlist·Trip이 범위에서 빠졌고, 기억할 것은 숙소 위치 하나뿐이다.

"내일 뭐하지?" 순간에 로그인 화면이 뜨면 대부분 닫고 검색창으로 간다.

## Decision

로그인 없이 연 즉시 사용한다. 숙소처럼 기억할 값은 기기 로컬 저장소에만 둔다. 서버 계정 없음.

## Consequences

- 기기를 바꾸면 숙소 설정이 사라진다 — 다시 한 번 검색하면 되는 수준이라 수용.
- 기억할 것이 늘어나 기기 간 동기화가 필요해지면 "선택 로그인"(기본은 비로그인)을 그때 검토한다.
