# ADR-0073: 예약 링크(마이리얼트립 검색) 중단 — 장소별로 확인된 경로가 생길 때까지

Status: Accepted (2026-10-01). 아래 "계획"은 보류(pending).

## Context

카드의 「마이리얼트립에서 예약 찾아보기」는 `myrealtrip.com/search?q=이름` 검색 링크다. `docs/research/booking-links-01.md` 표본 60곳에서 그 장소 상품에 닿은 곳은 10곳(17%)이었고, 나머지는 결과 0건이거나 다낭 골프·라스베이거스 투어처럼 관계없는 상품이었다. 진짜 예약 페이지는 네이버 예약(40%)에 가장 많았다.

## Decision

- 검색 링크를 카드에서 **보여주지 않는다.** `BOOKING_LINKS_ENABLED = false`(`apps/web/src/links.ts`)를 `render.ts`가 확인한다.
- `bookable` 필드, `bookingUrl`, 데이터는 지우지 않는다. 나중에 장소별 데이터 기반으로 다시 쓴다.
- ADR-0058의 "예약은 마이리얼트립만(`bookable`)"을 **당분간** 대체한다(ADR-0025의 "예약은 외부 링크" 방향은 그대로).
- 정적 랜딩·장소 페이지는 예약 링크를 원래 두지 않으며 계속 두지 않는다. `llms.txt`·개인정보 처리 문구에서 예약 링크 약속을 뺐다.

## 계획 (pending)

장소마다 **확인된** 경로 하나만 단다. 우선순위: 네이버 예약 → 마이리얼트립 직접 상품 → 비짓제주 예약 → 공식 홈페이지 → 전화. 확인된 것이 없으면 버튼을 숨긴다. 이 경로가 없는 체험(`bookable`)은 따로 결정한다. 데이터 수집은 `apps/web/review/booking/`에서 진행 중이다.
