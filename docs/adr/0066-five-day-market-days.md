# ADR-0066: 오일장 「오늘 열려요」 — 오일장 9곳 추가와 장날 표시

Status: Accepted (2026-10-01)

## Context

경쟁 조사(`docs/research/competitors-01.md` (a)#7)에서 오일장 날짜처럼 「오늘만」 맞는 정보가 싸고 「오늘」 맥락에 강하다고 봤다. 그런데 출하본 2,955곳에는 오일장이 한 곳도 없다. 수집한 비짓제주 카테고리가 식당·카페·관광지·체험·문화공간뿐이고, 비짓제주는 오일장을 `쇼핑`(c2)에 둔다. 오일장 안이나 근처의 식당 몇 곳만 있다(예: 대정오일시장 안 오메기식당).

## Decision

1. **데이터 추가(비짓제주, 새 출처 아님)**: 이미 정한 출처인 비짓제주(ADR-0023)에서 카테고리 하나(`쇼핑` 중 오일장)를 더한다. TourAPI는 쓰지 않는다. 비짓제주 공개 페이지(검색 `오일장`·`오일시장`·`5일장`·`민속시장`, 상세 페이지)에서 찾은 오일장 **9곳**을 추가한다: 제주민속·서귀포향토·한림민속·세화해녀민속·함덕민속·고성·대정·중문향토·표선. API 키가 없어 공개 페이지 원문을 읽었고 URL과 확인일(2026-10-01)을 남긴다. 출하 2,955곳 → **2,964곳**.
   - 원문: `review/input/batch-900.json`(기존 입력과 같은 필드, `category: shopping`, `source`에 상세 페이지 URL). 번호 900은 `prepare-review.mjs`가 만드는 001~065와 겹치지 않게 한 것이다.
   - 같은 단계를 거친다: 검수(keep·기분·이유 문장, `review/market/verdicts.json`, 근거 인용 포함) → 만족도 점수(`review/score/score-07.json`, ADR-0060 기준) → 카카오맵 대조(`review/copy/market-days.json`의 `kakao`: 장소 id, 영업 상태, 장날 문구, 좌표 차이 8~104m). `build-spots.mjs`가 같은 규칙으로 합친다.
   - 사진은 비짓제주 대표 사진 썸네일(다른 곳과 같은 핫링크, ADR-0063).
2. **기분은 하나로 고정: 새로운 거 · 구경**. 먹거리가 있는 시장도 있지만 먹기(식사·카페)는 「앉아서 먹을 한 곳」을 고르는 목록이고, 시장은 걸으며 둘러보는 곳이다. 비짓제주 분류도 `쇼핑`이다. 시장 안 식당은 이미 따로 먹기에 있다. 새로운 거 분류(ADR-0064)에 `shopping → sight` 규칙을 더한다.
3. **실내**: 9곳 모두 실외(ADR-0065 「애매하면 실외」). 판정은 `review/copy/indoor.json`.
4. **장날 규칙(정적)**: `review/copy/market-days.json`에 곳마다 장날(그달의 날짜 목록), 표시 라벨(`2·7일`), 출처 인용·URL·카카오 확인을 둔다. spots.json의 오일장에만 `market: { days, label, noFirstAfter31? }`. 외부 요청 없음.
   - 대정: 31일이 있는 달은 31일에 열고 다음 달 1일에는 열지 않는다(비짓제주 본문·테마여행, 카카오도 같음).
   - 출처끼리 다를 때: 표선 이용안내의 「27」(17의 오기)은 본문·카카오로 바로잡고, 함덕은 비짓제주가 나열한 날짜(31일 없음)를 따른다. 근거는 `market-days.json`의 `note`.
5. **어느 날로 보나**: 지금 모드면 오늘(제주 날짜, KST), 날짜 모드면 고른 날. 결과를 뽑을 때(정렬·제외)와 카드를 그릴 때(문구) 모두 이 날을 쓴다.
6. **표시**: 결과 카드 메타 줄 맨 앞에 장날 문구 하나(태그·칩 아님, `실내`와 같은 방식). 그날 열리면 `오늘 장 서는 날`(날짜 모드는 `이날 장 서는 날`), 아니면 `장날: 2·7일`. 저장 목록 줄에는 없다.
   - 운영시간: 비짓제주가 고정 시간을 적고 카카오와 어긋나지 않을 때만 표시한다. 지금은 **0곳**이다. 세화·표선은 원문이 「고정된 운영시간 없음」이라 하고, 중문은 비짓제주 08:00~17:00, 카카오 08:00~18:00로 출처끼리 다르다. 그래서 운영시간 표시는 만들지 않았다. 해당하는 곳이 생기면 그때 더한다.
   - 이 문구는 S1'의 「카드에 운영시간·요일 없음」의 예외로 이 ADR이 정한다. 이유 문장에는 여전히 날짜·시간을 넣지 않는다.
7. **정렬**: 장날이면 점수가 같은 카드들 안에서 맨 앞(점수는 올리지 않는다). 정렬 키는 점수 → 그날 장날 → 이동 시간 → id.
8. **제외**: 장날이 아닌 날에는 출처가 그날 닫는다고 한 경우에만 후보에서 뺀다. 9곳 중 「장날 아닌 날 닫는다」고 적은 원문은 없다. 출처가 닫는다고 한 날은 대정의 「31일 다음 1일」뿐이라 그날만 대정을 뺀다. 빼도 넓히기 규칙(3곳 미만이면 가까운 3곳)은 그대로라 빈손은 없다.

## Consequences

- 카드가 날짜에 따라 달라지는 첫 경우다(`specs/date-mode.md` 「추천은 날짜와 무관」의 예외). 뽑은 뒤 기준 시트에서 날짜만 바꾸면 결과는 다시 뽑지 않는다(지금처럼). 문구는 바로 새 날로 바뀌고 순서·제외는 다음 뽑기부터 적용된다.
- 자정이 지나면 문구는 새 오늘로 바뀐다(날짜가 바뀌면 화면을 다시 그린다).
- 장날이 아닌 날에도 오일장이 `장날: 2·7일`과 함께 나올 수 있다. 상설 점포가 있는지는 원문에 없어 단정하지 않는다. 사용 기록이 쌓이면 다시 본다.
- 오일장이 아닌 상설시장(동문·매일올레)은 이번 범위가 아니다.
- 상세는 `specs/market-days.md`.
