# ADR-0086: 저장·날짜 흐름은 지금대로 두고, 실제 기록으로 먼저 본다

Status: Accepted (2026-10-10). ADR-0085(저장 목록 흐름 기록)를 배포한다.

## Context

1차 가상 여행자 실험(`docs/research/p-persona-sim-01/40-report.md`)은 지금 흐름(날짜 먼저)에서 밤에 「지금」으로 담은 하트가 다음 날 「지난 날」로 접혀 ♥ 0이 되는 구조 문제를 냈고, 하트를 날짜 없이 담는 흐름(B)을 제안했다. 2차 실험(`docs/research/p-persona-sim-02/`)은 도구 검증(0c 조건부 통과) → 안전성 → 탐색 → 확증을 사전등록대로 밟았다(목표 `05-goal.md`).

확증(새 216명, `20-stage3-results.md`): 다음 날 꺼내기는 최소 수정 A′ +49.5%p, B +45.8%p로 크게 이겼지만, 계획 맡은 사람이 담은 곳을 내일·모레로 나누는 과제에서 비열등(−10%p)을 보이지 못했다(A′ −15.7%p, B −6.0%p, 90% 아래끝 −22.2·−12.5). 사전등록한 결정 규칙은 「이긴 흐름 없음 → A 유지」다.

## Decision

1. 저장·날짜 흐름은 지금대로 둔다(A).
2. 저장 목록 흐름 기록(ADR-0085)을 배포해, 실제 사용자에게서 「♥ 0인데 지난 날이 접힌 채 목록을 연 비율」과 「하루 이상 지난 줄에서 연 길찾기」를 잰다.
3. 흐름을 다시 다룰 때는 새 번호의 실험으로 한다: 계획 정리 과제의 측정을 고치거나(2·3단계 사이에서 결과가 뒤집혔다), 실제 기록에서 끊김이 확인된 뒤.

## Consequences

- 밤에 담은 하트가 다음 날 숨는 구조 문제는 남는다. 시뮬레이션에서는 크고 일관된 손해였다(꺼내기 37% 대 82~86%). 실제 기록으로 크기를 확인하기 전까지는 고치지 않는다.
- 사전등록 규칙을 결과를 본 뒤 바꾸지 않았다. 계획 정리 측정이 흔들린 것은 다음 실험의 숙제로 남긴다.
