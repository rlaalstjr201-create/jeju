# ADR-0082: 이름 「여차나:제주」, 주소 yeochana.pages.dev (ADR-0077 1·2·4·5·6 대체)

Status: Accepted (2026-10-04, 주인 결정). ADR-0077의 Amendment 1(태그라인)과 Amendment 2(목적 문장)는 이름만 바꿔 그대로 쓴다.

## Context

주인 의견(2026-10-04): 「여행귀」는 귀신 이름처럼 들린다. 후보는 여차나·여차·여찬이었고, 비교 내용은 다음과 같다.

| 후보 | 뜻 | 이름 검색 | 판단 |
|---|---|---|---|
| 여차 | 「여차하면」이라 뜻은 가장 잘 읽힌다 | 「여차저차」 같은 흔한 말과 섞여 이름 검색 1위가 어렵다 | 2순위 |
| 여찬 | 뜻이 안 읽히고 사람 이름 같다 | 실존 인물 이름과 섞인다 | 「여행귀」 반려 사유가 그대로 남는다 |
| 여차나 | 「여차하면 나선다」로 읽힌다 | 흔하지 않은 말이라 혼자 잡기 쉽다 | 채택. 처음 이름 「귀차나」와 운이 맞는다 |

지금 바꾸는 비용이 가장 작다. 서치콘솔·서치어드바이저 등록이 2026-10-02~03이었고, 네이버 순위 기준선은 전부 not_found였다. 사용자도 거의 없다.

## Decision

1. **정식 이름**은 `여차나:제주`다. 쓰는 곳은 ADR-0077 1과 같다.
2. **기본 이름**은 `여차나`다. 콜론 뒤가 지역이다(예: `여차나:부산`).
3. **문장**: ADR-0077 Amendment 1·2의 문장에서 이름만 바꾼다. 엔티티 문장만 다음으로 바꾼다.
   - 엔티티 문장: 「여차나:제주는 여차하면 나서는 P를 위한 여행동반자로, 계획 없이 다니는 여행자가 지금 있는 곳에서 기분 하나로 갈 곳 3곳을 받는 제주 무계획 여행 앱이다.」 해요체 자리는 「…앱이에요.」
   - 첫 화면 이름 줄 「여차나:제주 · P를 위한 여행동반자」, 태그라인, 목적 문장, description은 그대로다.
4. **홈 화면 이름**(manifest `short_name`)은 `여차나`다.
5. **브랜드 검색어**는 `여차나:제주`다. JSON-LD `alternateName`은 `여차나`, `여차나 제주`, `여행귀:제주`, `여행귀`, `여행계획짜기 귀찮아`다. 옛 이름은 이미 공유된 링크와 검색을 위해 남긴다.
6. **주소**:
   - 새 Cloudflare Pages 프로젝트 `yeochana`, `https://yeochana.pages.dev`. `SITE_URL`도 이 주소다.
   - `yeogwi`와 `gwichana-jeju`에는 둘 다 새 주소의 같은 경로로 바로 보내는 301과 스스로 해제하는 sw.js를 배포한다(ADR-0077 6과 같은 방식, `apps/web/scripts/redirect-site/`). 두 번 거쳐 넘기지 않는다.
   - 프로젝트에 붙은 비밀 `KMA_SERVICE_KEY`와 D1 `yeogwi-events` 바인딩은 새 프로젝트에 붙인다. D1 이름은 바꾸지 않는다.
7. **분석**:
   - GA4 측정 ID는 그대로 쓴다. 데이터 스트림 주소와 속성 이름은 주인이 바꾼다.
   - 네이버 애널리틱스는 사이트 주소에 묶여 있다. 2026-10-04에 새 주소를 등록해 새 ID `1caff08e05278f0`(사이트 「여차나:제주」)를 받았고 `SITE_IDS`에 반영했다. 옛 ID `1caa51952fb5230`은 쓰지 않는다. 네이버 서치어드바이저 소유 확인 메타도 새 주소용으로 바꿨다.
8. **바꾸지 않는 것**은 ADR-0077 7과 같다. 저장 키, 역사 기록, OG 이미지는 그대로다. 옛 주소에 저장된 하트는 옮겨지지 않는다.

## Consequences

- `smoke.sh`의 「옛 이름 0」 검사에 `여행귀`를 더한다. JSON-LD alternateName은 예외다.
- 서치콘솔·서치어드바이저에 새 주소를 등록하고 sitemap을 낸다. 서치콘솔에서는 「주소 변경」을 쓴다. 이 일은 주인과 원격으로 한다.
- 상표 출원 대상은 「여차나」, 「여차나:제주」다(KIPRIS 확인은 주인 할 일).
- 「여자나」로 잘못 들릴 수 있다. 말로 소개할 때 들리는 문제라 화면에서는 고치지 않는다. 문제가 실제로 생기면 다시 본다.
