# ADR-0090: 길 잃지 않게 — 위 줄 왼쪽은 「뒤로」(첫 화면은 로고), 기준·♥는 늘 오른쪽, 되돌리기·설정은 그 자리에서

Status: Accepted (2026-10-16). 주인 지적(「바꾸기가 눈에 안 들어오고, 홈으로 어떻게 가는지 한동안 생각했다」)과 첫 사용자 평가 3명(`docs/research/heuristic-audit-02/02-synthesis.md`, 설명 없이 사진만 보고 할 일 11개)이 근거다. SPEC 6.2(상단 줄)·6.4(결과 머리)·6.11(기준 시트)·6.12(저장한 곳)·9(문구)와 ADR-0087의 보이는 이름(「뺀 곳」)을 고친다. ADR과 충돌 없음(「← 돌아가기」를 글자 버튼으로 바꾼 것은 SPEC 디자인 심사 표의 선택이었다).

## Context

- 평가 3명 모두 같은 세 곳에서 막혔다: 결과 → 처음 화면(T3), 「가 봤어요」를 나중에 되돌리기(T8), 결과 화면에서 기록 끄기·개인정보 찾기(T11). 다른 동네로 바꾸기(T4)는 3명 모두 망설였다. 핵심 흐름(기분 → 3곳 → 길찾기·저장)은 3명 모두 막힘 없음.
- 지난 점검(`heuristic-audit-01`)은 평가자에게 버튼이 하는 일을 먼저 알려 줘서 「찾기」 문제를 놓쳤다.
- 관례: 계층 이동은 위 줄 맨 왼쪽 뒤로 아이콘(Apple HIG 내비게이션 바, Material 상단 앱 바), 같은 컨트롤은 화면마다 같은 자리(닐슨 N4), 눈에 띄는 비상구와 되돌리기(N3). iOS 홈 화면 PWA에는 브라우저 뒤로 버튼이 없다.

## Decision

1. **위 줄 왼쪽 = 이동.** 첫 화면은 로고. 결과·저장한 곳은 **뒤로 아이콘 버튼**(왼쪽 꺾쇠 SVG, 24 격자, 획 2, `--text`, 그린 40 원형 `--fill`, 누름 영역 48×48, `aria-label` `뒤로`).
2. **위 줄 오른쪽 = 기준 칩 + ♥ N 칩**, 모든 화면에서 같은 자리(전엔 결과 화면에서 기준 칩이 왼쪽으로 옮겨 갔다).
3. 뒤로의 동작은 지금 알약과 같다: 결과 → 「바꾸기」 처리(결과 항목을 지우고 기분 화면, 폰 뒤로가 결과로 안 돌아옴), 저장한 곳 → 「돌아가기」 처리(연 화면으로, 스크롤까지). 머리 줄의 「바꾸기」·「돌아가기」 알약은 없앤다.
4. **결과 화면 아래에도 「설정 · 지도 앱 · 의견」**(첫 화면 맨 아래와 같은 버튼·같은 곳으로).
5. **「가 봤어요」 되돌리기:**
   - 누르면 상태 줄 `{이름}은 다음부터 빼고 골라요.` 옆에 글자 버튼 `되돌리기`(다시 누른 것과 같다).
   - 보이는 이름을 맞춘다: `뺀 곳 N곳` → `가 본 곳 N곳`(펼친 목록의 `다시 넣기`·`모두 다시 넣기`는 그대로). 저장 키·이벤트·내부 이름(`jeju.visited`, `visited`)은 그대로.
   - 누르기 전후 버튼 폭이 바뀌지 않게 체크 자리를 미리 둔다.
6. **기준 시트의 다른 동네:** `다른 동네는 아래에서 골라요` 줄을 버튼 `다른 동네 고르기`로 — 누르면 동네 색인으로 내려가고 첫 칸에 포커스.
7. **랜딩 앱 링크 문구:** `앱에서 {동네} 근처 3곳 받기` → `앱에서 {동네} 근처 3곳 보기`(「받기」가 앱 설치로 읽힘).
8. 이번에 안 하는 것: 밤에 산행을 추천하는 문제(무엇을 밤에 뒤로 미룰지 제품 결정 — 따로 ADR), 「다른 3곳 보기」 막대가 둘째 카드 버튼을 덮는 것(출시 뒤).

## 확인

- e2e: 뒤로 → 기분 화면, 그 뒤 폰 뒤로가 결과로 안 돌아옴. 저장한 곳 뒤로 → 연 화면. 위 줄 왼쪽·오른쪽 자리가 세 화면에서 같음. 320에서 넘침 0, 누름 영역 48. 「되돌리기」로 빼기가 풀림. 결과 화면에서 설정에 닿음. 시트 「다른 동네 고르기」 → 색인이 화면 안.
- 다시 사진만 보고 T3·T4·T8·T11을 하는 평가 1명(설명 없이).

## Consequences

- 320px에서 위 줄 오른쪽 기준 칩 라벨이 짧아질 수 있다(긴 라벨은 지금 규칙대로 줄바꿈·말줄임).
- SPEC의 「유니코드 기호 ← 금지」는 그대로(SVG 아이콘).
