# ADR-0118: 이번 주 서울 — 매주 바뀌는 재료 (S2 첫 회)

Status: Accepted (2026-11-05, 주인 지시 「S2 매주 바뀌는 서울 첫 회」). 근거: `docs/office_hours-seoul.md` 「Claude 판단 4」·「단계 S2」. ADR-0115(판정·감사 틀)·ADR-0117(서울 홈 선반)에 선반 하나를 더한다. 스펙: `specs/seoul-weekly.md`.

## Context

- 서울 홈 선반(ADR-0117)은 고정 목록(즐길 거리 304곳)과 서울시 문화행사·KOPIS 그날 목록만 쓴다. 주인 관찰: 트렌디함이 없다.
- 팝업스토어·새로 연 곳·이번 주 끝나는 마켓·축제·전시는 서울시 문화행사 API에 거의 없다. 사람들은 이것을 네이버 블로그·뉴스와 인스타에서 찾는다.
- 쓸 수 있는 무료 출처: 네이버 검색 API(블로그·뉴스, `.env` NAVER_CLIENT_ID·NAVER_CLIENT_SECRET), 카카오 로컬 키워드 검색(KAKAO_REST_API_KEY). 유료 AI API는 쓰지 않는다. 판정은 Claude Code 하위 에이전트가 한다.
- 주인 원칙: 지금 갈 수 없는 곳은 추천하지 않는다. 내 위치가 먼저다.

## Decision

1. **선반 「이번 주 서울」**(`week`): 기간이 정해진 서울의 것만 싣는다 — 팝업(팝업스토어), 새로 연 곳(문 연 지 4주 안의 가게·공간), 전시(기간 한정), 마켓(플리마켓·장터), 축제. 항목마다 시작일·끝나는 날이 있다. 끝난 것은 앱이 날짜로 뺀다(데이터를 지우지 않아도 화면에서 빠진다).
2. **재료**: 네이버 검색 API 블로그·뉴스를 미리 고정한 검색어 표(`apps/web/review/seoul-weekly/queries-01.json`)로 한 번씩 묻는다. 글 제목·요약에서 후보(이름·장소·기간·시간)를 하위 에이전트가 글에 있는 말만 옮겨 적는다. 장소 좌표는 카카오 로컬 키워드 검색으로 확인한다(서울 주소만).
3. **판정·감사**(ADR-0115 틀): 실행 전에 사전등록 기준(`review/seoul-weekly/criteria-01.md`)을 커밋한다. 하위 에이전트가 기준대로 판정을 한 번 하고, 판정을 보지 않은 새 Opus가 블라인드 표본 감사를 한 번 한다. 일치 90% 이상이면 keep만 `data/seoul/weekly-seoul.json`으로 싣는다. 미달이면 싣지 않는다(재실행 없음, 주인 판단).
4. **앱**: 자료는 즐길 거리처럼 문화 청크(`browse.ts`·`browse-view.ts`, ADR-0100)에 묶여 그날 목록과 함께 `culture.items`에 실린다. 진입 번들에는 들어가지 않는다. 지금 열림은 그날 목록과 같은 `openNow`로 본다. 기간 밖이면 닫힘이다. 자료의 시간을 읽고, 시간이 없으면 시간대 규칙(19–9시 닫힘, 축제는 시간 없으면 뺌)을 쓴다. 서울시 목록에 같은 이름이 있으면 그날 목록 쪽만 남긴다.
5. **자리**: ADR-0115 6의 시간대 순서표에 `week`를 넣는다. 낮에는 맨 앞, 아침·해 질 녘에는 셋째, 밤·새벽에는 앞 세 줄 밖이다(스펙 표). 6장 미만이면 꽉 찬 줄 뒤로 가는 규칙(ADR-0115 Amendment 3)은 그대로다.
6. **갱신**: 이번에는 손으로 한 번(2026-11-05) 돌린다. 매주 자동으로 돌리는 일(클라우드 주기 실행, 키 위치)은 주인 몫으로 남긴다(스펙 「갱신」).

## 성공 기준

- 감사 일치 90% 이상(블라인드 표본, 1회).
- 「이번 주 서울」 카드는 모두 오늘이 기간 안이고 지금 열림 판정을 통과한다. 끝난 날 다음 날에는 0장이다(테스트).
- 한국어 진입 gzip ≤ 70,000 B(ADR-0116).
- tsc, vitest 세 모드 실패 0, check:jeju 기준선 그대로.

## Consequences

- 자료가 한 주 지나면 낡는다. 갱신이 멈추면 선반은 끝난 것부터 저절로 비고, 비면 나오지 않는다.
- 블로그·뉴스는 광고 글이 섞인다. 기준이 체인·광고성을 빼지만, 감사 표본 밖의 오류는 남을 수 있다.
- 새 출처 줄 「정보: 네이버 블로그·뉴스, 장소: 카카오맵」이 생긴다.
