# ADR-0067: 차로 바로 길찾기 · 차 안 사용 전제 · AI 에이전트용 딥링크

Status: Accepted (2026-10-01)

## Context

제주와 국내 여행 대부분은 차로 다닌다. 지금 카드를 누르면 카카오맵 **장소 페이지**가 열리고, 거기서 `길찾기` → `자동차` → 출발지 확인을 거쳐야 내비가 뜬다. 차 안에서는 이 몇 탭이 곧 위험이다.

또 ChatGPT·Claude·Perplexity 같은 AI 에이전트가 「애월에서 비 오는 날 걸을 만한 곳」을 물으면, 지금은 앱 첫 화면 링크만 줄 수 있다. 앱이 무엇인지 읽을 기계용 설명(`llms.txt`, 홈 JSON-LD)도 없다.

### 카카오맵 URL 조사 (2026-10-01)

| 방식 | 모양 | 확인한 것 |
|---|---|---|
| 웹 길찾기 링크 | `https://map.kakao.com/link/to/이름,위도,경도` | 공식 가이드(apis.map.kakao.com/web/guide 「URL로 사용하기」). 실제 요청: PC는 `map.kakao.com/?target=car&…`(자동차 탭, 도착지 채움). **모바일 UA(Android·iOS)는 `m.map.kakao.com/scheme/route?sp=&ep=위도,경도&en=이름&by=car`로 302** — 카카오가 공식 「모바일웹 스킴」으로 넘긴다. 이 스킴은 앱이 있으면 앱의 자동차 길찾기를, 없으면 모바일웹 길찾기를 연다(apis.map.kakao.com/android_v2 URL Scheme 문서). 출발지 `sp`가 비어 있어 현재 위치에서 출발한다 |
| 수단 지정 링크 | `https://map.kakao.com/link/by/car/출발,…/도착,…` | 출발지가 필요하다. 한 점만 주면 그 점이 **출발지**로 들어간다(실제 302 확인) → 쓰지 않는다 |
| 장소 id 길찾기 | `https://map.kakao.com/link/to/{placeId}` | 도착지가 비어 `?target=car`만 남는다(실제 302 확인) → 쓰지 않는다 |
| 앱 스킴 | `kakaomap://route?ep=위도,경도&by=CAR` | 앱이 있으면 가장 빠르다. 없으면 iOS Safari는 「주소가 유효하지 않음」 오류, 인앱 브라우저는 막거나 무시한다. 설치 여부를 웹에서 알 수 없다 |
| 안드로이드 intent | `intent://route?…#Intent;scheme=kakaomap;package=net.daum.android.map;S.browser_fallback_url=…;end` | 크롬은 미설치 때 대체 URL로 가지만 iOS에는 없다. 플랫폼마다 링크를 따로 만들어야 한다 |

## Decision

### 1. 카드에서 한 탭으로 자동차 길찾기

1. **링크**: `https://map.kakao.com/link/to/{이름},{위도},{경도}` 하나만 쓴다. 앱 설치 여부·iOS/Android·PC·인앱 브라우저를 카카오가 알아서 가른다(위 조사: 모바일은 공식 모바일웹 스킴으로, PC는 자동차 탭으로). 우리 쪽에서 UA를 보고 스킴을 고르지 않는다 — 실패했을 때 빈 화면·오류 대화상자가 차 안에서 가장 나쁘다.
   - 이름은 `cleanName`(괄호 별칭 등 정리) 뒤 쉼표를 공백으로 바꾼다(쉼표는 링크의 구분자). URL 인코딩.
   - **좌표가 없으면**(유한수가 아니거나 제주 밖) 지금의 검색 링크(`link/search/제주 {이름}`)로 대신한다. 지금 2,964곳은 모두 좌표가 있다.
2. **카드 배치**: 카드 이름·사진(카드 전체 링크)은 **지금처럼 장소 페이지**로 둔다. 우리는 운영시간·가격을 보이지 않으므로 「가기 전에 열었나」를 확인할 곳이 필요하고, 사람들은 이름을 누르면 정보가 나오리라 기대한다. 대신 카드마다 **`길찾기` 글자 버튼**(`a.tbtn.go`)을 메타 줄 아래, 예약 링크 위 **카드 폭 전체 줄**에 둔다. 결과 카드 3장과 저장한 곳 줄 모두.
   - 누름 높이 48px(design.md T2: 자주 누르는 대상), 그린 모양은 다른 `.tbtn`과 같은 밑줄 글자. 카드 링크 위(`z-index: 1`). 왼쪽 마진 -8(글자가 카드 왼쪽 선에).
   - 이름: `{이름}, 카카오맵 자동차 길찾기`(스크린리더). 화면 글자는 `길찾기` 세 글자뿐 — 320px에서도 넘치지 않는다.
   - 사용 기록(ADR-0061)은 `map`으로 센다(새 이벤트 이름을 만들지 않는다 — 둘 다 「카카오맵으로 나갔다」).
3. **`카카오맵` 문구**: 첫 카드 메타 끝의 `카카오맵`(카드를 누르면 어디로 가는지)은 **그대로 둔다**. 카드 탭이 여전히 카카오맵 장소 페이지라서 맞는 말이고, 원칙 6(「지도 목적지는 한 화면에 한 번」)도 그대로다. `길찾기`는 버튼 글자가 스스로 말한다.

### 2. 차 안 사용 전제 (design/SPEC.md 1절 원칙 13)

**고르는 사람은 동승자, 운전자는 길 안내만 본다.**
- 운전 중 읽거나 입력해야 하는 기능을 만들지 않는다. 운전자가 보는 화면은 카카오맵 내비뿐이다.
- 첫 탭은 한 탭(기분 하나 → 카드 3장), 카드에서 길 안내까지 한 탭(`길찾기`).
- 자주 누르는 대상은 누름 영역 48px 이상을 지킨다(design.md T2).

### 3. AI 에이전트가 읽고 바로 결과로 보내기 (agent-ready)

1. **딥링크 쿼리**: `/?mood=walk&area=aewol&reach=drive30&date=2026-10-03&indoor=1`.

   | 키 | 값 | 뜻 |
   |---|---|---|
   | `mood` | `rest` · `walk` · `new` · `food` · `any` | 기분(화면 이름과 1:1, `any` = 아무거나 골라줘). 있으면 바로 결과 화면 |
   | `area` | 세부 지역 슬러그 15개(`specs/seo-landing.md`) 또는 `here` | 기준. 슬러그면 그 지역 중심(위치 권한 묻지 않음), `here`면 지금 위치(지금처럼 권한을 묻는다) |
   | `reach` | `walk` · `drive30` · `drive60` | 얼마나 |
   | `date` | `YYYY-MM-DD` | 언제. 오늘이면 지금, 내일~1년 뒤면 그날, 그 밖은 무시 |
   | `indoor` | `1` / `0` | 비 와요(실내만) 켬/끔 |

   - 지역 한글 키(`애월`, `서귀포시내`)도 받는다. 슬러그가 정본이다.
   - **틀린 값은 그 키만 버린다**(나머지는 적용). 모르는 키는 무시. 아무 키도 맞지 않으면 링크가 없던 것과 같다.
   - **적용 = 사용자가 기준 시트에서 고른 것과 같다**: 기준·지역·얼마나·언제는 기기에 저장되고, 실내는 세션에만(ADR-0065). 그다음 `mood`가 있으면 그 기분을 누른 것과 같다(결과 화면 history 항목 push, 요청, 세션 기록, 사용 기록 `tap`).
   - 없는 키는 지금 저장된 값을 그대로 쓴다(기준을 안 주면 저장된 기준, 처음이면 지금 위치).
   - **주소에서 바로 지운다**(`#s=` 백업 링크와 같은 방식, replaceState로 쿼리만). 그래서 새로고침·뒤로가기·앞으로는 기존 규칙(세션 복원 S54, history 11.3)을 따른다. 결과 화면 기록이 있는 항목으로 마운트되면(새로고침) 링크 값은 쓰지 않는다.
   - `#s=` 백업 링크와 함께 오면 둘 다 적용한다.
   - 하위 탭(식사·카페, 섞어서·구경·체험)은 이번에 넣지 않는다(기본 탭으로 열린다).
2. **기계용 설명**:
   - `public/llms.txt`: 첫 줄 `# P의 여행`, 역할 한 줄(엔티티 문장, seo-analyst §0), 쓰는 법, 딥링크 표와 예시, 데이터 출처·라이선스(비짓제주(제주관광공사), 출처 표시 문구. **공공누리 유형은 적지 않는다** — ADR-0023 2026-10-01 갱신이 「공공누리 표시를 찾지 못했다」고 바로잡았고 공사 회신 전이다(`docs/licensing-visitjeju.md`). 대신 「공공누리 유형 미확인, 원문 재배포 안 함」을 적는다), 하지 않는 것(일정·코스, 평점·가격·영업시간, 광고·제휴 순위).
   - `index.html` JSON-LD: `WebSite` + `WebApplication`(audit-01 a-2 초안) + `potentialAction: SearchAction`(`EntryPoint.urlTemplate` = 딥링크 틀). 이름은 지금 이름 「P의 여행」, title·description·색은 바꾸지 않는다(이름·색 결정 대기).
   - `robots.txt`: 지금 `User-agent: * / Allow: /`가 AI 크롤러(OAI-SearchBot·ChatGPT-User·PerplexityBot·ClaudeBot·Claude-SearchBot·Google-Extended)를 모두 허용한다. 바꾸지 않는다(seo-analyst §4 「이름을 따로 적을 필요 없다」). Cloudflare 대시보드의 AI 크롤러 차단은 배포 직후 따로 확인한다.
   - seo-analyst §4에 딥링크·llms.txt 한 줄을 더한다(규칙의 단일 출처).
3. **하지 않는 것(나중 후보)**: 공개 API(장소·추천 JSON), MCP 서버(에이전트가 직접 3곳을 받아 가는 도구). 정적 호스팅·무료 운영(ADR-0063)과 라이선스(비짓제주 원문 재배포 쟁점, `docs/licensing-visitjeju.md`)를 먼저 풀어야 한다. 사용 기록에서 딥링크 유입이 보이면 다시 본다.

## Consequences

- 카드가 한 줄(48px) 길어진다. `다른 3곳 보기`는 끝에 붙어 떠 있으므로 닿는 거리는 같다.
- `길찾기`는 걸어서 가는 카드(1km 안, `걸어서 약 N분`)에도 자동차 길찾기를 연다. 웹 링크로 수단을 「도보」로 지정하려면 출발지가 필요해서다(위 조사). 카카오맵에서 도보 탭 한 번이면 바뀐다.
- 우도·비양도 등 섬 카드는 카카오가 배편 구간을 어떻게 안내하는지 우리가 정하지 못한다.
- 실기기(iOS 사파리·카카오톡 인앱·안드로이드 크롬, 앱 있음/없음) 확인은 배포 뒤 체크리스트(`docs/deploy.md`)로 남긴다. 이 환경에서는 302 응답까지만 확인했다.
- 딥링크로 열면 저장된 기준이 바뀐다(시트에서 고른 것과 같다). 다시 바꾸는 길은 기준 시트 그대로다.
- 상세는 `specs/drive-and-agents.md`.
