# ADR-0087: 「가 봤어요」로 그곳을 이 기기에서만 후보에서 뺀다

Status: Accepted (2026-10-14, 주인이 스펙 요지 승인). ADR-0061의 이벤트 이름 목록을 늘린다(ADR-0085와 같은 방식). **보이는 이름(「뺀 곳」)과 되돌리는 길(3)은 ADR-0090이 개정했다**(2026-10-16, 아래 Amendment).
Amended by ADR-0097 (2026-10-19): `jeju.visited`는 두 여행지가 같이 쓴다. 다른 여행지 id는 지우지 않고, 「가 본 곳 N곳」은 지금 여행지 데이터에 있는 것만 센다.

## Decision

1. 결과 카드마다 글자 버튼 「가 봤어요」를 둔다. 누르면 그곳은 다음 뽑기부터 이 기기의 후보에서 빠진다. 다시 누르면 되돌린다.
2. 뺀 곳은 이 기기 저장소(`jeju.visited`, 장소 id 배열. 데이터의 `hide`(폐업 숨김, ADR-0074)와 섞이지 않게 이름을 따로 둔다)에만 둔다. 저장소가 없거나 오류가 나면 이번 방문 동안 메모리로 동작하고, 앱은 그대로 쓸 수 있다.
3. 되돌리는 길은 두 가지다. 같은 카드에서 다시 누르거나, 저장한 곳 화면 아래 「뺀 곳 N곳」에서 하나씩 또는 모두 되돌린다.
4. 빼는 범위: 결과 카드, 홈 기분 줄 「예:」, 노을 볼 곳 묶음과 그 수, 오늘 장 서는 곳. 저장한 곳 목록과 랜딩·장소 페이지에는 적용하지 않는다.
5. 측정: 자체 기록에 `visited`·`unvisited`(장소 id만)를 남긴다. 중단 기준(미리 등록): 배포 8주 뒤 `visited`가 10건 미만이면 버튼을 뺄지 다시 본다. 「실수로 뺐다」는 제보가 1건이라도 오면 자리를 다시 본다.

## Consequences

- 카드 아래 줄이 조금 무거워진다. 320·390 스크린숏으로 확인한다.
- 개인정보 안내의 「이 기기에만」 목록과 사용 기록 목록에 한 줄씩 더한다.
- 뺀 곳이 많으면 넓히기가 더 자주 일어나 차로 걸리는 시간이 길어질 수 있다. 그 사실은 지금의 상태 줄 문구가 그대로 알린다.

## Amendment (2026-10-16, ADR-0090)

- 보이는 이름: 저장한 곳 화면의 `뺀 곳 N곳` → `가 본 곳 N곳`(카드의 「가 봤어요」와 이어지게), `뺀 곳 N곳을 모두 다시 넣었어요.` → `가 본 곳 N곳을 …`. `다시 넣기`·`모두 다시 넣기`, 저장 키(`jeju.visited`)·이벤트(`visited`·`unvisited`)·내부 이름은 그대로다.
- 3(되돌리는 길)에 하나를 더한다: 누른 자리 상태 줄 `{이름}은 다음부터 빼고 골라요.` 옆 글자 버튼 `되돌리기`(다시 누른 것과 같다). 설정 입구는 결과 화면 맨 아래에도 있다(`설정 · 지도 앱 · 의견`).
- 「가 봤어요」는 체크 자리를 미리 둬 누르기 전후 폭이 같다.
