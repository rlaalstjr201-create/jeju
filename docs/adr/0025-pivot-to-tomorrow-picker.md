# ADR-0025: "내일 뭐하지" 파트너로 방향 전환

Status: Accepted (2026-09-30)

Superseded in part by ADR-0028·ADR-0059 (2026-09-30): 기분 버튼 4개·「맛집 범위 밖」은 ADR-0028이, 대상 순간 「내일」과 마무리 날짜는 ADR-0059(「지금」)가 대체했다. 나머지 갱신은 본문 끝 「Updated by ADR-0058」.

## Context

처음 의도는 "첫 화면이 숨 막히지 않는, 계획 안 세우는 사람을 위한 편한 여행 도구"였다. 진행하면서 큐레이션 앱으로 변했고, 더 많은·더 정확한 정보 수집에 매달리게 됐다. 사용자 없이 범위만 커지고 마무리가 안 되는 상태.

기준이 된 실제 경험: 유럽 자유여행 중 계획 없이 다니다가 밤에 "내일 뭐하지?" 싶으면 있는 도시를 검색해 체험·입장권을 골라 산다.

## Decision

**대상 순간**: 여행 중 "내일(또는 오늘 오후) 뭐하지?" 하는 순간. 사전 여행 계획·일정 짜기는 대상이 아니다.

**원칙**: 기존 자산은 쓸 수 있으면 쓰되 거기에 맞추지 않는다. 기준은 "계획을 자세히 세우지 않는 사람이 마음 편히 쓰는 여행 파트너".

**핵심 흐름**:
1. 앱을 연다 → 기분 버튼 4개: **푹 쉬고 싶어 / 좀 걷고 싶어 / 새로운 거 해보고 싶어 / 아무거나 골라줘**
2. 한 번 탭 → 근처 할 거리 3~4개 카드
3. 카드 = 사진, 이름, 추천 이유 한 줄, 차로 몇 분 (가격·운영시간·평점 없음)
4. 하나를 고르면 끝 — 길찾기는 카카오맵/네이버지도, 유료는 클룩·마이리얼트립 링크로 넘긴다

**위치**: 기본은 내 위치(GPS). "내 위치 ↔ 숙소" 전환 버튼, 숙소는 전환을 처음 누를 때만 검색해 등록하고 기억한다. 위치 권한 거절 시 지역 선택(제주시/서귀포/동쪽/서쪽).

**범위 밖**: 앱 내 예약·결제, 일정 짜기(DayPlan/ScheduleComposer), 맛집(음식 버튼 없음), 추가 데이터 수집.

**마무리 기준**:
1. 배포 링크를 폰에서 열면 바로 기분 버튼 4개가 보인다 — 2026-10-14까지
2. 제주 어느 지역에서 눌러도 4버튼 모두 카드 3개 이상 (부족하면 반경 확대, 데이터 추가 수집 금지) — 2026-10-14까지
3. 제주 가는 지인 1명 이상이 여행 중 실제로 써 본다 — 2026-10-30까지

## Consequences

- 큐레이션·일정 관련 기존 도메인(Shortlist, Trip, DayPlan, 추천 엔진, 트렌드 발굴)은 이 방향에서 쓰지 않는다. 코드는 지우지 않고 둔다.
- `docs/context.md`의 기존 정의는 이 ADR과 충돌하면 이 ADR이 우선한다.
- 관련 결정: ADR-0026(로그인 없음), ADR-0027(모바일 웹 + 고정 데이터).

Updated by ADR-0058 (2026-09-30): 기분 버튼 4개 → 5개(먹기 포함, ADR-0028), 카드 3~4개 → 3장, 숙소는 검색이 아니라 GPS 또는 지역 선택, 지역 4개 → 15곳(ADR-0029), 유료 링크는 마이리얼트립만(`bookable`). 마무리 기준의 "4버튼"도 5버튼으로 읽는다.
