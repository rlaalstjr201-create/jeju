# ADR-0028: 맛집 포함 + 보유 데이터 전 항목 검수

Status: Accepted (2026-09-30) — ADR-0025의 "맛집 범위 밖"과 기분 버튼 4개 부분을 대체

## Context

ADR-0025 이후 첫 빌드에서 카드로 쓸 수 있는 스팟은 275곳이었다. 추천 이유 문장이 있는 곳만 썼고 맛집을 뺐기 때문이다. 보유 후보는 3천여 곳이다. 사용자 결정: 맛집 앱과의 경쟁은 신경 쓰지 않고, 가진 데이터를 전부 하나씩 검수해 쓴다.

## Decision

- **맛집 포함.** 기분 버튼 5개: 푹 쉬고 싶어 / 좀 걷고 싶어 / 새로운 거 해보고 싶어 / **맛있는 거 먹고 싶어** / 아무거나 골라줘.
- **전 항목 검수.** 사전 필터(좌표·https 사진·경고 표시)를 통과한 보유 스팟 전부를 한 곳씩 검수해 쓸지/뺄지, 기분, 추천 이유 한 줄을 정한다. 이유 문장은 보유 텍스트(요약·소개·기존 코멘트)만 근거로 쓴다 — 새 수집 없음.
- **지도 링크 폴백.** 카카오 장소 ID가 없으면 카카오맵 이름 검색 링크(`https://map.kakao.com/link/search/{이름}`)로 연결한다.
- **아무거나 골라줘** = 쉬기·걷기·새로운 것에서 한 장씩. 먹기는 섞지 않는다 — 맛집은 "맛있는 거 먹고 싶어" 버튼으로만 나온다(2026-09-30 수정).
- 검수 방법론과 모델 배정은 `plans/tomorrow-picker.md`의 "전 항목 검수" 절을 따른다.

## Consequences

- 카드 후보가 수백에서 수천 곳으로 늘어난다.
- 영업 여부 등 현재성은 확인하지 않는다(ADR-0025: 정확도에 매달리지 않음). 판단은 보유 텍스트 범위 안에서만 한다.
