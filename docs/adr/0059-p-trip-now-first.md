# ADR-0059: 이름 "P의 여행", 기준 순간 "지금", 날짜별 보관(약식 플래너)

Status: Accepted (2026-09-30)

## Context

ADR-0025는 대상 순간을 "밤에 내일 뭐하지?"로 잡았고 화면도 "내일은 어떤 기분이에요?"로 묻는다.
사용자의 실제 의도는 MBTI P 여행자가 계획 없이 다니다 "지금 여기서 뭐하지?" 할 때 켜는 여행 파트너다.
날짜별로 카드를 모아 두는 약식 플래너 요구도 나왔지만, 기간 입력·일차 탭은 ADR-0025가 피한 "일정 짜기"로 되돌아갈 위험이 있다.

## Decision

1. **이름**: 앱 이름 `P의 여행` (manifest name·short_name, `<title>`, 설명 문구).
2. **기준 순간**: 기본은 "지금". 첫 화면 질문과 날짜 줄은 지금·오늘 기준으로 쓴다. 위치 기준(여기·숙소·지역)은 지금처럼 바꿀 수 있다.
3. **날짜별 보관(날짜 모드)**: 같은 날 사용자 요청으로 v2로 미루지 않고 이번에 함께 넣는다. 상세는 `specs/date-mode.md`.
   - 여행 기간 입력 없음. 첫 화면은 늘 "지금 여기".
   - 상단 기준에 날짜(오늘·내일·날짜 고르기)를 더하고 위치는 내 위치 또는 직접 정한 곳.
   - 하트는 그때 기준 날짜에 보관(지금 모드는 오늘). 저장 목록은 저장이 있는 날짜별로 묶는다.
   - 날짜 안 순서 바꾸기(위·아래 버튼), 다른 날로 옮기기, 삭제. 시간대·동선 없음.
4. **배포 시점**: 고정 날짜(10/14·10/30) 대신 "어느 정도 완성되면" 배포한다. 판단은 사용자가 한다.

## Consequences

- ADR-0025의 대상 순간("내일")과 마무리 날짜를 대체한다. 흐름(기분 → 카드 3장 → 외부 지도)은 그대로다.
- 날짜 모드 Light Spec: `specs/date-mode.md`.
