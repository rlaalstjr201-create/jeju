# ADR-0079: 주간 SEO·순위 운영 — 측정은 기계가, 고침은 커밋까지, 배포는 사람이

Status: Accepted (2026-10-03). `.claude/skills/seo-geo/references/measurement.md` 「주기」 표의 사람 몫(주 1회 순위 기록)을 자동화로 바꾼다.

## Context

사용자 요구: SEO·GEO를 주기적으로 점검하고 업데이트하는 에이전트를 둔다. 검색어 순위에서 밀리지 않게 업데이트하는 기능도 있어야 한다. 사용자 결정(2026-10-03): 매주 월요일 아침 이 PC에서 돈다. 고치고 커밋까지는 자동으로 하고, 배포·push는 사람이 승인한다.

조회 경로 확인(2026-10-03):
- **네이버 검색 결과**: curl은 403이다. Claude in Chrome과 앱 내장 브라우저는 네이버 도메인을 안전 제한으로 막는다. 로컬 Playwright 브라우저는 열린다.
- **구글 순위**: GSC API에는 서비스 계정이 필요한데 지금은 없다. 대신 GSC 실적 화면은 로그인된 크롬으로 읽을 수 있다.
- **구글 검색 결과를 직접 긁는 것**은 약관 위반이고 막히기 쉬워서 하지 않는다.

## Decision

1. **순위 측정**(주 1회):
   - **네이버**: `scripts/seo/rank-naver.mjs`가 Playwright로 target·watch 검색어를 검색한다. 통합검색에서 우리 주소가 처음 나오는 블록과 순위를 기록하고, 없으면 「없음」으로 기록한다. 쿼리 사이에 간격을 두고, 막히면 「확인 실패」로 기록한다.
   - **구글**: 주간 작업이 크롬으로 GSC 「실적 → 검색어」(지난 7일)를 읽어 `data/seo/gsc/YYYY-MM-DD.json`에 저장한다. `scripts/seo/gsc-import.mjs`가 이를 검증해 `keywords.json` `track[]`에 넣는다.
   - 서비스 계정이 생기면 `gscLayerStats`로 바꾼다.
2. **판정**: 기존 사전등록 규칙 `pivotOf`(measurement.md)를 그대로 쓴다.
   - 「밀림」 경보는 지난주보다 3계단 넘게 내려가거나, 10위 안에서 밖으로 나가는 경우다. 경보가 나면 push 또는 meta 조치 후보로 올린다.
   - 신규 4주 안에는 판정하지 않는다(흔들림 구간).
3. **조치 범위**:
   - **자동으로 하는 것**(테스트·`check:slop`·`seo:crawl`·`seo:verify` 통과 시 로컬 커밋까지):
     - 판정이 meta일 때 title·description 고침.
     - 판정이 push일 때 내부 링크와 본문 보강.
     - 구조화 데이터·llms.txt 정합.
     - 사이트맵·IndexNow 갱신.
   - **제안만 하는 것**:
     - 새 랜딩 페이지 만들기.
     - 검색어 target·kill·pivot 바꾸기.
     - 브랜드 문장 바꾸기.
     - ADR이 필요한 변경.
4. **IndexNow**: 키 파일을 공개 폴더에 두고, 배포 뒤 바뀐 URL만 네이버와 IndexNow API에 알린다. 「IndexNow를 쓰기 시작한 뒤 추가·변경된 URL만」 규칙을 따른다.
5. **보고**: `docs/seo/weekly/YYYY-MM-DD.md`에 순위 표, 판정, 한 일, 승인 대기 항목, 확인 실패 항목을 쓴다. 분석 리포트(ADR-0078 6) 링크도 단다.
6. **정직성**: 막힌 조회는 「확인 실패」로 남기고 0이나 「없음」으로 바꾸지 않는다. 결과를 바꾸려고 같은 측정을 다시 돌리지 않는다.

## Consequences

- 주간 작업이 Playwright·크롬·wrangler를 쓰므로 이 PC에서 Claude 앱이 켜져 있어야 한다. 꺼져 있으면 다음에 켤 때 돈다.
- 「순위가 밀리지 않게」는 보장이 아니라 감지와 대응이다. 신규 사이트라 첫 4주는 기준선을 쌓는 기간이다.
