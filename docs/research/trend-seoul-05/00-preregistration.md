# 트렌드 05 — 유료 AI 없이, 규칙 추출을 고치면 후보 재현율이 오르나 (사전등록)

작성 2026-11-04 KST, 실행 전에 커밋한다. 커밋 뒤에는 규칙·판정·결론 규칙을 바꾸지 않는다. 추출은 한 번이다.

## 묻는 것

트렌드 04: 넓게 받은 글·영상에 기준 목록의 93.5%가 있었지만(R1), 규칙 추출 후보 목록에는 54.8%만(R2), 상위 100개 중 51개가 잡음.
주인 조건(2026-11-04): 「외부 api로 계속 해야되는 작업이면 못하지」 — 매일 비용이 드는 유료 AI 추출은 쓰지 않는다.
**같은 원자료(04의 `02-posts.json`과 03의 유튜브)에서, 비용 없는 규칙 v2로 R2와 정밀도가 얼마나 오르나?**

## 공정성

- 실행자는 04 판정의 **놓친 이유 유형**(「… 팝업」 꼴 아님, 1건뿐, 일반어·날짜 잡음, 앞말이 붙어 갈림)만 보고 규칙을 고쳤다.
  기준 목록 항목 이름은 보지 않았다. 그래도 같은 기준 목록으로 재므로 **과적합 위험이 있다** — 결과에 적고, 다음 실제 운영 전 다른 날짜로 다시 잰다.
- 원자료는 새로 받지 않는다(04 그대로).

## 규칙 v2 (`extract-v2.mjs`)

1. 이름 꼴 늘리기: 「X 팝업(스토어)」에 더해 「X 콜라보 카페」「X 팝업 카페」「X 전시(회)」「X 스토어 오픈」「X 체험존」,
   제목 안 괄호 이름(「」『』[] < >)이 팝업·전시·오픈과 같은 제목에 있을 때.
2. 잡음 거르기: 날짜(○월, ○일, 2026년), 숫자만, 일반어 목록(브랜드·뷰티·패션·단독·오프라인·체험형·신규·한정·이색·인기 등),
   꾸밈말로 시작하는 조각(열린·진행된·마련된·선보인·○에서), 끝 조사(에서·의·가·이·을·를·와·과·도) 떼기.
3. 이름 합치기: 정규화 키가 다른 키를 품고 짧은 쪽이 3자 이상이면 같은 후보로 합친다(긴 쪽 표기 유지).
4. 지역: 「용산 팝업」 검색어 글은 지역을 정하지 않는다(반경 밖 아이파크몰 문제). 글 본문에 지역 지명(성수·연무장·서울숲 / 홍대·연남·합정 /
   이태원·한남)이 있으면 그 지역, 없으면 검색어의 지역.
5. 남기는 기준: 10-15 이후 서로 다른 글·영상 2건 이상(04와 같음).

## 판정 (새 Opus 하위 에이전트, 이전 판정자와 다름)

- R2 후보 재현율(성수 23·홍대 8, 이태원 따로), 04 대비 새로 잡은 것·잃은 것.
- 상위 100개 중 비이름 비율, 정밀도(04와 같은 표본 규칙: 0번부터 45개 간격, 비이름은 건너뛰고 수를 셈, 웹 확인 최대 20회).

## 미리 정한 결론 규칙

- **R2 70% 이상이고 상위 100개 비이름 25% 이하** → 규칙 v2 + 매일 쌓기 + 주 1회 검수(구독 안의 예약 작업)로 2단계 작은 판을 설계한다.
- **R2 55~70%** → 규칙을 한 번 더 고치는 대신, 검수 단계(사람 또는 예약 작업)를 필수로 둔 판을 검토한다.
- **R2 55% 미만** → 규칙으로는 한계. 트렌드 층은 「검수가 중심인 큐레이션」으로만 가능하다고 결론 내고 주인과 정한다.
