# 트렌드 05 — 결과

- **R2 후보 재현율 58.1%(18/31)** — 성수 14/23, 홍대 4/8. 04(54.8%)보다 1개 늘었고(미리위크, 경계 판정), 잃은 것 없음. 새 이름 꼴로는 하나도 늘지 않았다.
- 상위 100개 비이름 37%(04 51%) — 줄었지만 25% 조건은 못 맞춤. 정밀도 15.4%(확인 실패를 맞음으로 쳐도 30.8%).
- 결론 규칙: **55~70% → 규칙은 더 고치지 않고, 검수 단계를 필수로 둔 판을 검토한다.** 실행자 예상(R2 65~75%, 비이름 25~35%)은 R2에서 틀렸다.
- 조사 떼기 결함: 이름 약 30개가 잘렸지만 R2·정밀도 손실은 0(표시 품질과 중복 문제).
- 종합(01~05): 정보는 무료 출처(네이버 블로그·뉴스, 유튜브)에 93.5% 있다. 막히는 곳은 「글에서 지금 하는 팝업을 골라내는 판단」이고, 규칙은 55~58%에서 멈췄다.
