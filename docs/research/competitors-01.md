### 강점 / 약점

- 강점: 데이터 폭(2.5만), 「오늘·지금 제주 뭐하지」 문장 선점, 실시간 실용 정보(물때·여객선·오일장·심야약국·응급실), 프로그램 SEO 규모, 로그인 없는 찜, 무장애 정보.

| 5 | 날씨 한 줄(비·일몰 시각)로 카드 우선순위 보정 | 「지금」 맥락 강화 | 중(기상청 API 키, 외부 요청 추가) | ADR-0058 외부 요청 원칙 확대 → 새 ADR 필요 |
| 6 | 무장애 정보(TourAPI 무장애 여행 서비스) | 차별 데이터, 전국 확장 때 같은 API | 중 | ADR-0062 범위 안(TourAPI) |
| 7 | 오일장 날짜(끝자리 규칙) 같은 「오늘만」 정보 | 싸고 「오늘」 맥락에 강함 | 낮음 | 정적 규칙, 문제 없음 |
| 8 | 네이버 서치어드바이저·Bing 인증, sitemap 제출 | 오늘제주도 했음. 기본기 | 낮음 | 없음 |

### (b) 우리가 지킬 것

- **3장**: 오늘제주·지도앱은 모두 수십 곳 목록을 준다. 「고르지 않아도 되는 3장」은 아무도 안 한다.
- **기분 1탭**: 자연어 입력·폼 없음. 오늘제주 AI 검색은 「산책」을 숙소·병원으로 풀었다 — 자유 입력은 틀릴 때 신뢰를 잃는다.
- **이동 시간 범위(걸어서/30/60분)**: 경쟁자는 km 반경. 여행자는 분으로 생각한다.
- **평점·가격·광고 없음, 조용한 화면**: 오늘제주는 업주 입찰 우선 노출로 갈 예정. 「광고 없는 추천」은 문장으로 쓸 가치가 있다.
- **P 포지션 + 날짜별 약식 보관**: 오늘제주·NOL·「P들의 여행」은 모두 AI 일정·동선(J 도구)으로 간다.
- **로그인 없는 저장 + 출처 표시(공공누리)**: 데이터 권리 리스크가 없다.

### (c) 피할 것

- 네이버 등 타사 **리뷰 원문·평점 복제**, 타사 리뷰 기반 AggregateRating 마크업.
- `/search/제주렌트카` 같은 **검색량만 노린 헤드 키워드 대량 페이지** — 얇은 콘텐츠로 품질 평가를 깎고, 우리 재고(2,955곳)와 의도가 맞지 않는다.
- 업주 유료 우선 노출 → 3장의 신뢰가 무너진다.
- 홈에 섹션 9개·카테고리 20종 — 「조용한 화면」과 정반대.
- 자유 자연어 AI 검색을 주 입력으로 두는 것(네이버·카카오가 같은 걸 더 잘 한다).
- 「P들의 여행」과의 이름 혼동 방치: 브랜드 검색에서 앱스토어 결과가 섞인다(keyword-research-01의 yes24 동명 도서와 함께). 이름 결정 자체는 사용자 판단 사항으로 남긴다.

### 전국 확장 관점

- 전국을 덮는 쪽: 네이버지도 에이전트·카카오맵 카나나·티맵(위치·대화형, 업종 전체), NOL(예약), 대한민국 구석구석(공식 콘텐츠). 이들은 「근처 + 조건」을 이미 하므로 **전국에서 데이터 폭으로는 이길 수 없다.**
- 오늘제주는 「제주만 깊이」를 업주 영업 문구로 쓰고 있어(https://onuljeju.com/for-owners) 당분간 제주 밖으로 안 나올 가능성이 크다.
- 우리 차이: 같은 TourAPI 출처라도 **심사 → 한 줄 이유 → 만족도 점수 → 3장**이라는 고르는 방식이 지역마다 똑같이 적용된다(ADR-0062). 확장 시 내세울 것은 지역 수가 아니라 「어느 지역에서 켜도 3장」이다. 부산·강릉·경주처럼 차로 이동하는 관광지가 이 방식에 맞는다(ADR-0062 4와 일치).
