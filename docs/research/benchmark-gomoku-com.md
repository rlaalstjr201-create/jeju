# 벤치마크: gomoku.com — 왜 「오목」 1위인가, 우리가 배울 것

작성 2026-10-12. 주인 관찰: 크롬에서 「오목」을 치면 gomoku.com이 맨 위, AI로 만들었다고 들음. 직접 본 것(모바일 375px, 2026-10-12)과 공개 기록(RDAP·Wayback·사이트 자체 개발 로그)만 근거로 쓴다.

## 한 줄 결론

1위의 가장 큰 이유는 **27년 된, 검색어와 철자가 같은 도메인과 그 이력**으로 보이고, 사이트 자체는 SEO 기교가 거의 없다(글 약 700자, 구조화 데이터 없음). 우리가 가져올 수 있는 건 도메인이 아니라 **「들어오자마자 핵심 행동」, 「사람이 있다는 신호」, 「언어별 진짜 페이지」, 「꾸준한 출시 기록」**이다.

## 왜 노출이 높은가 (근거 강도 순)

1. **정확일치 + 오래된 도메인과 이력(강함).** 검색어 「gomoku」와 같은 .com을 1998년부터 오목 사이트로 써 온 이력이 있어 예전 링크·신뢰가 쌓였을 가능성이 크다. 지금 운영자가 산 건 이 자산이다. 우리는 따라 할 수 없다.
2. **검색 의도와 결과가 정확히 같다(강함).** 「오목」을 치는 사람은 오목을 두고 싶다. 페이지에 들어오자 2번 탭으로 둔다 → 바로 나가지 않고, 오래 머물고, 다시 온다. 이런 만족 신호가 순위를 지킨다(추정이지만 일관됨).
3. **언어별 진짜 페이지(중간).** 번역만 한 게 아니라 각 언어 title·description에 그 나라 검색어(「온라인 오목 무료」)가 들어 있고, hreflang으로 묶였다. 한국어 「오목」 검색에 한국어 페이지가 바로 걸린다.
4. **같은 운영자의 게임 도메인 묶음과 상호 링크(중간, 추정).** 다섯 개 이상의 게임 이름 도메인이 서로 링크한다. 링크·브랜드 신호를 나눠 가진다.
5. **꾸준한 갱신(약함).** 개발 로그에 3~8주 간격 출시. 사이트맵 lastmod도 갱신된다.

글 양·구조화 데이터·블로그 같은 흔한 SEO 수단은 거의 쓰지 않았다. 즉 이 사이트의 순위는 「콘텐츠 기교」가 아니라 **도메인 자산 + 검색 의도를 바로 채우는 제품**에서 나온다.

## 왜 잘 쓰이는가

- **목적 행동까지 2탭, 로그인 없음.** 회원은 랭킹·친구용으로 뒤에 붙였다(출시 두 달 뒤).
- **혼자서도, 같이도.** 싱글로 들어온 사람에게 「누가 기다린다」를 계속 보여 온라인으로 옮긴다. 사람이 있다는 신호(접속자 수)가 첫 화면에 숫자로 있다.
- **광고가 놀이를 막지 않는다.** 판 사이(다시 시작·되돌리기)에만.
- **반복 사용 구조.** 한 판이 짧고 끝나면 또 한다. 랭킹·업적이 다시 오게 한다.

## 우리에게 주는 교훈

| # | 교훈 | 우리에게 맞나 | 할 수 있는 것 |
|---|---|---|---|
| L1 | 첫 화면 = 핵심 행동, 탭 수 최소 | 이미 같은 원칙(기분 1탭 → 3곳 → 길찾기). 휴리스틱 점검에서도 「바꾸면 안 되는 것」 | 지킨다. 앞으로 첫 화면에 무엇을 더할 때마다 「핵심 행동까지 탭 수」를 잰다 |
| L2 | 「사람이 쓰고 있다」는 신호 | 우리는 혼자 쓰는 도구라 대전 알림은 맞지 않음. 다만 신뢰 신호가 첫 화면에 없다 | 자체 기록(D1)으로 「오늘 이 동네에서 N명이 길찾기를 열었어요」 같은 익명 집계를 보일지 — 개인정보 원칙(시각·기기 없음) 안에서 가능한지 검토 필요(새 ADR) |
| L3 | 검색 의도와 같은 이름·제목 | 「오목」은 단일 검색어, 우리는 「제주 ○○ 근처 가볼만한곳」처럼 긴 검색어 다수. 동네 페이지(/jeju/**) 2,938쪽이 이 역할 | 동네·기분 페이지 title이 실제 검색어와 맞는지 keyword gate(seo-analyst)로 점검 |
| L4 | 들어온 사람이 바로 만족 → 머무름·재방문 | 랜딩(/jeju/애월/)에서 앱까지 1탭(「앱에서 애월 근처 3곳 받기」) | 랜딩→앱 전환율과 재방문을 GA4로 본다(지금 측정 가능) |
| L5 | 언어별 진짜 페이지 | 2026-10-05 주인 결정: 당분간 제주·한국어만. 외국인 확장은 보류 | 지금은 하지 않음(결정 존중). 나중에 꺼낼 때 hreflang 구조 참고 |
| L6 | 정확일치 오래된 도메인 | 따라 할 수 없음(yeochana.com은 2026-10 신규) | 대신 시간이 필요하다는 기대치 조정: 새 도메인 색인·순위는 수주~수개월 |
| L7 | 공개 개발 로그·수치 | 우리도 결정 기록(ADR)이 많지만 사용자에게는 안 보임 | 「업데이트 소식」 한 페이지(무엇이 바뀌었나)를 둘지 — 신선도·신뢰 신호, 작은 비용 |
| L8 | 수익이 경험을 막지 않는 자리 | 수익화는 로드맵 10(제주관광공사 상업 이용 확인 뒤) | 그때 「판 사이」 원칙: 길찾기·고르기 흐름 중간에는 넣지 않는다 |

## 우리 규칙과 충돌 점검 (2026-10-12, 주인: 「무조건 적용 반대, 먼저 충돌 점검」)

| # | 교훈 | 부딪히는 규칙 | 판정 |
|---|---|---|---|
| L1 | 첫 화면 → 핵심 행동 탭 수 최소 | 없음. ADR-0075(홈 A′)·SPEC §2 원칙 2와 같은 방향 | **적용 가능**(이미 지키는 원칙. 새 규칙 아님) |
| L2 | 「사람이 쓰고 있다」 신호(익명 집계를 화면에) | ① ADR-0061 6: 모은 카운트는 **빌드 때 점수에 섞는 데만** 쓴다(화면 표시는 정해진 쓰임이 아님) ② ADR-0060 5: 인기도는 데이터가 쌓인 뒤 점수에 섞기로 이미 길이 있음 ③ ADR-0075: 첫 화면 구성(오늘 판·기분 줄·아래 두 묶음)이 정해져 있음 ④ 개인정보 안내: 보내는 항목만 적혀 있고, 남의 사용을 보여 준다는 약속은 없음 ⑤ 현실: GA4 주간 활성 26명(2026-10-05) — 「오늘 0명」은 역효과 ⑥ P 이해: 「꼭 가야 할 곳」 압박 금지 | **적용 안 함(보류).** 새 ADR·개인정보 안내 개정이 필요하고, 지금 숫자로는 목적을 못 이룬다. 인기도는 ADR-0060 5의 길(점수에 섞기)로만 |
| L3 | 검색어와 같은 제목 | ① ADR-0079 2: **신규 4주 안에는 판정하지 않는다** — yeochana.com 2026-10-08부터라 약 11-05까지 흔들림 구간 ② ADR-0079 3: title 고침은 주간 판정이 meta일 때만 자동, 검색어 target 바꾸기는 제안만 ③ ADR-0072 1: 조합 페이지는 keyword gate가 target으로 판정한 것만 | **지금은 손대지 않음.** 11월 초 주간 점검에서 seo-analyst 규칙대로만 |
| L4 | 랜딩 → 앱 전환·재방문 재기 | ADR-0072 9: 랜딩은 **스크립트 없음**(GA 없음) → 랜딩 쪽 조회는 못 잼. 앱 쪽 `?area=` 딥링크 진입은 GA4 page_location으로 셀 수 있음(ADR-0078) | **부분 적용**: 앱 쪽 진입만 잰다. 랜딩에 스크립트 넣기는 하지 않음(결정 위반) |
| L5 | 언어별 진짜 페이지 | 2026-10-05 주인 결정: 당분간 제주·한국어만 | **적용 안 함** |
| L6 | 새 도메인은 시간이 걸린다 | 없음(ADR-0079 4주 규칙과 같은 생각) | **기대치로만** |
| L7 | 「업데이트 소식」 공개 페이지 | 규칙 위반은 없으나 새 공개 페이지 = CLAUDE.md 워크플로(Light Spec → Plan) 대상. 문구는 check:slop·브랜드 문장 규칙(ADR-0079 3 「브랜드 문장 바꾸기는 제안만」) | **제안만.** 하려면 스펙부터 |
| L8 | 광고는 흐름 밖에 | ADR-0010(수익이 큐레이션에 영향 없음), ADR-0072 3(상업화 결정 시 사진 끄기 조건), 로드맵 10(공사 확인 뒤) | **원칙으로만 기록.** 수익화 자체가 아직 보류 |

정리: 지금 바로 적용할 것은 없다. L1은 이미 지키고 있고, 나머지는 결정(ADR)·주인 결정·측정 규칙에 막히거나 스펙이 먼저다.

## 하지 말 것

- 자매 도메인을 사서 서로 링크하는 방식(L4 자매 사이트)은 구글이 「링크 계획」으로 볼 수 있는 회색 지대이고, 우리 규모·목적과 맞지 않는다.
- 「AI로 만들어서 잘 됐다」는 결론: 근거 없음. 이 사이트의 차이는 만드는 도구가 아니라 도메인과 제품-검색 의도 일치에서 온다.

- 구글 「오목」 결과 1~10위 비교(SERP) — seo-analyst keyword gate 방식으로.
