# 맞대결 01 — 사실 확인 (판정 1)

작성 2026-11-03, 사실 확인 담당 하위 에이전트(실행자와 다른 에이전트). 어느 시스템이 나은지는 판단하지 않는다.

## 방법

- 대상: 30개 원문(`01-raw/sNN-*.md`)의 「답 전문」/「결과 화면 전문」에서 등장 순서로 처음 3곳. 여차나는 원문의 「처음 3곳」을 그대로 썼다.
- 좌표·실재·상태: **카카오맵** 장소 데이터(m.map.kakao.com 검색 결과와 place-api 장소 상세 — 상태 `status=Y`, WGS84 좌표, 「화(11/3)」 영업 표시)를 기본 근거로 삼았다. 보조로 OpenStreetMap(Nominatim) 좌표와 웹 검색을 썼다.
- 거리: 장면 좌표에서 장소 좌표까지 하버사인 직선거리(km, 지구 반지름 6371.0088). 길(올레 코스, 해안도로)은 원문이 가리키는 구간 중 장면에 가장 가까운 확인된 지점(시작·끝 지점)까지 쟀다.
- 「근처 아님」: 10km 초과. 5번·9번은 15km 초과.
- 변경 기록에 따라 「새벽 3시라 지금 닫힘」은 오류로 세지 않았다. 2026-11-03(화) 정기 휴무만 「화요일 휴무」로 적었다.
- `ok` 판정은 「카카오맵에 같은 이름·위치로 현재 등록(status=Y)되어 있고 휴무 표시가 없음」을 뜻한다. 카카오맵에 남아 있어도 실제로는 폐업했을 가능성은 남는다(한계).

### 추출 규칙에서 판단이 필요했던 곳

1. **경고·부정으로만 나온 장소는 세지 않았다.** 「피할 곳」(s02 Claude의 한담해안산책로), 「오늘은 화요일이라 경복궁이 휴궁」(s05 Claude)처럼 가지 말라고 한 장소는 「제시한 장소」가 아니라고 봤다. 그래서 s02 Claude는 추천 장소가 2곳뿐이다. 글자 그대로 세어도 한담해안산책로는 ok라 오류 수는 같다. s05 Claude의 경복궁은 그 답이 스스로 휴궁이라고 말했으므로, 넣어서 오류로 세는 것은 맞지 않다고 봤다.
2. **장면 자체 지역은 뺐다.** s09 ChatGPT 지도 카드의 1번 「Jeonju Hanok Village」는 사용자가 이미 있는 곳이라 건너뛰었다.
3. **도입 문단도 등장 순서에 넣었다.** s05 ChatGPT는 도입에서 「경복궁·북촌 … 청계천」을 먼저 꺼낸 뒤 목록(경복궁·국립현대미술관 서울관·청계광장)을 냈다. 등장 순서대로 경복궁·북촌·청계천을 썼다. 목록 3곳으로 바꿔도 국립현대미술관 서울관은 화요일 영업(카카오 10:00~18:00)이라 오류 수는 같다. s08 ChatGPT도 도입의 「이중섭거리」를 첫 번째로 잡았다(목록 순서로 해도 같은 3곳이다).
4. **가게 이름 안의 지명은 따로 세지 않았다.** 「24시무인카페 동백역세브란스병원점」의 동백역·세브란스병원, 「망원역 인근 · 벌툰 …」의 망원역, 「연남동 · 옐로우미플」의 연남동은 위치 설명으로 봤다.
5. **같은 장소의 다른 표기는 하나로 봤다.** s02 Claude 「애월항 ~ 애월 카페거리(한담 입구)」는 애월항, s05 Claude 「덕수궁 돌담길에서 정동길 산책」은 덕수궁 돌담길(덕수궁과 다른 카카오 장소), s07 Claude 「화성행궁 광장」은 화성행궁과 다른 장소로 셌다.
