## 결과 화면 구조와 카드 해부 (맛있는 거 → 구제주)

`ours-T2-390-02.jpeg`, `ours-T2-390-04.jpeg`

순서: 헤더(「구제주 근처」) → 「맛있는 거 먹고 싶어 / 바꾸기」 → 탭 「식사 | 카페·디저트」 → 큰 카드 1장 → 「아니면 · 둘 다 차로 약 5분」 → 작은 카드 2장 → 바닥 고정 파란 버튼 「다른 3곳 보기」 → 출처 줄 「정보·사진: 비짓제주」 → 「동네별로 둘러보기」.

큰 카드(위에서 아래로):
1. 사진 358×239(3:2), 실사, 모서리 둥긂
2. 이름 20px/700 + 오른쪽 하트(44×44)
3. 이유 한 줄 15px/400, 두 줄로 넘침 (예: 「산지등대 관사를 고친 카페, 루프탑에서 바다가 보여요」)
4. 메타 15px 회색: 「(실내 ·) 구제주에서 차로 약 5분 · 네이버지도」
5. 「길찾기」 15px/600 밑줄 글자. 카드 아래 약 20px 떨어져 있다

작은 카드: 왼쪽 정사각 사진 94×94 + 오른쪽 이름 17px/600 + 이유. 「길찾기」는 사진 아래 왼쪽에 따로 있다.

- 카드당 메타 1~2개(실내, 차로 N분). 배지·별점·가격 없음.
- 색: 글자 #14181F, 메타 #5F6267, 파란 #0A6FD6(「다른 3곳 보기」, 탭 밑줄), 주황(「아무거나」 밑줄), 구분선 #E3E3E4, 사진 자리 #F3F3F4.
- 글자 크기 15/17/20px 세 단계, 최소 15px.

## 홈 → 장소 결정 흐름

홈(기분 1탭) → 위치(성공 시 자동, 실패 시 동네 1탭) → 3곳 → 「길찾기」 1탭 → 네이버지도 자동차 길찾기(새 탭). 위치가 되면 **2탭**으로 길 안내까지 간다. 사이에 상세 화면은 없다. 이름을 누르면 네이버지도 검색으로 나간다.
