기준: `docs/research/ux-audit-criteria.md`. 감사자 1명. 주관 항목은 「1인 판단」. 기능 메모는 `competitors-01.md` §1에 있어 여기서는 화면·디자인·흐름만 본다.

## 환경

- 폭: 390×844(채점), 1440×900(T1 참고만)
- 날짜·시각: 2026-10-02 21:50~22:10 KST
- 브라우저: Playwright MCP Chromium
- 위치 권한: 줄 수 없음. 「내 주변」에서 「위치 요청 시간 초과.」 빨간 상자가 뜬다. 미리 정해 둔 지점 「📍 이도이동」을 골랐다(제주시청 근처).
- 앱 설치 유도·쿠키·팝업: 없음. 오른쪽 아래에 「맨 위로」 원형 버튼이 늘 떠 있다.
- 로그인·가입·예약·결제는 누르지 않았다. 찜은 로그인 없이 기기에 저장되는 것이라 눌렀다.
- 초는 도구 기준(클릭~화면 안정)이고 사람이 읽는 시간은 빠져 있다.

관찰:
- **첫 두 화면에 사진이 0장이다.** 꽉 차 보이는 이유는 사진이 아니라 44px 굵은 제목, 그라데이션 바탕, 칩 10여 개, 체크 문구다.
- 섹션마다 같은 틀을 반복한다: 주황 번호(01~09) + 영문 대문자 라벨 + 한글 제목(한 단어만 파란 이탤릭) + 회색 설명 한 줄 + 「전체 보기 →」 + 카드 줄. 이 반복이 리듬을 만들어 길어도 덜 헷갈린다.
- 섹션 사이 간격이 크다(약 100~200px). 카드 안은 촘촘하다. 간격만으로 묶음이 읽힌다.
- 카드 형태가 역할별로 다르다: 분야 = 세로 사진 타일 2열, 상황 = 글 카드 1열, 오늘 것(축제·오일장) = 가로 넘김, 지역 = 낮은 사진 타일 2열, 검색어 = 칩.
- 가로 넘김 줄은 다음 카드가 화면 끝에서 잘려 보여 「더 있다」를 알린다.
- 같은 카드 모서리(24px), 그림자 거의 없음, 알약 칩.

## 색·글자

- 바탕 #FAF8F5(따뜻한 흰색) + 하늘·살구 그라데이션. 글자 #121826, 회색 #555C6D와 그 투명도 9단계(0.2~0.85).
- 강조: 브랜드 파랑 #0882BA, 주황 #F97015(번호·Chapter), 장미 #E11D48(진행 중), 초록 #059669(오일장), 보라(아이콘), 칸마다 다른 파스텔. 색이 7개 이상이고 한 색에 뜻이 하나가 아니다.
- 글자: Pretendard + 숫자·영문 라벨은 세리프 이탤릭. 크기 12단계(10~44px), 최소 10px. 11~12px 글자가 440곳.

## 「왜 꽉 차 보이는데 덜 피곤한가」

1. 같은 섹션 틀(번호 + 라벨 + 제목 + 설명 한 줄 + 카드 줄)을 9번 반복한다. 읽는 법을 한 번 배우면 나머지는 훑는다.
2. 섹션 사이 여백이 크고 카드 안은 촘촘하다. 간격이 묶음을 대신 말해 준다.
3. 카드 형태가 역할마다 다르다. 「오늘 것」은 가로 넘김, 「분야」는 사진 타일, 「상황」은 글 카드.
4. 첫 화면은 사진 없이 큰 글자 + 옅은 그라데이션 + 칩으로 채운다. 비어 보이지 않지만 사진 정보도 없다.
5. 피곤함은 홈이 아니라 그 뒤(목록·AI 결과·상세)에서 생긴다: 카드당 태그 6~18개, 결과 30장, 12,000px 상세.
