## 2. 네이버지도 (m.map.naver.com, m.place.naver.com) — D3·D6·D8 + T2·T4

### 첫 화면 (`navermap-home-390-01`)

지도 + 위 검색창 「장소, 주소 검색」 + 「앱 열기」 파란 버튼. 아래에서 「네이버지도 앱에서 더 많은 기능을…」 시트가 올라와 지도 절반을 가린다. 「모바일 웹으로 보기」로 닫힌다. 기본 위치는 서울시청.

### 검색 목록 카드 (`navermap-T2-390-02`)

- 맨 위 한 줄: 「위치 정보 없음 · 내위치 · 변경」, 그 아래 「'제주시청' 근처 '맛집' 검색결과」. 검색어에서 기준 지점을 읽어 문장으로 보여 준다.
- 정렬: 관련도순 / 거리순.
- 카드(높이 140): 이름 18px/400 검정 + 업종 13px #999 / 주소 14px #666 한 줄 말줄임 / 좋아요 수·공유·가격 14px / 오른쪽 사진 68×68 정사각(모서리 없음, 일부는 초록 「예약」 원 배지) / **아래 4칸 액션 줄: 지도·전화·길찾기·내비게이션**(각 약 80×38).
- 거리·이동시간 숫자가 없다. 「거리순」을 눌러도(`navermap-T2-390-04`) 목록 순서만 바뀌고 카드에 거리는 안 나온다.
- 메타: 업종·주소·좋아요·공유·가격(+예약 배지) = 5~6개 + 액션 4개.

### 장소 상세 (`navermap-T2-390-03`)

위에서 아래로:
1. 뒤로·저장(별)·마이플레이스
2. 이름 26px 굵게 → 「일식당 · ★4.71 · 리뷰 3,628」 → 「영업 종료 · 11:30에 영업 시작」

4. **알약 버튼 줄**: 길찾기(연파랑 바탕 #E6F0FF, 글자 #006CFF, 모서리 19px, 86×38)·공유·전화·문의·알림받기

6. 아이콘 + 한 줄 정보: 주소(지도·내비게이션·거리뷰 링크), 찾아가는길, 영업시간, 전화(복사), 홈페이지, 편의

## 3. 카카오맵 — 확인 못 함

- `m.map.kakao.com` → HTTP 403. `map.kakao.com/?q=제주시청 맛집`도 `m.map.kakao.com/scheme/search`로 넘어가 403, 본문 「Restricted User Agent」(`kakaomap-home-390-01`, `kakaomap-T2-390-01`, 빈 화면).
- 자동화 브라우저를 막는 것으로 보고 다시 시도하지 않았다. D3·D6·D8, T2·T4 모두 `확인 못 함`.
- 사용자 크롬(Claude in Chrome)으로 보면 볼 수 있을 수 있다.
