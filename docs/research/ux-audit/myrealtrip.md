# UX/UI 감사: 마이리얼트립 (제주 투어·티켓·체험·맛집 범위)

기준: `docs/research/ux-audit-criteria.md`. 감사자 1명. 주관 항목은 「1인 판단」.

## 0. 측정 환경

- 날짜·시각: 2026-10-02, 약 21:20~21:50 (KST)
- 브라우저: 사용자 크롬(Claude in Chrome), Windows 11, DPR 1.25. 사용자가 미리 로그인한 상태. 감사자는 로그인·로그아웃 하지 않음.
- 폭: 크롬 창이 최대화돼 있어 창 크기 변경이 먹지 않았다. 그래서 **같은 출처 iframe(가로 390px, 세로 780px)** 을 페이지에 넣어 390px 레이아웃을 띄웠다. 스크롤바 15px 때문에 실제 내용 폭은 375px.
  - 한계: 사용자 에이전트는 데스크톱 크롬이다. 휴대폰 UA에서만 뜨는 앱 설치 배너는 `확인 못 함`.
  - 상품 상세(experiences.myrealtrip.com)는 다른 하위 도메인이라 같은 방법으로 그 도메인에서 다시 띄워 관찰했다.
- 1440px 참고: 창이 최대화 상태라 실제 뷰포트는 1482×830. T1만 봤다.
- 위치 권한: 묻는 화면을 만나지 않았다. 지도 화면의 「내 위치」 버튼은 누르지 않음 → 거부 시 동작 `확인 못 함`.
- 스크린숏: **파일로 저장하지 않았다.** 아래 `<mrt-과제-폭-번호>` 라벨은 화면에서 본 사실과 JS로 뽑은 구조 값이다. `shots/` 폴더에 마이리얼트립 파일은 없다.
- 하지 않은 것: 결제·예약·옵션 선택·쿠폰 받기, 찜 추가·삭제, 설정 변경, 리뷰·폼 제출. 개인정보(메뉴에 보인 이름·이메일)는 기록하지 않음.

### 카드 해부

<mrt-T1-390-03> 홈 가로 줄 상품 카드(제일 흔한 형태). 화면에 약 2.2장 보임.

1. 사진 165×165 정사각, 모서리 12px.
2. 사진 왼쪽 위 배지 하나: 「무료취소」(파랑 #1583DB, 연파랑 바탕) / 「즉시 확정」(보라 #8238FA, 연보라 바탕) / 「10월 특가」(분홍 #FF4EDB) / 「최저가보장제」(주황 #F78000).
3. 사진 오른쪽 위 책갈피 아이콘 32×32. 접근 이름(aria-label) 없음.
4. 제목 15px/500 검정, 2줄 말줄임. 판매자 말머리가 붙음(「[킴스제주]」「[당일가능]」).
5. 가격 15px/700 검정. 제목과 같은 크기라 굵기로만 앞선다.
6. 별 + 평점 + (리뷰 수) 14px/600. 리뷰 0이면 이 줄이 빠짐.
7. 「광고」 13px 회색 #848C94 (광고 상품만).
- 메타 개수: 배지 1 + 저장 1 + 가격 1 + 평점 1 + 리뷰 수 1 (+광고 1) = 5~6개.
- 카드는 `<a>`가 아니라 클릭 처리된 `<div>`. 키보드 포커스가 안 간다.

<mrt-T3-390-02> 검색 목록 카드(세로 목록).

- 위에 가로 꽉 찬 사진(사진 2장을 나란히), 그 아래 제목 2줄, 오른쪽에 책갈피 + 저장 수(예: 19, 124, 586).
- 「제주도 · 액티비티」 회색 메타, 배지 1~2개(최저가보장제 빨강 바탕 흰 글자 + 즉시 확정 보라), 가격은 오른쪽 정렬 굵게.
- 통합 탭 카드에는 「제주도 ∙ 미식투어 ∙ 1시간 소요」처럼 소요시간이 붙는다.

<mrt-T1-390-02> 순위 줄 카드: 순위 숫자(24px) + 56px 사진 + 이름 1줄 + 가격. 사진이 작아 글자 목록에 가깝다.
