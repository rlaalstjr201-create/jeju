# 개화 시기 판정 방법 비교 (bloom-timing-02, 2026-10-04)

조사: 서브에이전트 1회. 주인이 승인한 웹 조회 25회를 모두 썼다(WebSearch 16, WebFetch 9). 이어지는 결정은 ADR-0080 「2026-10-04 비교 조사 반영」.

## 요약 (권고)

- **벚꽃·매화·단풍은 기상청 계절관측에서 나온 그해 관측일만 날짜의 근거로 쓴다.** 시즌 중에는 정해진 작업이 매일 `blooms-YYYY.json` 하나만 갱신한다.
- 기온 누적 예측(600℃ 법칙 등)은 **화면에 내지 않는다.** 언제부터 관측을 매일 조회할지 정하는 신호로만 쓴다.
- 유채꽃·억새·동백·수국은 공식 관측이 없다. 원문에 달이 적힌 곳만 싣는다.
- 귤 따기는 꽃이 아니므로 재배 방식별 수확 달로 정한다.

  - 공공누리 제1유형, 개발계정 10,000회다.

- 쓰임은 하나로 제한한다. 누적값이 문턱의 약 80%를 넘으면 관측 조회를 매일로 바꾸는 신호다. 예측 날짜는 보이지 않는다(ADR-0080 결정 A).

## 종류별 권고

- **벚꽃**
  - 서귀포(189)·제주(184) 관측 개화일로 창을 연다.
  - 관측일 전에는 아무것도 보이지 않는다.
- **매화**: 계절관측 종에 매화가 있다. 제주 지점에서 관측하는지는 확인하지 못했다. 관측이 없으면 원문 달 방식으로 간다.
- **단풍**: 기상기후데이터위키에 「한라산 단풍」 관측이 있다. 한라산 장소에만 쓸 수 있다.
- **유채꽃·억새**: 공식 관측도, 공개 데이터도 찾지 못했다. 원문 달 방식으로 간다. 「서귀포 1월·제주시 2월」은 블로그 수준이라 근거가 아니다.
- **동백**: 관측 지점은 여수 오동도와 선운사뿐이고 제주는 없다(위키 요약). 원문 달 방식으로 간다.
- **수국**: 공식 관측이 없다. 원문 달 방식으로 간다.
- **귤 따기**: 출처는 제주농산물수급관리센터다.
  - 노지 온주: 10~12월. 극조생은 10월 중순부터 출하하고, 10/1 전 출하는 당도 검사가 필요하다.
  - 하우스: 5~10월.
  - 월동(비가림): 2~4월.
  - 만감류: 1~4월.
  - **이전 메모 「노지 10월~이듬해 2월」의 1~2월은 노지 근거가 없다.** 월동·만감류일 수 있다.
  - 재배 방식을 모르는 9곳에 기본 달을 쓴다면 노지 10~12월만 안전하다.

| B. Pages Function 런타임 조회 | 첫 요청에 기상청 지연이 붙는다. | 0 | 당일 | 기상청 장애가 화면에 바로 닿는다. 새 비밀값이 필요하다. |
| **C. 시즌 중 매일 `blooms-YYYY.json`만 갱신·커밋 후 배포 (권고)** | 빠르다 | 시즌 약 90회 빌드 | 하루 늦다. | `failed`를 기록하고 이전 값을 유지한다. 사람이 검토하고 이력이 남는다. |

ADR-0080 「주인 확인」 1의 (a)가 C다.

## 상태를 모를 때

- `pending`(시즌 중 관측 없음)과 `failed`(받기 실패)에는 철 글자를 붙이지 않는다.
- `failed`를 `none`으로 바꾸지 않는다.
- 민간 예상은 이용 허락이 없어 1단계에서 싣지 않는다.

## 확인 실패

「없다」가 아니라 「확인하지 못했다」는 뜻이다.

- 계절관측 API
  - 호출 주소·인자·응답 형식.
  - data.go.kr `serviceKey`로 부를 수 있는지.
- 제주 4개 지점(184·185·188·189)
  - 어느 지점이 어느 종을 관측하는지(특히 매화, 제주 184의 벚꽃).
  - 관측일 공개 지연.
- ASOS 일자료: 전날 자료가 올라오는 시각.
- 600℃·400℃ 법칙
  - 오차 「최대 3일」의 1차 자료.
  - 제주에서의 검증.
- NPS 생장도일 「217」(언론에만 있음).
- 민간·산림청 자료
  - 웨더아이: 방법과 이용 조건.
  - 산림청 예측지도: 라이선스, 그리고 한라수목원 날짜가 개화인지 만개인지.
  - tenki.jp: 명소 단계 기준.
- 계절별 공개 자료
  - 노지감귤 1~2월 수확(농업기술원 원문을 열지 못했다).
  - 유채꽃·억새·수국 공개 데이터(검색 1회만 했다).
- 동백 관측 지점 「전주 선운사」 표기: 고창일 수 있다.
- Cloudflare Pages 무료 빌드 한도 숫자.
