## 잘 된 것 (바꾸면 안 되는 것)

1. **카드 화면의 선택지 수와 위치**(03, 10): 큰 카드 1장 + 「아니면」 2장, 화면 아래 고정 「다른 3곳 보기」(56px)와 48px 「길찾기」. 결정 부담이 작고(M3) 주 동작이 엄지 영역에 있다(M1).
2. **기준이 카드 위에 보인다**(03, 10): 맨 위 「애월 근처」와 「차로 30분 안에서, 소개글로 볼 때 가 볼 만한 곳부터 골랐어요」, 카드마다 「애월에서 차로 약 10분」. 무엇을 기준으로 골랐는지 바로 읽힌다(N1).
3. **위치 꺼짐에서도 막히지 않는다**(02): 고른 기분(「좀 걷고 싶어」)을 유지한 채 동네 15곳(대표 지명 포함)으로 바로 이어져 한 번 탭으로 결과가 나온다(N9, M5).

## 확인 못 함

- 위치 허용 상태의 흐름, 다크 모드, 오프라인, 실제 기기(iOS Safari·안드로이드 크롬), 카카오톡 인앱 브라우저, 길찾기 이후(지도 앱 전환) — 증거 없음.
- E2-1에서 빈 하트를 다시 누르면 「내일」에 두 번째로 저장되는지, 오늘 저장이 풀리는지.
- E2-6 「돌아가기」 첫 탭 무반응의 재현성·원인(1회 관찰).
- 느린 통신에서 카드 사진·첫 화면이 뜨는 실제 시간(M2). 앱 코드 전 탭의 0.3초 뒤 대기 점은 서술만 있고 화면 증거 없음.
