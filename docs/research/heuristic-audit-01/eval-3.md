## 잘 된 것 (바꾸면 안 되는 것)

1. **결과 화면 구조(03·10)**: 큰 카드 1장 + 대안 2장, 카드 안에 「애월에서 차로 약 10분 · 네이버지도」로 출발점·시간·넘어갈 앱을 함께 보이고 「길찾기」가 한 번 누름이다(N1·N2·M3). 「기분 → 3곳 → 길찾기」의 짧은 길을 지킨다.
2. **첫 저장 피드백(04)**: ♥ 누르면 즉시 채워지고 맨 위에 「♥ 1」이 생기며 「저장한 곳은 맨 위 하트 버튼에 모여요」가 위치를 알려 준다(N1·N6·N10).
3. **위치 거부 시 막다른 길 없음(02)**: 오류 화면 대신 동네 15곳을 대표 지명(한담·성읍 등)과 함께 바로 보여 주어 한 번 더 누르면 결과로 간다(N9). 앱이 뜨기 전 누른 기분도 0.3초 뒤 점 네 개로 대기를 보이고 이어 처리한다(M2).

## 확인 못 함

- 위치 허용 상태의 흐름, 다크 모드, 오프라인·느린 통신, 실제 기기(iOS Safari·안드로이드 크롬), 카카오톡 인앱 브라우저, 길찾기 이후 지도 앱 전환.
- 「다른 3곳 보기」 뒤 이전 3곳으로 돌아갈 수 있는지(N3) — 증거에 없음.
- 「돌아가기」 첫 탭 무반응(E3-05)의 재현 빈도와 원인.
- 카드에서 밑줄 친 「네이버지도」 글자 자체를 눌렀을 때의 동작(코드상 `aria-hidden` span으로 보임 — 카드 전체 누름과의 관계는 화면으로 확인 못 함).
- E3-02의 실제 사용자 크기(가상 실험 결과뿐, ADR-0085 기록 대기).
- 햇빛 아래 대비(회색 보조 글자 `--muted`의 실제 대비 수치는 재지 않음).
