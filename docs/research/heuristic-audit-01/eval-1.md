## 잘 된 것 (바꾸면 안 되는 것)

1. 첫 화면 결정 부담이 작다(01): 기분 5개, 각 줄에 실제 장소 이름 두 개와 사진 두 장. 한 번 누르면 3곳(큰 카드 1 + 작은 카드 2). M3·N6에 맞는다.
2. 동네 고르기 칸에 대표 지명이 함께 있다(02: 「애월 / 한담」, 「구좌 / 월정리」). 동네 이름을 모르는 여행자도 아는 지명으로 고를 수 있다(N2).
3. 터치 크기: 하트·기준·♥ N·탭·옵션이 44px 이상, 자주 누르는 것은 48px 히트 영역(`style.css` .heart·.basis·.saved-btn·.go). 「이 브라우저에만 저장돼요」+「링크로 백업」처럼 저장 한계를 숨기지 않고 말한다(05, N1).

## 확인 못 함

- 위치 허용 상태의 흐름(「내 위치 근처」 라벨, 위치 받는 동안의 대기 표시, M2).
- 「돌아가기」 첫 탭이 안 먹은 원인과 재현 빈도(V2).
- 시트에서 위치 꺼진 「지금 있는 곳」을 눌렀을 때의 반응(V8).
- 「네이버지도」 글자 링크가 여는 곳(V11) — 화면에서만 판단.
- 다크 모드·햇빛 아래 대비, 오프라인·느린 통신, 실제 기기(iOS Safari·안드로이드 크롬), 카카오톡 인앱 브라우저(이 경우 「이 브라우저에만 저장」이 특히 문제일 수 있으나 증거 없음).
- 길찾기 이후 지도 앱에서 돌아오는 흐름(M5 이어 하기).
- 밤에 담은 하트가 다음 날 숨는 문제(V1 관련)는 이번 점검에서 직접 찍지 않았고 지난 실험 기록에 기댔다.
