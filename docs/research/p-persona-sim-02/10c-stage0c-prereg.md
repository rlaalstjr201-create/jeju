## 0b가 어떻게 끝났나

0b(`10b-stage0b-prereg.md`)는 사용 한도(5시간·주간)에 걸려 묶음 774개 중 431개만 끝나고 **중단**했다. 끝난 431개의 결과는 **보지 않았다**(판정·집계 안 함). 남은 것만 이어 돌리면 앞뒤 실행 조건이 섞이므로, 주인 결정(2026-10-10)으로 0c를 처음부터 다시 돌린다. 0b 원자료는 쓰지 않는다.

## 0b와 다른 점

| 바꾼 것 | 이유 |
|---|---|
| **시뮬레이터 = 전용 에이전트 `sim-player`**(`.claude/agents/sim-player.md`, 도구 Bash·Write만, 짧은 지시) | 0b 하위 작업은 시작부터 맥락 약 6만 토큰(일반 지시·도구 설명·스킬 목록)을 싣고 누를 때마다 다시 읽었다. 파일럿(c0004, Sonnet)에서 sim-player 시작 맥락은 약 7,700토큰, 도구 호출 5번, 4세션 모두 끝남 |
| **`step.mjs brief`로 지시문+사람+첫 화면을 한 번에** | 왕복을 줄인다. 지시문 내용 자체는 0b와 같다 |
| **묶음 배정 난수 씨앗 `stage0c-2026-10-10`** | 같은 240명·같은 설계로 새로 배정. 0b 묶음 파일과 겹쳐 쓰지 않는다(`work/stage0c/`) |

사람(0b와 같은 240명, 0b 결과는 안 봤으므로 재사용), 팔·상황·성공 규칙·묶음 구성(한 묶음 = 한 팔·한 상황·서로 다른 10명), 주 모델 Sonnet, 교차 모델 Opus·Haiku·Fable(48명 소패널), 통과 기준 G1~G8과 판정 규칙은 **0b와 같다**(`10b-stage0b-prereg.md`의 표를 그대로 따른다). 판정은 `node lab/analyze0.mjs docs/research/p-persona-sim-02/work/stage0c`(`stage0c` 경로면 0b 규칙). 만들기: `node lab/build0.mjs --0c` → 묶음 774개, 세션 6,912개.

시뮬레이터가 바뀌므로, 0b와 같은 결과를 기대할 근거는 「같은 모델·같은 지시문」뿐이다. 전용 에이전트의 짧은 시스템 지시가 행동을 바꿀 수 있다는 점은 결과 해석에서 한계로 적는다.
