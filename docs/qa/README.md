# QA

- **언제 부르나**: 기능을 내보내기 전, 버그 제보를 받았을 때, 고친 결함이 정말 고쳐졌는지 볼 때 — 「qa-analyst로 specs/<기능>.md 점검해 줘」(규칙: `.claude/agents/qa-analyst.md`).
- **무엇을 받나**: 시험 조건 표(정상·예외·경계, P0–P3)와 결함 보고서 파일(`.scratch/<기능>/issues/NN-*.md`). 테스트가 결함을 잡는 힘은 `npm run test:mutation`(apps/web) 결과 `docs/qa/mutation-*.md`로 본다.
- **보고서 읽는 법**: 「증거」 칸(스크린샷 경로·콘솔·네트워크·file:line)이 비었거나 「재현 횟수」가 0이면 믿지 말고, 「재현 절차」를 그대로 따라 해 같은 결과가 나오는지 보고, 「QA 상태: 닫힘」은 고친 커밋과 새 테스트 이름이 있을 때만 받아들인다.
