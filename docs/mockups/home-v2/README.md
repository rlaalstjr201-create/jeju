# 첫 화면 v2 시안 (주인 확인용, 앱 코드는 바꾸지 않음)

`A.png`·`B.png`·`C.png`는 각 `.html`을 375×812(2배)로 찍은 것이다. 사진은 실제 비짓제주 사진을 주소로 불러온다(주소가 바뀌면 사진이 사라질 수 있다). 색·반지름은 `apps/web/src/style.css`의 값 그대로다. 「섭지코지」「차로 12분」「해 지는 시각 17:47」은 시안용 값이다(실제 계산이 아니다). 스펙: `specs/home-v2.md`.

| 시안 | 모양 | 장점 | 걸리는 점 |
|---|---|---|---|
| A | 큰 사진 카드 한 장 + 기분은 가로 스크롤 카드 | 사진이 가장 크고 「지금 여기서」가 한눈에 | 기분이 가로로 숨는다(둘째 줄부터), 한 손으로 스크롤이 필요 |
| B | 작은 가로 카드 + 기분 2열 사진 격자 | 기분 6개가 스크롤 없이 다 보인다 | 「지금 여기서」 사진이 작다 |
| C | 화면 가득 사진 + 아래 기분 칩 (트리플식) | 가장 감성적이고 깔끔하다 | 기분이 칩이라 우리 특징이 작아진다, 오늘 판 줄이 아래로 밀린다 |

다시 찍기: 각 `.html`을 크롬에서 열거나 `chrome --headless=new --window-size=375,812 --force-device-scale-factor=2 --virtual-time-budget=12000 --screenshot=<out.png> file:///.../A.html`.
