# 영어권 여행 앱·가이드북 표현 조사 (여차나:제주 영어화 근거)

조사일 2026-10-17. WebSearch 30회(상한 도달) + WebFetch. 모든 주장은 URL을 붙였고, 원문을 직접 못 연 것은 「검색 요약 경유」, 끝내 못 찾은 것은 「확인 실패」로 적었다. 영어 인용은 15단어 미만.

> 한계: Lonely Planet·Culture Trip·Atlas Obscura 본문은 WebFetch가 메뉴만 받거나(403·타임아웃) 실패해 일부는 검색 요약에 기댔다. Rough Guides·Time Out의 제주 페이지는 찾지 못했다(확인 실패). 공식 가이드북 PDF(visitjeju.net)는 10MB를 넘어 읽지 못했다.

## 1. 앱 마이크로카피의 말투와 「기분 버튼」 문형

**결론: 대형 여행 앱의 내비게이션·필터는 대부분 명사 라벨이고, 1인칭 문장 버튼은 드물지만 "사용자가 앱에 말하는" 자리에서는 실제로 쓰인다.**

- 명사 라벨이 기본이다. VisitJeju 영어판 메뉴는 "Attractions, Food, Stay, Shop" 식 명사 나열이다 ([visitjeju.net/en](https://www.visitjeju.net/en)). Google 지도도 검색창 옆 추천을 "Restaurants, Coffee, or Hotels" 같은 명사로 보여 준다 ([Google Maps Help](https://support.google.com/maps/answer/6303244)). Airbnb 체험 카테고리도 2025년 개편 때 "Food tours, cooking classes, and dining experiences"처럼 명사구로 발표됐다 ([Airbnb Newsroom](https://news.airbnb.com/airbnb-2025-summer-release), 검색 요약 경유).
- 1인칭 버튼의 실례. Airbnb는 2021년 위치·날짜를 정하지 않은 사람용 검색을 "I'm Flexible"이라 불렀다 ([Airbnb Newsroom](https://news.airbnb.com/unique-stays), [2021 Release](https://news.airbnb.com/2021-release)). Google 검색의 "I'm Feeling Lucky"는 결과 목록을 건너뛰고 첫 결과로 바로 보낸다 ([Wikipedia: Google Search](https://en.wikipedia.org/wiki/Google_Search)). 「아무거나 골라줘」와 성격이 같다.
- My/Your 원칙. 사용자가 제품에 말하면 "My", 제품이 사용자에게 말하면 "Your", 둘 다 아니면 대명사를 빼라는 기준이 있다. 한 화면에서 섞지 말라는 경고도 같이 있다: "Never mix different pronouns, because it will confuse the users." ([Smart Interface Design Patterns](https://smart-interface-design-patterns.com/articles/your-vs-my/)). 여차나의 기분 버튼은 "사용자가 앱에 말하는" 자리라 1인칭이 원칙에 맞는다. 단, 같은 화면의 다른 문구(예: 안내문)에서 "you"를 쓰면 섞임이 생기므로 버튼 쪽은 대명사 없는 짧은 동사구가 안전하다.
- 기분 기반 추천 앱 선례. Momondo Places(2014)는 Romantic·Social·Local 등 여섯 "mood"를 형용사로 붙였다 ([The Next Web](https://www.thenextweb.com/news/momondos-new-travel-guides-ipad-lets-find-things-based-mood), 검색 요약 경유). 스탠퍼드 HCI 과제 Mingo는 자유 입력 대신 정해진 기분 목록을 골랐다 ([Mingo Final Report](https://hci.stanford.edu/courses/cs147/2015/au/projects/mobility/mingo/assets/Mingo_Final_Report.pdf), 검색 요약 경유). "I want to…" 문형을 버튼으로 쓰는 대형 여행 앱 사례는 **확인 실패**.
- 대소문자. Microsoft 스타일 가이드는 버튼·체크박스 같은 UI 라벨도 첫 단어만 대문자로 쓰는 sentence case를 기본으로 한다 ([Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/capitalization)). Google Material·Apple HIG 원문은 WebFetch가 본문을 못 받아 **확인 실패**.
- 저장 목록. Google 지도의 기본 목록 이름은 "Favorites, Want to go, Starred places" 등이다 ([Google Maps Help](https://support.google.com/maps/answer/7280933)). 「가 보고 싶은 곳」류는 "Want to go"가 이미 영어권 사용자에게 익숙한 표현이다. 「가 봤어요」에 해당하는 Google 기본 목록 이름은 **확인 실패**.
- 비 오는 날. Google은 비가 오면 "activities for a rainy day"를 물어 실내 추천을 받으라고 안내한다 ([Google blog](https://blog.google/products-and-platforms/products/maps/google-maps-generative-ai-local-guides/), 검색 요약 경유). "rainy day"와 "indoor"가 영어권의 자연스러운 짝이다.
- 길찾기. Google 지도 도움말은 장소 정보에서 "get directions"를 쓰고, 경로 시작은 "start navigation"으로 구분한다 ([Google Maps Help](https://support.google.com/maps/answer/144349)). 버튼 문구 자체가 "Directions"인지는 앱 버전마다 달라 **확인 실패**.

## 2. 제주 고유어와 랜드마크 공식 영문명

**결론: 공식 기관끼리도 표기가 갈린다. VisitJeju(제주관광공사)와 VisitKorea(한국관광공사, KTO) 중 하나를 기준으로 정하고 일관되게 쓰는 게 핵심이다.**

### 고유어
- 오름: VisitJeju는 "volcanic cones called oreum"이라 풀어 쓴다 ([VisitJeju, Stone Culture](https://visitjeju.net/en/themtour/view?contentsid=CNTS_200000000012527)). Lonely Planet은 "grassy oreum (craters)"로 괄호 풀이를 붙였다 ([Lonely Planet, Olle Trail 1](https://www.lonelyplanet.com/south-korea/eastern-jeju-do/activities/olle-trail-1/a/poi-act/1512844/357419), 검색 요약 경유). 복수형은 VisitJeju가 "four oreums"처럼 -s를 붙인 사례가 있다(같은 페이지, 검색 요약 경유).
- 올레: 공식 재단 영문 페이지 제목은 "Jejuolle Trail"이고 구간을 "Route 1"처럼 Route로 센다 ([jejuolle.org/trail_en](https://www.jejuolle.org/trail_en), 구간 목록은 검색 요약 경유). VisitJeju는 같은 구간을 "Jeju Olle Course 10"처럼 Course로 쓴다 ([VisitJeju](https://m.visitjeju.net/en/detail/view?contentsid=CNTS_000000000018792)). Lonely Planet은 "Olle Trail 1", "Olle Trail Rte 8"이다(위 LP 링크). 구간 거리도 두 공식 출처가 다르다(Course 4: 23.6km vs Route 4: 19km).
- 곶자왈: VisitJeju "the virgin forest of Gotjawal" ([VisitJeju, Stone Culture](https://visitjeju.net/en/themtour/view?contentsid=CNTS_200000000012527)). 위키백과는 제주어로 나무·덩굴이 덮인 바위투성이 화산 지대라 정의한다 ([Wikipedia: Jeju Olle Trail](https://en.wikipedia.org/wiki/Jeju_Olle_Trail), 검색 요약 경유).
- 해녀: 로마자 "haenyeo"가 표준이고 "female divers", "women divers"로 풀이한다 ([UNESCO](https://www.unesco.org/archives/multimedia/document-4388), [FAO](https://www.fao.org/family-farming/detail/en/c/1754489/), 검색 요약 경유). Atlas Obscura는 장소명을 "Jeju Mermaids"로 붙였다 ([Atlas Obscura](https://www.atlasobscura.com/places/jeju-mermaids), 본문 403, 제목만 확인). "mermaid"는 기사 제목용 별칭이지 UI 용어로는 부적합하다고 판단한다(판단).
- 오일장: 위키백과 표제어는 "Seogwipo Rural Five-Day Market" ([Wikipedia](https://en.wikipedia.org/wiki/Seogwipo_Rural_Five-Day_Market)). Culture Trip은 "Jeju Minsok Five-day Market"이라 쓰고 장날을 2·7일로 적었다 ([Culture Trip](https://theculturetrip.com/articles/the-best-traditional-markets-in-jeju), 검색 요약 경유). 한국 놀(NOL) 영문은 "Seogwipo Hyangto 5-day Market", "Jeju City Traditional 5-day Market" ([NOL](https://world.nol.com/en/content/pois/561ac833-3799-45e9-bcc7-6dd98dcc4885)). Hotels.com은 날짜 끝자리가 2나 7인지 보라고 안내한다 ([Hotels.com](https://www.hotels.com/see/go/south-korea/best-markets-jeju), 검색 요약 경유). 「장날」을 직역한 영어 관용구는 **확인 실패**, 영어권 글은 "held every five days" 식 설명으로 대신한다.
- 해안도로: VisitJeju는 고유명은 "Hagwi-Aewol Coastal Road"처럼 대문자, 본문은 소문자 "the coastal road"로 쓴다. "Windmill Coastal Road" 같은 별칭과 "spectacular ocean sunsets" 같은 노을 표현도 같은 글에 있다 ([VisitJeju, 5 coastal roads](https://www.visitjeju.net/en/detail/view?contentsid=CNTS_200000000009201)).
- 귤 따기: GetYourGuide·Klook 상품명이 모두 "Tangerine Picking"이다 ([GetYourGuide](https://www.getyourguide.com/seogwipo-si-l155164/jeju-winter-east-snow-camellia-tangerine-picking-tour-t1119637/), [Klook](https://www.klook.com/activity/138266-jeju-camellia-tangerine-snow-winter-seasonal-tour/)). KTO 농장 페이지는 "citrus orchard"를 쓴다 ([VisitKorea, Jejue In Farm](https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=190912), 검색 요약 경유). 넷플릭스 「폭싹 속았수다」 영문명 "When Life Gives You Tangerines" 덕에 tangerine이 더 강해졌다 ([GetYourGuide](https://www.getyourguide.com/jeju-province-l32347/jejuk-drama-spot-when-life-gives-you-tangerines-hotel-pick-t640766/)).

## 3. 한→영 여행 문구의 번역투 함정

- **이중 보통명사**: 문체부 2020년 지침은 로마자 뒤에 영어 범주어를 붙이게 해 "Hallasan Mountain"이 된다. 비판도 있다: "Halla Mountain Mountain"이냐는 조롱 ([Korea JoongAng Daily](https://www.koreajoongangdaily.com/korea/its-hangang-river-not-han-river-says-seoul-govt/12366739), [Korea Times](https://www.koreatimes.co.kr/amp/opinion/20241201/doublespeak-and-gobbledygook), 검색 요약 경유). KTO의 "Cheonjiyeonpokpo Falls"는 폭포(pokpo)+Falls 중복의 실례다. 이 지침은 시장 같은 인공 시설엔 적용하지 않는다고 보도됐다(같은 기사).
- **같은 장소, 여러 철자**: 창덕궁 후원이 "Rear Garden", "Huwon"으로 갈렸고 한 문화재가 7~8가지로 표기된다는 지적 ([Korea JoongAng Daily](https://www.koreajoongangdaily.com/lifestyle/tourist-sites-confront-translation-troubles/10590217)). 제주에서도 위 표처럼 주상절리·천지연·올레 구간 단위가 갈린다.
- **직역 문장**: 박물관 표지 "Instrument to measure of rainfall", "No use cell phone" (같은 기사). 원인으로 사전 의존과 원어민 교정 부재가 꼽힌다 ([Korea Herald](https://www.koreaherald.com/article/10337902), 검색 요약 경유).
- **대명사 섞기**: 버튼은 "I", 안내문은 "you"로 한 화면에 섞이면 혼란 (1절 Smart Interface Design Patterns).
- **Title Case 남용**: 버튼마다 단어 첫 글자를 대문자로 쓰는 것은 영어권 UI 관례(sentence case)와 어긋난다 (1절 Microsoft).
- **고유어 무설명 노출**: 영어권 공식·편집 매체는 oreum·gotjawal·haenyeo를 처음 쓸 때 거의 항상 짧은 풀이를 붙인다(2절 VisitJeju·LP 인용). 풀이 없이 "Oreum" 칩만 두면 뜻이 안 전해진다.
