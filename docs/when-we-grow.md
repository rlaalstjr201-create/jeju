# 커지면 할 것 (발전할 때 참고)

지금 규모에서는 일부러 단순하게 두었지만, 사용자·자료가 늘면 다시 봐야 하는 것들. 새 항목은 맨 아래에 날짜와 함께 더한다. 착수하면 ADR을 새로 내고 이 줄에 ADR 번호를 적는다.

## 추천·최신화

- **최신화 규칙 → 학습 방식으로** (2026-11-06, ADR-0124)
  - 지금: 정해 둔 규칙만 쓴다. 7일 안 새 곳은 앞으로, 3번 넘게 보이고 안 눌린 카드는 뒤로, 선반 4칸 중 1칸은 덜 본 곳, 날짜 씨앗으로 섞는다. 기록은 기기 안에만 둔다.
  - 커지면: 누름 데이터로 밴딧이나 랭킹 모델을 학습시킨다. 기준은 browse_card의 「새로 들어옴/당겨옴/기본」 칸이다.
  - 먼저 할 일: 아래 출처를 실제로 찾아 확인하고, 업계 권장 값과 우리 값(3회·4칸 중 1칸·7일)을 비교해 문서로 남긴다.
    - 신선도·시간 감쇠: 해커뉴스·레딧 순위식, 새 콘텐츠 냉시작 부스트
    - 노출 할인·피로도: Lee et al., "Modeling Impression Discounting in Large-scale Recommender Systems", KDD 2014(링크드인)
    - 탐색과 활용: 엡실론-그리디, 다중 슬롯 밴딧
    - 디더링: Ted Dunning & Ellen Friedman, *Practical Machine Learning: Innovations in Recommendation*(2014)
  - 확인 전: 위 출처는 진행자의 지식에서 나온 것이다. 이 세션에서 검증하지 않았다.

## 카드 사진

- **선반 전체 실사진** (2026-11-06)
  - 구글 Places 사진은 월 1,000장 무료, 이후 1,000장당 7달러다. 서울 홈을 하루 50번 열고 한 번에 20장씩이면 월 약 200달러에 장소 조회 요금이 따로 붙는다.
  - 지금은 카드를 눌렀을 때만 보여 주는 쪽을 검토 중이다(주인 결정 대기).
  - 방문이 늘거나 수익이 생기면 다시 본다. 출처: developers.google.com/maps/billing-and-pricing/pricing
- **카페·바 공식 그림**: 대부분 인스타그램만 있다. Meta oEmbed는 2025-11부터 썸네일을 주지 않는다. 브랜드 제휴가 생기면 가게가 직접 그림을 주는 길을 연다.

## 큐레이팅 자료 출처

- **네이버 검색 API 약관** (2026-11-06 발견, 「나중에」로 미룸 — 주인)
  - 2026-09-07 개정 약관은 이렇게 정한다.
    - 2.1: 「네이버 검색결과를 제공하기 위한 목적으로만」 쓸 수 있다.
    - 금지: 「데이터를 AI에 입력하거나 학습, 개선, 평가 및 노출 등에 활용하는 행위」, 데이터 복사·저장(임시 보관 최대 21일).
  - 우리 큐레이팅 근거 수집(블로그 → AI 판정, 근거 파일을 저장소에 저장)이 걸릴 수 있다.
  - 조치: 매일 발굴 루틴은 2026-11-06에 꺼 두었다.
  - 할 일: 대체 출처(카카오·다음 검색 약관, 공공 자료)를 확인하고, 저장된 네이버 원문 파일을 처리한다(히스토리 정리 여부는 주인이 정한다). 검색광고 API(검색량)는 약관을 따로 확인한다.
- **매일 발굴 엔진 다시 켜기**: 위 문제가 풀린 뒤. 루틴 trig_01CaCvKgkh1H7yy93bkawQej(꺼짐), 자동 배포 워크플로는 그대로다.
- **가게 갈래**: 감사 2회 실패. 블로그 제목만으로는 판정이 갈린다. 더 나은 근거(본문 요약 등)가 생기면 다시 한다(ADR-0121).
- **2040 거르기**: 감사 drop 83.3%로 미달. criteria-02(확실한 종류만 drop)를 승인받은 뒤 다시 한다(ADR-0119).
- **카페 후보 46곳**: 상호 묶기 버그로 판정 전에 빠졌을 수 있다(review/seoul-cafe/brand-check-01.md).
