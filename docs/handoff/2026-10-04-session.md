## 환경에서 배운 함정 (모델이 추론하기 어려운 것)

- **줄바꿈**: Windows `core.autocrlf=true`라 `_headers`·`public/*.txt`·`*.sh`는 `.gitattributes`로 LF 고정했다. 옛 주소 `_redirects`도 배포 전에 `tr -d '\r'`.
- **wrangler 4.147**: 새 Pages 프로젝트를 처음 만들 때 `pages project create --force`가 필요하다(Workers 위임 실패). 이후에는 `--force` 없이 쓴다.
- **D1**: 막 만든 DB는 원격 쿼리가 7403으로 잠깐 거부된다. 잠시 뒤 된다.
- **기상청 키**: Cloudflare에 인코딩 키가 들어가 있어서 함수가 `%`가 있으면 풀어 쓴다. 실패 이유는 응답 헤더 `X-Rain-Reason`에 남는다(키는 남지 않음).
- **네이버 도메인**: Claude in Chrome·내장 브라우저는 search/searchadvisor/analytics.naver.com을 안전 제한으로 막는다. Playwright MCP는 search.naver.com이 열린다.
- **e2e 포트**: 기본 포트 4179/4180은 병렬 세션과 부딪힌다. `E2E_PORT=45xx E2E_DEPLOY_PORT=45xx`로 따로 쓴다.
- **서브에이전트 제약**: 보고서 파일을 쓰지 못한다(「결과는 글로」). 보고서는 메인이 쓴다.
- **자격 증명**: 다른 프로젝트(taste-radar `.env`)의 자격 증명 읽기는 auto mode가 막는다. 우회하지 말고 사용자에게 명령을 준다.
- **Codex**: Codex 교차 리뷰는 이 계정에서 모델 미지원으로 실패한다. Claude 독립 리뷰로 대신하고 그 사실을 기록한다.
- **push**: PowerShell exit code를 믿지 말고 `git ls-remote origin refs/heads/master`로 대조한다.
