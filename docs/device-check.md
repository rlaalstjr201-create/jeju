# 실기기 점검 — 길찾기 7분 (ADR-0069, ADR-0071)

자동으로 못 보는 것만 본다: 지도 앱(네이버지도·카카오맵·TMAP)이 있을 때와 없을 때, iOS가 앱 호출 실패에 띄우는 창, 카카오톡 인앱 브라우저. 링크가 어디로 가는지는 `npm run check:links`가 이미 확인한다(네이버·카카오 × UA 5종 + PC, TMAP은 링크 모양).

**지도 앱 고르기**: 저장한 곳 화면(♥ N) 맨 아래 한 줄 `지도 앱  네이버지도 · 카카오맵 · TMAP`. 기본은 네이버지도. 아래 표의 「지도 앱」 칸대로 먼저 고르고 본다(하트 하나를 눌러야 ♥ N이 보인다). 고른 앱은 그 브라우저에 남는다 — 카카오톡 인앱은 따로 고른다.

## 준비 (1분)

- 배포 주소(아래 `{주소}`)를 폰 메모에 붙여 둔다. 아래 세 링크는 주소 뒤에 붙인다.
  - **자동차** `{주소}/?mood=new&area=seongsan&reach=drive30` — 성산 기준, 첫 카드 `길찾기`
  - **도보** `{주소}/?mood=food&area=gujeju&reach=walk` — 동문시장 기준, 첫 카드 `길찾기`
  - **배 타는 곳** `{주소}/?mood=new&area=hangyeong&reach=drive30` — 한경 기준, 차귀도 카드의 `배 타는 곳까지 길찾기`
- 카카오톡 칸은 위 링크를 나와의 채팅에 보내고 거기서 연다(인앱 브라우저).
- 「앱 없음」은 그 지도 앱을 지우거나, 앱이 없는 다른 폰으로 본다.

## 결과 판정

- 1·2·4·5·7·9·10·11이 기대와 같으면 통과. 앱이 길찾기 대신 지도 첫 화면만 열면 그 칸을 「실패」로 적고 화면을 캡처한다.
- 3·6·8(앱 없음)은 **빈 화면이나 막다른 오류만 아니면** 통과. 카카오 `설치없이 지도보기`가 도착지 없이 지도 첫 화면을 여는 것은 카카오 쪽 동작이라 알려진 한계다(ADR-0069 Consequences).
- 12는 결과만 적는다(통과·실패 아님).
- 실패가 있으면 결과 칸과 캡처를 ADR-0071(네이버·TMAP) 또는 ADR-0069(카카오)에 덧붙이고, `npm run check:links`를 다시 돌려 지도 쪽이 바뀌었는지 먼저 본다.
- 덤(10초): 홈 화면에 추가한 아이콘 아래 이름 `계획귀찮아`가 잘리지 않는지(ADR-0068, 사용자 확인 대기).
