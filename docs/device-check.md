# 실기기 점검 — 길찾기 5분 (ADR-0069)

자동으로 못 보는 것만 본다: 카카오맵 앱이 있을 때와 없을 때, iOS가 앱 호출 실패에 띄우는 창, 카카오톡 인앱 브라우저. 링크가 어디로 가는지는 `npm run check:links`가 이미 확인한다(UA 5종 + PC).

## 준비 (1분)

- 배포 주소(아래 `{주소}`)를 폰 메모에 붙여 둔다. 아래 세 링크는 주소 뒤에 붙인다.
  - **자동차** `{주소}/?mood=new&area=seongsan&reach=drive30` — 성산 기준, 첫 카드 `길찾기`
  - **도보** `{주소}/?mood=food&area=gujeju&reach=walk` — 동문시장 기준, 첫 카드 `길찾기`
  - **배 타는 곳** `{주소}/?mood=new&area=hangyeong&reach=drive30` — 한경 기준, 차귀도 카드의 `배 타는 곳까지 길찾기`
- 카카오톡 칸은 위 링크를 나와의 채팅에 보내고 거기서 연다(인앱 브라우저).
- 「앱 없음」은 카카오맵 앱을 지우거나, 앱이 없는 다른 폰으로 본다.

## 점검 (칸마다 30초)

| # | 폰 · 브라우저 | 카카오맵 앱 | 링크 | 기대 결과 | 결과 |
|---|---|---|---|---|---|
| 1 | 아이폰 · Safari | 있음 | 자동차 | 카카오맵 앱이 열리고 **자동차** 길찾기, 출발 = 현재 위치, 도착 = 카드 장소. 앱이 위치를 묻는다면 앱이 묻는 것 | |
| 2 | 아이폰 · Safari | 있음 | 도보 | 앱이 열리고 **도보** 길찾기, 출발 = 현재 위치 | |
| 3 | 아이폰 · Safari | 없음 | 자동차 | 카카오 연결 페이지(「연결중입니다」 · `카카오맵 앱 설치` · `설치없이 지도보기`). 빈 화면 없음. **Safari 「주소가 유효하지 않음」 창이 뜨는지 적는다** | |
| 4 | 아이폰 · 카카오톡 인앱 | 있음 | 배 타는 곳 | 앱이 열리고 **자구내포구(차귀도포구)** 까지 자동차 길찾기. 카드 글자가 한 줄 `배 타는 곳까지 길찾기` | |
| 5 | 아이폰 · 카카오톡 인앱 | 있음 | 도보 | 앱 도보 길찾기. 인앱이 앱 열기를 막거나 확인 창을 띄우면 그 문구를 적는다 | |
| 6 | 안드로이드 · Chrome | 있음 | 도보 | 앱(또는 「카카오맵으로 열기」 확인 뒤 앱) 도보 길찾기, 출발 = 현재 위치 | |
| 7 | 안드로이드 · Chrome | 없음 | 배 타는 곳 | 카카오 연결 페이지 또는 Play 스토어. 빈 화면·오류 없음 | |
| 8 | 안드로이드 · 삼성 인터넷 (또는 카카오톡 인앱) | 있음 | 자동차 | 앱 자동차 길찾기 | |

## 결과 판정

- 1·2·4·5·6·8이 기대와 같으면 통과. 앱이 길찾기 대신 지도 첫 화면만 열면 그 칸을 「실패」로 적고 화면을 캡처한다.
- 3·7(앱 없음)은 **빈 화면이나 막다른 오류만 아니면** 통과. `설치없이 지도보기`가 도착지 없이 지도 첫 화면을 여는 것은 카카오 쪽 동작이라 알려진 한계다(ADR-0069 Consequences).
- 실패가 있으면 결과 칸과 캡처를 ADR-0069에 덧붙이고, `npm run check:links`를 다시 돌려 카카오 쪽이 바뀌었는지 먼저 본다.
- 덤(10초): 홈 화면에 추가한 아이콘 아래 이름 `계획귀찮아`가 잘리지 않는지(ADR-0068, 사용자 확인 대기).
