# 라이트하우스 — LCP 고친 뒤 (2026-11-05, 측정 전 고정)

주인 요청: 「LCP 개선도 이어서 해줘」. 기준선은 `lighthouse-2026-11-05-budget.md`(운영 홈 3번 중앙값: 성능 75, LCP 6,370ms, CLS 0, TBT 187).

## 원인과 고친 것
- 첫 방문(저장된 것 없음)은 「어디서 여행 중이에요?」 시작 화면이 홈 전체를 덮는다. 그런데도 그 아래 기분 칸 사진을 받았고, 가려진 그 사진이 LCP로 잡혔다. 사진은 1.2MB 장소 파일을 다 받고 JS가 칸을 그린 뒤에야 요청된다(느린 4G 흉내에서 6초대).
- 고친 것: 시작 화면이 덮고 있는 동안 홈 사진은 주소를 `data-later`에 두고 받지 않는다. 시작 화면이 닫히면 그때 받는다(`src/later.ts`, render.ts homePhoto, start.ts close, app.ts). 다시 온 사람(시작 화면 없음)은 그대로다.

- 이 측정은 **첫 방문**만 잰다. 다시 온 사람의 홈(시작 화면 없음, LCP는 기분 칸 사진)은 이 고침으로 바뀌지 않으며 라이트하우스 기본 설정으로는 재지 않는다 — 결과를 「다시 온 사람도 빨라졌다」로 읽지 않는다.
