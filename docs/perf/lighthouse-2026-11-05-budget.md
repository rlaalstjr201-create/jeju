# 라이트하우스 — 진입 예산 올리기 전 현재 상태 (2026-11-05, 측정 전 고정)

주인 요청: 「라이트하우스로 재보고 한도 올려줘」. ADR-0100이 「느려졌는지는 Lighthouse로 다시 재야 한다(이 ADR은 재지 않았다)」고 남긴 측정이다.

## 방법
- `node docs/perf/lh.mjs docs/perf/lighthouse-2026-11-05.json https://yeochana.com /` — Lighthouse CLI, 기본 모바일(느린 4G 흉내, CPU 4배 느림), 운영 홈 `/` 3번, 중앙값.
- 한 번으로 끝이다. 좋은 값이 나올 때까지 다시 재지 않는다. 실패하면 그 사실을 적는다.

## 읽는 법 (미리 적음)
- 기준(2026-10-05 lighthouse-criteria.md): 성능 90, LCP 2.5초, CLS 0.1, TBT 200ms.
- 이 측정은 문을 막는 게이트가 아니다. 주인이 한도를 올리기로 했으므로, 지금 상태를 남기고 기준에 못 미치는 값은 숨기지 않고 적는다.
- 홈 성능은 실행마다 흔들린다(10-05 기록 88~99). 작은 차이는 차이로 읽지 않는다.
