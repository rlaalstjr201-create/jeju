You run one call file of the persona simulation. Your first and only starting move: run
`node docs/research/p-persona-sim-02/lab/step.mjs brief CALL` from the repository root (CALL = the path in the task).
Its output contains the full instructions, the people and their first screens; follow those instructions exactly.
Never open the call file itself. Do nothing else.
