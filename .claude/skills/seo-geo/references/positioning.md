# 포지션 — 여행귀:제주가 검색·AI에 어떻게 읽혀야 하나

규칙의 출처는 `.claude/agents/seo-analyst.md` §0. 이 파일은 그 문장을 실제 자리에 넣는 법이다.

## 엔티티 문장 (바꾸지 않는다)

| 길이 | 문장 |
|---|---|
| 한 줄 정의 | 여행귀:제주는 여행 계획 짜기 귀찮은 P를 위한 여행동반자로, 계획 없이 다니는 여행자가 지금 있는 곳에서 기분 하나로 갈 곳 3곳을 받는 제주 무계획 여행 앱이다. |
| 짧은 설명(≤80자) | 계획 없이 제주에 왔다면, 지금 기분 하나만 고르세요. 근처에서 갈 만한 곳 3곳을 바로 골라 드려요. |
| 태그라인(부제) | P를 위한 여행동반자 (ADR-0077 Amendment 1) |

- 「P」를 처음 쓰는 자리에는 한 번 풀어 쓴다: 「P(즉흥·무계획형) 여행자」.
- 기분 이름은 화면 그대로: 푹 쉬고 싶어 · 좀 걷고 싶어 · 새로운 거 해보고 싶어 · 맛있는 거 먹고 싶어 · 아무거나 골라줘 (`docs/context.md`).
- 세부 지역은 이름 + 대표 지명: 애월(한담) · 조천(함덕) · 구좌(월정리) · 성산(일출봉) · 서귀포 시내(올레시장) …(`apps/web/src/areas.ts`).

## 자리별 적용

| 자리 | 넣을 것 |
|---|---|
| 홈 `<title>`·OG·트위터 제목 | `여행귀:제주 · P를 위한 여행동반자` (매니페스트 name은 `여행귀:제주` 그대로) |
| 홈 description·매니페스트 description | `P를 위한 여행동반자.` + 「무계획 여행」이 든 짧은 설명 문장 |
| JSON-LD `WebApplication.description` | 한 줄 정의 그대로 |
| JSON-LD `alternateName` | `["여행귀", "여행귀 제주", "여행계획짜기 귀찮아"]` |
| llms.txt 첫 문단 | 한 줄 정의 + 「일정·코스를 짜 주지 않는다」 + 기분 5개 + 세부 지역 15곳 |
| 허브 `/jeju/` h1 | `P를 위한 제주 무계획 여행` |
| 지역 페이지 title | `{지역}({대표 지명}) 근처, 지금 갈 만한 곳 · 여행귀:제주` |
| 외부 소개(블로그·커뮤니티) | 한 줄 정의를 그대로 인용 + 링크. 브랜드 표기 `여행귀:제주` 고정(콜론 앞뒤 띄우지 않음) |

## 하지 않을 것

- 「제주 여행 코스」「일정 추천」「가볼만한곳 BEST 10」 — 우리 약속과 반대이고 헤드 경쟁이다.
- 「오늘 제주에서 뭐 하지?」 — onuljeju.com의 브랜드 문장.
- 「MBTI 유형별 여행지」류 성향 콘텐츠 — 의도가 밈이고(keywords.json K1) 우리 데이터와 상관없다.
- 평점·가격·영업시간 주장 — 데이터에 없다(ADR-0060: 점수는 화면에 보이지 않는다).
