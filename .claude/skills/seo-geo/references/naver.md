# 네이버 — 어디서 이기고 어디서 비키나

## SERP 구조와 우리 자리

「○○ 근처 맛집/카페/가볼만한곳」 네이버 결과는 대체로 파워링크 → 플레이스(지도) → 블로그·카페·인플루언서 → 웹문서 순이다(검색어마다 다르다 — 후보마다 직접 보고 keywords.json `serp.naver_sections`에 적는다).
정적 웹페이지가 들어갈 수 있는 칸은 **웹문서**뿐이다. 플레이스는 업체 소유자의 등록이고 블로그·카페는 네이버 안 문서다.

| 블록 | 우리가 할 수 있는 것 |
|---|---|
| 플레이스 | 없음(업체가 아니다). 이 블록이 맨 위인 검색어(맛집·카페)는 K3로 버린다 |
| 블로그·카페·인플루언서 | 우리 사이트로는 못 들어간다. 오프사이트(아래)로 「우리 이름이 나오는 네이버 안 문서」를 만드는 것만 가능 |
| 웹문서 | 서치어드바이저 등록 + 정적 랜딩 + 사이트맵. 여기가 본전 |
| AI 브리핑 | 주로 네이버 안 문서·웹문서를 근거로 쓴다. 웹문서 칸 진입 + 네이버 안 언급이 선행 조건 |

## 서치어드바이저 (배포 후, `docs/seo/README.md` 순서)

1. searchadvisor.naver.com → 사이트 등록 `https://<도메인>`.
2. 소유 확인: HTML 파일(`public/naver<코드>.html`) 업로드를 권장 — index.html 메타를 건드리지 않아도 된다. 메타 방식이면 `<meta name="naver-site-verification" content="…">`.
3. 요청 → 사이트맵 제출(`/sitemap.xml`), RSS는 없음.
4. 검증 → robots.txt(Yeti 허용 확인), 웹페이지 수집 요청(허브·지역 페이지).
5. 리포트 → 검색 노출·클릭·검색어: API가 없으므로 **주 1회 수동으로** keywords.json target의 `track[]`에 `naver_pos`·`impressions`를 적는다.

다음(카카오) 검색은 웹마스터도구(webmaster.daum.net)에 같은 방식으로 등록한다(우선순위 낮음).

## 오프사이트 — 링크 0건 도메인의 유일한 레버

seoulist는 외부 인용 0건으로 부스트가 걷힌 뒤 50~80위로 밀렸다(`docs/seo/seoulist-postmortem.md`). 홍보가 아니라 쓸모 있는 답으로:

| 채널 | 무엇 | 규칙 |
|---|---|---|
| 여행 카페·커뮤니티 Q&A | 「지금 성산인데 비 와서 뭐하지」「계획 없이 제주 왔는데」류 질문에 장소 2~3곳을 직접 답하고 끝에 앱 한 줄 | 답이 먼저, 링크는 마지막·선택. 같은 문장 반복 금지 |
| 네이버 블로그(우리 채널 1개) | 세부 지역 × 기분 글. 랜딩 페이지 문장을 복사하지 않는다(중복 문서) | target·watch 검색어에 맞춘 제목. 글마다 사이트 해당 지역 페이지 링크 |
| P·무계획 여행 글 | 「P의 무계획 제주 여행」 경험 글에 도구로 소개될 기회(브런치·블로그 제보) | 엔티티 한 줄 그대로 인용되게 |
| 뉴스레터·정리 글 | 제주 여행 앱 정리 글 작성자에게 제보 | 1회성. 수락 여부를 기록 |

게시는 사람이 한다. 진단은 「어디에 무엇을」만 내고 `queue_kind: offsite`로 큐에 올린다. 다음 가동이 게시 여부(URL)로 채점한다.
